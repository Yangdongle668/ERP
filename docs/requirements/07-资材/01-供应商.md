# 07-01 供应商

## 1. 功能说明

供应商档案（基本、交易、联系人、银行、资质）、可供物料清单（含默认供应商）、准入流程（潜在 → 合格）、暂停与淘汰。

- 使用者：采购员、采购主管、SQE
- 优先级：P0

## 3. 页面

### 3.1 供应商列表（T1）

查询：关键字（编码/名称/简称）、状态（默认潜在、审批中、合格、暂停）、等级、类型、采购员、资质到期（全部/已过期/30 天内到期）、可供物料（MaterialSelect）。
列：编码（链接）、简称、名称、类型、等级、国家、采购员、币别、付款条件、主联系人、资质状态（有过期资质显示红色“资质过期”）、状态（潜在灰、审批中橙、合格绿、暂停橙 plain、淘汰红）、操作（编辑、提交准入、暂停/恢复、淘汰、删除）。
工具栏：新建、导入、导出。

### 3.2 新建/编辑供应商（T3）

分组：基本信息（名称*、英文名、简称*、编码、类型*、等级、国家*、省市地址、税号、电话、邮箱、网址、采购员*、备注）；交易信息（币别*、付款条件*、贸易条款、税率*、发票类型*、默认交货期）；联系人（表格）；银行（表格）；资质（表格：类型*、证书号、发证日期、到期日期、文件*、备注）；可供物料（表格：物料*、供应商料号、供货状态、默认供应商、交期、MOQ、MPQ、备注；[批量添加物料]）。

### 3.3 供应商详情（T5）

页头按钮：编辑、提交准入（潜在）、暂停（合格）、恢复（暂停）、淘汰（合格/暂停）。
页签：基本信息、联系人与银行、资质、可供物料、价格（有效价格列表，需 `pur:price:view`）、采购订单（该供应商订单）、到货与质量（最近 12 个月到货批次、IQC 合格率）、评估记录、应付（财务，需权限）、审批记录、操作日志、附件。

## 4. 状态与流转

| 当前 | 动作 | 条件 | 结果 |
|---|---|---|---|
| 潜在 | 提交准入 | R03 | 审批中（无审批流时直接合格） |
| 审批中 | 通过 / 驳回 | | 合格（记录准入日期）/ 潜在 |
| 合格 | 暂停 | 原因 | 暂停 |
| 暂停 | 恢复 | | 合格 |
| 合格 / 暂停 | 淘汰 | 原因 | 淘汰（不可恢复，需重新建档） |

| 状态 | 询价 | 样品/试用订单 | 正式采购订单 | 到货 |
|---|---|---|---|---|
| 潜在、审批中 | 是 | 是 | 否 | 仅样品订单 |
| 合格 | 是 | 是 | 是 | 是 |
| 暂停 | 否 | 否 | 否 | 已下订单可到货（提示） |
| 淘汰 | 否 | 否 | 否 | 否 |

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| PUR-SUP-R01 | 保存 | 编码、名称唯一；税号非空时唯一 | `供应商「{name}」已存在` |
| PUR-SUP-R02 | 保存 | 可供物料中同一物料只能有一个默认供应商（设置新默认时自动取消其他供应商的默认） | — |
| PUR-SUP-R03 | 提交准入 | 必须：主联系人、默认银行账户、付款条件、营业执照资质（国内）、至少一个可供物料 | `提交准入需要：{缺少的项}` |
| PUR-SUP-R04 | 下单校验 | `validateQualified`：状态合格，且没有已过期的营业执照/ISO9001 资质 | `供应商「{name}」不是合格供应商` / `供应商「{name}」的资质「{type}」已过期` |
| PUR-SUP-R05 | 提醒 | 资质到期前 30 天、到期当天提醒负责采购员和 SQE | — |
| PUR-SUP-R06 | 暂停/淘汰 | 原因必填；提示该供应商未完成的采购订单数量；发布 `SupplierStatusChangedEvent` | `该供应商还有 {n} 张未完成采购订单` （提示） |
| PUR-SUP-R07 | 删除 | 只有潜在状态且无任何订单、价格、询价记录可删除 | `供应商已有业务数据，不能删除` |
| PUR-SUP-R08 | 可供物料 | 试用状态的物料只能下“样品”类型订单 | `物料「{code}」在该供应商处为试用状态，只能下样品订单` |

## 6. 接口

`/purchase/suppliers`（CRUD、import/export）、`/{id}/qualify`、`/{id}/suspend`、`/{id}/resume`、`/{id}/eliminate`、`/purchase/suppliers/search`（SupplierSelect）、`/purchase/suppliers/{id}/materials`（可供物料 CRUD）、`/purchase/supplier-materials?materialId=`（某物料的可供供应商）。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PUR-SUP-T01 | 潜在供应商无营业执照 | 提交准入 | 提示“提交准入需要：营业执照资质” |
| PUR-SUP-T02 | 审批通过 | — | 状态合格，准入日期为今天 |
| PUR-SUP-T03 | 物料 A 默认供应商 V1 | 在 V2 中把 A 设为默认 | V1 的默认标记取消；MRP 采购建议默认 V2 |
| PUR-SUP-T04 | 营业执照过期 | 对该供应商下订单 | 提示“供应商「…」的资质「营业执照」已过期” |
| PUR-SUP-T05 | 物料在 V1 为试用 | 下标准采购订单 | 提示只能下样品订单 |

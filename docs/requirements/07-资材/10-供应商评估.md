# 07-10 供应商评估

## 1. 功能说明

按月（或季度）对合格供应商打分：质量和交期由系统自动计算，价格和服务由采购/SQE 手工评分，按权重得出总分和等级，作为供应商分级、暂停、配额的依据。

- 使用者：采购主管、SQE
- 优先级：P1

## 2. 评分规则

| 维度 | 默认权重 | 计算方式（满分 100） |
|---|---|---|
| 质量 | 40 | 批次合格率 × 100。批次合格率 = 评估期内 IQC 判定为合格的批次数 ÷ 判定批次数（特采算不合格）；期内无批次时该维度不计分，权重按比例分给其他维度 |
| 交期 | 30 | 准时率 × 100。准时率 = 准时到货的订单行数 ÷ 评估期内应到货的订单行数；准时 = 首次到货日期 ≤ 确认交期（无则要求日期）+ 容差天数，且到货数量 ≥ 订购数量的 95% |
| 价格 | 20 | 手工评分 0～100（可参考：期内调价幅度、与其他供应商比价结果） |
| 服务 | 10 | 手工评分 0～100（响应速度、配合度、异常处理） |

总分 = Σ 维度得分 × 权重 ÷ 100。等级：≥ 90 A、≥ 80 B、≥ 70 C、< 70 D。

## 3. 数据表

### pur_supplier_score

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| supplier_id | id | 是 | |
| period | str(7) | 是 | 评估期：月 `2026-09` 或季度 `2026-Q3` |
| lot_count / lot_pass_count | int | 是 | 判定批次数 / 合格批次数 |
| quality_score | rate | 否 | |
| due_line_count / ontime_line_count | int | 是 | |
| delivery_score | rate | 否 | |
| price_score / service_score | rate | 否 | 手工 |
| total_score | rate | 否 | |
| grade | str(1) | 否 | A/B/C/D |
| score_status | enum(CALCULATED/SCORED/PUBLISHED) | 是 | 已计算（待手工评分）/ 已评分 / 已发布 |
| comment | str(512) | 否 | 评语 |

唯一：`(supplier_id, period)`。

## 4. 页面（T1）

路由 `/purchase/score`。
查询：评估期、供应商、等级、状态。
工具栏：[计算]（选择评估期：为期内有业务的合格/暂停供应商计算质量和交期得分；已发布的不重算）、[发布]（勾选已评分的记录发布：更新供应商等级，D 级供应商提醒采购主管评估是否暂停）、[导出]。
列：供应商、评估期、批次（合格/总数）、质量得分、交期行（准时/应到）、交期得分、价格得分（可编辑数字框）、服务得分（可编辑）、总分、等级（A 绿 / B 蓝 / C 橙 / D 红）、评语（可编辑）、状态。
行操作：[明细]（抽屉：本期不合格批次列表、延误订单行列表）。
右侧：选中供应商近 12 期总分折线图。

## 5. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| PUR-SC-R01 | 权重取参数 `pur.score.weights`，合计必须为 100 | `评估权重合计必须为 100` |
| PUR-SC-R02 | 价格、服务得分都填写后状态变为已评分；只有已评分才能发布 | `请先完成价格和服务评分` |
| PUR-SC-R03 | 发布后供应商 level 更新为本期等级；发布后不能修改，需要时由采购主管“撤销发布”（原因必填） | — |
| PUR-SC-R04 | 每月 3 日 02:00 自动计算上月（参数可关闭） | — |

## 6. 接口

`GET /purchase/scores`、`POST /purchase/scores/calculate`（period）、`PUT /purchase/scores/{id}`（手工评分）、`POST /purchase/scores/publish`、`POST /purchase/scores/{id}/unpublish`、`GET /purchase/scores/{id}/details`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PUR-SC-T01 | V1 9 月 10 批，合格 9；应到 20 行，准时 18 | 计算 | 质量 90、交期 90 |
| PUR-SC-T02 | 价格 80、服务 100 | 保存 | 总分 90×0.4+90×0.3+80×0.2+100×0.1 = 89，等级 B |
| PUR-SC-T03 | 已评分 | 发布 | 供应商等级变为 B |
| PUR-SC-T04 | 总分 65 | 发布 | 等级 D，采购主管收到“建议评估是否暂停”提醒 |

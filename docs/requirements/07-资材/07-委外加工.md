# 07-07 委外加工

## 1. 功能说明

把部分加工交给外部加工商：本厂提供材料（发料），加工商加工后交回成品/半成品（收货），按加工费结算。系统管理委外订单、发料、收货、材料核销。

- 使用者：采购员（委外跟单）、仓管员
- 优先级：P1
- 范围：整件委外（物料取得方式为“委外”）。工序委外（生产订单中的某道工序外发）在生产模块处理（P2）。

## 2. 数据表

### pur_outsourcing 委外单（BaseDocDO，编码规则 PUR_OUTSOURCING）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| supplier_id | id | 是 | 加工商（类型建议为委外加工商，合格状态） |
| material_id | id | 是 | 加工成品（取得方式为委外，需有已审核 BOM） |
| bom_id | id | 是 | 使用的 BOM 版本（快照） |
| qty | qty | 是 | 委外数量（基本单位） |
| process_price | price | 是 | 加工费不含税单价 |
| tax_rate | pct | 是 | |
| currency | str(3) | 是 | |
| exchange_rate | rate | 是 | |
| amount / tax_amount / total_amount | amt | 是 | 加工费金额 |
| required_date | date | 是 | 要求交回日期 |
| received_qty | qty | 是 | 已收货（到货） |
| qualified_qty | qty | 是 | 检验合格入库 |
| mrp_result_id | id | 否 | 来源 MRP |

状态：草稿 → 待审批 → 已审核 → 执行中（有发料或收货）→ 已完成（收齐且核销）/ 已关闭。

### pur_outsourcing_material 委外用料

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| outsourcing_id | id | 是 | |
| material_id | id | 是 | 子件 |
| qty_per | qty | 是 | 单位用量（来自 BOM，含损耗） |
| required_qty | qty | 是 | 应发数量 = 委外数量 × 单位用量（向上取整） |
| issued_qty | qty | 是 | 已发（出库确认回写） |
| returned_qty | qty | 是 | 加工商退回的余料（入库确认回写） |

| loss_qty | qty | 否 | 超耗 = 已发 − 退回 − 消耗（>0 为超耗） |
| loss_reason | str(256) | 否 | 超耗原因 |

## 3. 页面

### 3.1 委外单列表（T1）

查询：单号、加工商、物料、状态、要求日期。列：单号、加工商、加工物料、数量、加工费单价（字段权限）、要求日期、发料进度、收货进度、状态、操作。

### 3.2 编辑页（T4）

单头：加工商*、加工物料*（选择后带出默认 BOM 并生成用料明细）、BOM 版本（下拉，默认版本）、数量*（修改后重算应发数量）、加工费单价*（取采购价格表中该加工商该物料的价格）、税率、币别、汇率、要求日期*、备注。
用料明细（只读计算，可调整“应发数量”，需填写原因）：子件、单位用量、应发数量、可用库存。

### 3.3 详情页（T5）

按钮：编辑/提交/审批、[发料]（已审核/执行中：选择用料行和本次数量 → 生成委外发料出库单 OUTSOURCE_ISSUE，发料仓按物料默认仓）、[收货]（跳转到货单，类型委外收货，带入本委外单）、[余料退回]（选择用料行和退回数量 → 生成仓库入库单，入库类型“委外退料入库” OUTSOURCE_RETURN；良品入物料默认仓，不良入不良品仓）、[核销]（收齐后计算消耗与超耗，超耗行必须填写原因）、[关闭]、打印（委外加工单，含用料清单）。
页签：用料（应发、已发、退回、消耗、超耗）、收货记录、关联单据、审批记录、操作日志。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| PUR-OS-R01 | 保存 | 物料取得方式为委外且有已审核 BOM | `物料「{code}」不是委外件或没有已审核的 BOM` |
| PUR-OS-R02 | 发料 | 本次发料 ≤ 应发 − 已发（参数允许超发比例，默认 0） | `物料「{code}」发料超过应发数量` |
| PUR-OS-R03 | 收货 | 收货数量 ≤ 委外数量 − 已收货；收货入库走到货单流程（需检入待检仓） | `收货数量超过委外剩余数量` |
| PUR-OS-R04 | 收货 | 按已发料齐套数控制：本次收货后累计收货 ≤ min(已发 ÷ 单位用量)；超过时警告“收货数量超过已发材料可生产的数量” | 警告 |
| PUR-OS-R05 | 核销 | 消耗 = 合格数量 × 单位用量；超耗 > 0 的行必须填写原因；核销后委外单完成 | `物料「{code}」超耗 {qty}，请填写原因` |
| PUR-OS-R06 | 对账 | 加工费按合格收货数量 × 加工费单价进入供应商对账 | — |
| PUR-OS-R07 | 成本 | 委外入库成本 = 消耗材料成本（月末计算）+ 加工费（不含税，本位币） | — |

## 5. 接口

`/purchase/outsourcings`（CRUD、submit、close）、`/{id}/issue`（生成发料出库单）、`/{id}/return-material`、`/{id}/settle`（核销）、`/{id}/print-data`；`OutsourcingApi.createFromMrp`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PUR-OS-T01 | 委外件 SF1 BOM：A×2、B×1 | 新建委外 100 | 用料：A 应发 200、B 100 |
| PUR-OS-T02 | 发料 A 200、B 100（仓库确认） | 收货 100 并 IQC 合格 | 收货进度 100%；可核销 |
| PUR-OS-T03 | 已发 A 205、B 100；加工商退回 A 余料 3；合格收货 100 | 核销 | A 消耗 200，超耗 2（205 − 3 − 200），必须填写超耗原因后才能完成核销；B 超耗 0 |
| PUR-OS-T04 | 只发了 A 100 | 收货 100 | 警告“收货数量超过已发材料可生产的数量（50）” |

# 07-02 采购价格

## 1. 功能说明

维护“供应商 × 物料”的采购价格（支持阶梯价、有效期）。价格只能通过**调价单**（新建或询价定标生成）经审批后生效，保证每次价格变化可追溯。采购订单下单时自动取价。

- 使用者：采购员（发起调价）、采购主管（审批）
- 优先级：P0
- 价格属于敏感数据：查看需要字段权限 `pur:price:view`。

## 3. 页面

### 3.1 采购价格列表（T1）

路由 `/purchase/price`。
查询：供应商、物料（编码/名称）、物料类别、状态（默认有效）、生效日期（范围）。
列：供应商简称、物料编码、名称、规格、单位、币别、阶梯（“≥1,000”）、不含税单价、税率、含税单价、生效日期、失效日期、状态、来源调价单（链接）、更新时间。
工具栏：[新建调价单]、[导入价格]（生成草稿调价单）、[导出]。
行操作：[历史价格]（抽屉：该供应商该物料的全部历史价格记录及折线图）、[调价]（以该物料带入新建调价单）。

### 3.2 调价单编辑（T4）

单头：供应商*（SupplierSelect，潜在或合格）、币别*、调价原因*、附件（供应商报价单）。
明细：物料*（MaterialSelect，只列该供应商可供物料；参数允许时可选其他物料并自动加入可供物料为“试用”）、阶梯起始数量*、原价（只读）、新价*、税率、涨跌幅（只读，涨价红色、降价绿色）、生效日期*、失效日期、备注。
页头：[保存] [提交]。

### 3.3 调价单详情（T5）

按钮：编辑、提交、撤回/通过/驳回、作废（草稿）、打印。页签：明细、审批记录、操作日志、附件。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| PUR-PRC-R01 | 提交 | 同一物料的阶梯起始数量不重复，且必须有一档从 0 开始 | `物料「{code}」必须有起始数量为 0 的阶梯` |
| PUR-PRC-R02 | 审核生效 | 对同一供应商 + 物料 + 币别：生效日期 ≤ 今天的新价格立即替代原有效价格（原价格 effective_to 设为新生效日期前一天，状态 REPLACED）；生效日期在未来的价格先写入 EFFECTIVE，到期由定时任务在生效日替代旧价 | — |
| PUR-PRC-R03 | 定时 | 每天 00:05：effective_to < 今天的价格置为 EXPIRED；到达生效日的新价格替代旧价格 | — |
| PUR-PRC-R04 | 取价 | `getEffectivePrice(supplier, material, qty, date, currency)`：取该日期有效、币别相同、min_qty ≤ 数量的最大一档；没有返回空 | — |
| PUR-PRC-R05 | 提交 | 新价格与原价相比涨幅 > 10% 时明细行标红提示（审批流可按 maxIncreasePct 条件分支） | — |
| PUR-PRC-R06 | 字段权限 | 无 `pur:price:view` 时，价格列表页不可访问；其他页面的价格字段显示 `***` | — |

## 5. 接口

`GET /purchase/prices`、`GET /purchase/prices/history?supplierId=&materialId=`、`GET /purchase/prices/effective?supplierId=&materialId=&qty=&date=&currency=`（采购订单取价）、`/purchase/price-adjusts`（CRUD、submit、void、import）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PUR-PRC-T01 | — | 调价单：A 阶梯 0 → 1.00，1000 → 0.95，审核 | 价格列表两档有效价格 |
| PUR-PRC-T02 | 同上 | 采购订单数量 1500 | 带出 0.95 |
| PUR-PRC-T03 | A 当前 1.00 | 新调价 1.20 生效日期下月 1 日，审核 | 当月仍取 1.00；下月 1 日后取 1.20，旧价状态“被替代” |
| PUR-PRC-T04 | 阶梯只有 1000 一档 | 提交 | 提示“必须有起始数量为 0 的阶梯” |
| PUR-PRC-T05 | 无价格查看权限 | 打开采购订单 | 单价、金额显示 `***` |

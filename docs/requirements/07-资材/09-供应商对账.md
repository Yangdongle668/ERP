# 07-09 供应商对账

## 1. 功能说明

按期（通常每月）与供应商核对应付金额：系统自动汇总本期验收合格入库的物料（和委外加工费）减去退款退货，形成对账单；采购员与供应商核对（可增加扣款/调整行），供应商确认后，财务据此生成应付单。

- 使用者：采购员、财务
- 优先级：P1（未上线前，财务可直接按入库记录生成应付；上线后应付只来源于对账单）

## 2. 数据表

### pur_statement 对账单（BaseDocDO，编码规则 PUR_STATEMENT）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| supplier_id | id | 是 | |
| period_from / period_to | date | 是 | 对账区间（按入库确认日期/退货出库日期） |
| currency | str(3) | 是 | 一张对账单一个币别 |
| goods_amount | amt | 是 | 货款（价税合计，原币） |
| return_amount | amt | 是 | 退货（负数） |
| adjust_amount | amt | 是 | 调整（扣款为负） |
| total_amount | amt | 是 | 对账总额 = 货款 + 退货 + 调整 |
| tax_amount | amt | 是 | 税额 |
| supplier_confirmed_at | datetime | 否 | 供应商确认时间 |
| supplier_confirmer | str(64) | 否 | 供应商确认人 |

状态：草稿 → 待审批 → 已审核 → 已确认（供应商确认，推送财务）；已确认可“取消确认”（财务未生成应付时）。

### pur_statement_line

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| line_type | enum(GOODS/RETURN/PROCESS_FEE/ADJUST) | 是 | 货款 / 退货 / 委外加工费 / 调整 |
| source_type / source_id / source_line_id / source_no | | 条件 | 到货行、退货行、委外单（调整行为空） |
| order_no | str(64) | 否 | 采购订单号 |
| material_id | id | 否 | 调整行可空 |
| biz_date | date | 是 | 入库确认日期 / 退货出库日期 / 调整日期 |
| qty | qty | 是 | 基本单位数量（退货为负） |
| price_incl_tax | price | 是 | |
| tax_rate | pct | 是 | |
| amount / tax_amount / total_amount | amt | 是 | 退货、扣款为负 |
| remark | str(256) | 条件 | 调整行必填说明（如“来料不良扣款”） |

## 3. 可对账数量口径

| 行类型 | 数量来源 | 条件 |
|---|---|---|
| GOODS | 到货行：合格数量（含特采；免检为入库数量）− 已对账数量 | 检验已判定、已入库确认，且 biz_date 在区间内 |
| RETURN | 退款类退货行出库数量（负数） | 出库已确认 |
| PROCESS_FEE | 委外单合格收货数量 × 加工费单价 − 已对账 | |
| ADJUST | 手工录入 | |

不合格且换货退回的数量不进入对账（供应商会补货，补货的到货再对账）。

## 4. 页面

### 4.1 对账单列表（T1）

查询：单号、供应商、区间、状态、采购员。列：单号、供应商、区间、币别、货款、退货、调整、对账总额、状态、供应商确认时间、操作。
工具栏：[新建对账]、[批量生成]（选择区间，为区间内有可对账数据的所有供应商各生成一张草稿）。

### 4.2 编辑页（T4）

单头：供应商*、币别*、区间*（默认上月 1 日～月末）→ [加载可对账明细]。
明细分三个区块：货款（自动加载，可取消勾选暂不对账的行）、退货（自动加载）、调整（手工：说明*、金额*（含税）、税率）。底部汇总。
页头：[保存] [提交]。

### 4.3 详情页（T5）

按钮：编辑/删除/提交（草稿）、审批、[打印对账单]（发给供应商核对签字）、[供应商已确认]（已审核：填写确认人、确认日期、上传签字对账单*）、[取消确认]（R05）。
页签：明细、审批记录、操作日志、附件。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| PUR-ST-R01 | 加载 | 同一到货行/退货行不能同时出现在两张未作废对账单中（按剩余可对账数量加载） | — |
| PUR-ST-R02 | 保存 | 对账单币别与明细来源订单币别一致；不同币别的订单分开对账 | `明细币别与对账单币别不一致` |
| PUR-ST-R03 | 审核 | 回写订单行 statement_qty | — |
| PUR-ST-R04 | 供应商确认 | 必须上传供应商签字的对账单附件；确认后发布 `PurchaseStatementConfirmedEvent`（财务生成应付单） | `请上传供应商确认的对账单` |
| PUR-ST-R05 | 取消确认 | 财务已生成应付单时不能取消（财务监听 `PurchaseStatementUnconfirmingEvent` 并在已生成应付时抛出异常） | `财务已根据此对账单生成应付，不能取消确认` |
| PUR-ST-R06 | 反审核 | 扣回 statement_qty | — |

## 6. 接口

`/purchase/statements`（CRUD、submit、confirm、unconfirm、print-data）、`GET /purchase/statements/candidates?supplierId=&currency=&from=&to=`、`POST /purchase/statements/batch-generate`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PUR-ST-T01 | 9 月 V1 合格入库 3 批、退款退货 1 批 | 新建 9 月对账 | 货款 3 行、退货 1 行（负数） |
| PUR-ST-T02 | 某批检验未完成 | 加载 | 该批不出现 |
| PUR-ST-T03 | 加扣款 −500（来料不良） | 保存 | 对账总额减少 500 |
| PUR-ST-T04 | 未上传签字对账单 | 供应商已确认 | 提示“请上传供应商确认的对账单” |
| PUR-ST-T05 | 已确认 | — | 财务应付列表出现对应应付单 |

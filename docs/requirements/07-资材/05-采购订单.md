# 07-05 采购订单

## 1. 功能说明

向供应商下达采购订单：由采购申请生成或手工新建，自动取价，审批后发送给供应商，跟踪交期回复与到货，支持订单变更和关闭。

- 使用者：采购员（下单、跟单）、采购主管（审批）
- 优先级：P0

### pur_order_change / pur_order_change_line 订单变更单（编码规则 PUR_ORDER_CHANGE）

单头：`order_id`、`change_reason`*、`new_version`。明细：`order_line_id`（新增行为空）、`change_type`（ADD/MODIFY/CANCEL）、`material_id`、旧/新 `qty`、旧/新 `price`、旧/新 `required_date`、`remark`。审核后应用到订单，order_version + 1，并保存变更前的订单快照（json）。

## 3. 页面

### 3.1 采购订单列表（T1）

查询：单号、供应商、采购员、状态（默认已审核、执行中）、物料、单据日期（近 3 个月）、要求到货日期、订单类型、逾期（开关：有未到货行且确认交期/要求日期 < 今天）。
列：单号（链接）、类型、供应商简称、采购员、币别、价税合计（字段权限）、最早交期、到货进度（进度条：已到货/订购）、逾期行数（>0 红色）、发送状态（已发送时间）、版本（>1 时显示“V2”）、状态、单据日期、操作。
工具栏：[新建]、[从申请生成]、[导出]、[批量打印]。

### 3.2 从申请生成（SourceDocPicker）

弹窗列出待转订单的申请行（见 03-采购申请），可按供应商、物料、需求日期筛选；勾选后 [生成]：按建议供应商分组，每个供应商生成一张草稿订单（未指定供应商的行要求先在弹窗中选择供应商）；数量默认未转数量，按供应商 MOQ/MPQ 调整（调整后的数量在行上提示“已按 MPQ 取整”）。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| PUR-PO-R01 | 提交 | 标准订单：供应商 `validateQualified`；样品订单：供应商非暂停/淘汰 | 见 01-供应商 R04 |
| PUR-PO-R02 | 提交 | 物料启用；参数 `require-approved-supplier-material` 为是时物料必须是该供应商的合格可供物料（样品订单允许试用） | `物料「{code}」不是供应商「{name}」的合格可供物料` |
| PUR-PO-R03 | 行保存 | 数量 < 供应商或物料 MOQ 时警告；不是 MPQ 整数倍时提示“是否向上取整到 {n}” | 警告，不阻止 |
| PUR-PO-R04 | 取价 | 按供应商、物料、订单币别、行数量、单据日期取有效价格；无价格时按参数：NONE 不提示 / WARN 提示“无有效采购价格” / BLOCK 阻止提交 `物料「{code}」没有有效的采购价格` | |
| PUR-PO-R05 | 行保存 | 单价 > 价格表价 × (1 + 容差) 时标记超价，单头 has_price_overrun = 1 | — |
| PUR-PO-R06 | 金额 | 含税录入：price_incl_tax 为录入值，price = ROUND(price_incl_tax ÷ (1 + 税率), 6)；行价税合计 = ROUND(数量 × 含税单价, 2)，行不含税金额 = ROUND(价税合计 ÷ (1 + 税率), 2)，税额 = 价税合计 − 不含税金额。不含税录入则反向计算。单头合计 = 行合计之和 | — |
| PUR-PO-R07 | 变更 | 新数量 ≥ 已到货数量；已到货完的行不能修改单价（已对账的行任何字段不能改）；变更单审批通过后才生效 | `第 {n} 行变更后数量不能小于已到货数量 {qty}` |
| PUR-PO-R08 | 关闭 | 原因必填；有已到货未入库（到货单未审核）的记录时不能关闭 | `订单还有未处理的到货单「{no}」` |
| PUR-PO-R09 | 删除/反审核 | 草稿才能删除；有到货记录不能反审核 | `订单已有到货，不能反审核，请使用变更` |
| PUR-PO-R10 | 提醒 | 每天 08:00：确认交期（没有则要求日期）前 `pur.overdue.remind-days` 天仍未到货的行提醒采购员；已逾期的每天提醒一次 | — |
| PUR-PO-R11 | 字段权限 | 无 `pur:price:view` 时单价、金额显示 `***`，这类用户不能新建、编辑订单 | — |

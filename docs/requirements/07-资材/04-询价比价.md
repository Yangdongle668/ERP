# 07-04 询价比价

## 1. 功能说明

对一个或多个物料向多家供应商询价，录入各家报价，自动生成比价表，定标后生成调价单更新采购价格。

- 使用者：采购员、采购主管
- 优先级：P1

## 2. 数据表

### pur_rfq 询价单（BaseDocDO，编码规则 PUR_RFQ）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | str(128) | 是 | |
| currency | str(3) | 是 | 要求报价币别 |
| quote_deadline | date | 是 | 报价截止日期 |
| rfq_status | enum(DRAFT/QUOTING/COMPARING/AWARDED/CANCELED) | 是 | 草稿 / 报价中 / 比价中 / 已定标 / 已取消 |

### pur_rfq_line 询价物料

`rfq_id`、`line_no`、`material_id`*、`qty`*（预计采购量）、`required_date`、`remark`。

### pur_rfq_supplier 询价供应商

`rfq_id`、`supplier_id`*、`sent_at`（发出时间）、`quoted`（是否已报价）。

### pur_rfq_quote 报价

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| rfq_line_id | id | 是 | |
| supplier_id | id | 是 | |
| price | price | 是 | 不含税单价 |
| tax_rate | pct | 是 | |
| moq | qty | 否 | |
| lead_time_days | int | 否 | 交期 |
| valid_until | date | 否 | 报价有效期 |
| is_awarded | bool | 是 | 是否中标 |
| award_qty_pct | pct | 否 | 中标份额（多家中标时） |
| remark | str(256) | 否 | |

唯一：`(rfq_line_id, supplier_id)`。

## 3. 页面

### 3.1 询价单列表（T1）

查询：单号、标题、状态、物料、供应商、截止日期。列：单号、标题、物料数、供应商数、已报价家数、截止日期（已过期未定标红色）、状态、采购员、操作。

### 3.2 编辑页（T4）

单头：标题*、币别*、截止日期*（≥ 今天）、附件（图纸、规格书）。
两张明细表：**询价物料**（物料*、数量*、需求日期、备注）；**询价供应商**（供应商*，默认带出这些物料的可供供应商）。
按钮：[保存] [发出询价]（状态 → 报价中，可打印/导出询价函给供应商）。

### 3.3 录入报价与比价（专用页面）

矩阵表格：行 = 物料，列 = 供应商；单元格录入单价、税率、MOQ、交期、有效期（点击单元格弹出小表单）。

```
物料 \ 供应商         | V1 华强          | V2 立创          | V3 ...
FPC00001 数量 10,000  | 0.95 / 7天 ✓最低 | 1.02 / 5天       |
ELEC00012 数量 5,000  | 0.12 / 15天      | 0.11 / 10天 ✓最低|
```

- 每行最低价高亮绿色，并标注与当前有效价的差异（±%）。
- 底部按供应商汇总：若所有物料都向该供应商采购的总金额。
- 状态“报价中”时可录入报价；[结束报价] → 比价中。
- 比价中：每行勾选中标供应商（可多家并填写份额，合计 100%）→ [定标]。

定标：状态 → 已定标；按中标供应商分组，每家生成一张调价单（草稿，来源 RFQ，新价格 = 报价），采购员检查后提交审批。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| PUR-RFQ-R01 | 发出询价时至少 1 个物料、1 家供应商；供应商不能是暂停/淘汰状态 | `供应商「{name}」已暂停合作` |
| PUR-RFQ-R02 | 定标时每个物料至少选择一家中标供应商，多家时份额合计 100% | `物料「{code}」的中标份额合计必须为 100%` |
| PUR-RFQ-R03 | 截止日期后仍可录入报价（提示“已过截止日期”），便于补录 | — |
| PUR-RFQ-R04 | 已定标的询价单不能修改；可取消（未定标时，原因必填） | — |
| PUR-RFQ-R05 | 报价、比价页面需要 `pur:price:view` | — |

## 5. 接口

`/purchase/rfqs`（CRUD）、`/{id}/send`、`/{id}/quotes`（GET 矩阵、PUT 批量保存）、`/{id}/end-quote`、`/{id}/award`、`/{id}/cancel`、`/{id}/print-data`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PUR-RFQ-T01 | 2 物料、3 供应商 | 录入报价 | 每行最低价高亮 |
| PUR-RFQ-T02 | 物料 1 选 V1，物料 2 选 V2 | 定标 | 生成 V1、V2 各一张草稿调价单 |
| PUR-RFQ-T03 | 物料 1 选 V1 60%、V2 30% | 定标 | 提示份额合计必须为 100% |

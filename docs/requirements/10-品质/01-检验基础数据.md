# 10-01 检验基础数据

## 1. 功能说明

检验单开展所需的基础数据：

1. **检验项目库**：可复用的检验项目（外观、尺寸、功能……）；
2. **检验标准**：针对物料或物料类别、某种检验类型的检验项目组合（含规格值和抽样方案），有版本；
3. **抽样方案**：GB/T 2828.1（等同 ISO 2859-1）一次正常抽样，或全检、固定数量、免检；
4. **缺陷代码**：缺陷分类与等级。

- 使用者：QE、SQE
- 优先级：P0

### qc_aql_table（内置技术表）

内置 GB/T 2828.1 一次正常检验的“样本量字码表”（批量范围 × 检验水平 → 字码）和“主表”（字码 × AQL → 样本量、Ac、Re，含箭头指向规则展开后的结果）。不提供维护页面。

### qc_defect_code 缺陷代码

`code`（唯一）、`name`、`category`（dict qc_defect_category）、`default_level`（CR/MA/MI）、`status`。生产模块的不良代码（mfg_defect_code）可在参数中配置为直接使用本表。

## 3. 样本量与判定计算（GB2828 方案）

1. 由批量 N 和检验水平查字码；
2. 分别按 CR、MA、MI 的 AQL 查主表得样本量 n 和 Ac/Re（箭头时取箭头指向的第一个方案的 n、Ac、Re）；
3. 检验单样本量取三者中最大的 n（样本量 ≥ N 时全检，n = N）；
4. 判定：各等级缺陷数分别与对应 Ac/Re 比较，任一等级 ≥ Re 判不合格；AQL 为 0（零缺陷）时 Ac=0、Re=1。

示例：N = 1000，II 级 → 字码 J；MA 0.65 → n=80、Ac=1、Re=2；MI 1.5 → n=80、Ac=3、Re=4。

## 4. 检验标准匹配规则

检验单创建时按以下顺序查找**生效**的标准：物料 + 检验类型 →（IPQC 再按工序）→ 物料所在类别（向上逐级）+ 检验类型 → 找不到时使用“通用标准”（该检验类型下 scope 为 CATEGORY 且类别为空的标准，初始化时每种类型建一个“通用外观检验”）。

## 5. 页面

### 5.1 检验标准（T1 / T4）

路由 `/quality/standard`，页面三个页签：**检验标准**、**检验项目库**、**抽样方案**、**缺陷代码**（第四个页签）。

**检验标准列表**：查询：编号、名称、检验类型、物料、类别、状态（默认生效）；列：编号、名称、检验类型、适用（物料编码或类别名）、工序、抽样方案、版本、项目数、状态、更新时间、操作（编辑（草稿）、新版本（生效）、生效（草稿，`qc:standard:approve`）、作废、删除（草稿））。

**标准编辑（T4）**：单头：名称*、检验类型*、适用范围*（物料/类别二选一）、工序（IPQC）、默认抽样方案*、检验规范文件。明细：项目（从项目库选择）*、名称、规格描述、目标值、上限、下限（定量）、缺陷等级、抽样方案（可覆盖）、关键项目。

**项目库 / 抽样方案 / 缺陷代码**：T1 + T2 弹窗表单，字段即数据表字段。抽样方案表单提供 [计算预览]：输入批量 → 显示样本量和各等级 Ac/Re。

## 6. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| QC-STD-R01 | 同一物料（或类别）+ 检验类型（+ 工序）同一时间只能有一个生效标准；新版本生效时旧版本自动作废 | — |
| QC-STD-R02 | 定量项目至少填写上限或下限；上限 ≥ 下限 | `项目「{name}」请填写规格上下限` |
| QC-STD-R03 | 生效的标准不能修改，只能新建版本；已被检验单引用的标准不能删除 | `已生效的检验标准不能修改` |
| QC-STD-R04 | GB2828 方案必须填写检验水平和至少一个 AQL | `请填写检验水平和 AQL` |
| QC-STD-R05 | 检验单保存所用标准和抽样结果的快照，标准变更不影响已创建的检验单 | — |

## 7. 接口

`/quality/standards`（CRUD、new-version、activate、obsolete）、`/quality/inspection-items`、`/quality/sampling-plans`（含 `POST /preview`）、`/quality/defect-codes`；`GET /quality/standards/match?materialId=&inspectType=&operation=`。

## 8. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| QC-STD-T01 | 方案：II 级，MA 0.65，MI 1.5 | 预览批量 1000 | 样本量 80；MA Ac1/Re2；MI Ac3/Re4 |
| QC-STD-T02 | 批量 5 | 预览 | 样本量 5（全检） |
| QC-STD-T03 | 物料 A 无标准，类别 ELEC 有 IQC 标准 | A 到货生成 IQC | 使用 ELEC 标准 |
| QC-STD-T04 | 标准 V1 生效 | 新版本 V2 生效 | V1 作废；已创建的检验单仍按 V1 |

# 10-05 客诉

## 1. 功能说明

登记客户投诉，跟踪分析、回复、赔偿/退换货和结案，并与退货、NCR、CAPA 关联。

- 使用者：业务员（登记）、QE（分析回复）、品质主管（结案）
- 优先级：P1

## 3. 页面

### 3.1 客诉列表（T1）

查询：单号、客户、物料、类型、严重度、状态（默认未结案）、负责 QE、收到日期。列：单号、客户、物料、类型、严重度、数量、收到时间、回复期限（逾期未回复红）、负责 QE、处理方式、状态、业务员、操作。

### 3.2 编辑页（T4）

客户*、联系人、类型*、严重度*、物料、客户料号、订单号、出货单（选择该客户出货单，带出批次）、批次、序列号、投诉数量、问题描述*、收到时间*、回复期限、负责 QE*、附件（客户照片、报告）。

### 3.3 详情页（T5）

按钮：编辑、[开始分析]（新建 → 分析中）、[记录回复]（填写回复内容*、回复时间，上传回复文件；状态已回复）、[生成 NCR]、[生成 CAPA]、[生成销售退货]（跳转销售退货新建并带入）、[登记处理结果]（处理方式、索赔金额、同意金额）、[结案]（审批流 QC_COMPLAINT_CLOSE，要求：已回复、CAPA 已生成（严重度 ≥ 严重时）、处理结果已登记）、[取消]（原因）、打印。
页签：处理时间线（登记、分析、回复、处理、结案）、关联单据、审批记录、操作日志、附件。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| QC-CPL-R01 | 严重度为致命时：立即通知品质主管和总经理（参数中的管理层用户）；自动生成 CAPA | — |
| QC-CPL-R02 | 回复期限前 1 天未回复提醒负责 QE；逾期每天提醒并抄送品质主管 | — |
| QC-CPL-R03 | 结案条件见 3.3 | `结案前需要：{缺少的项}` |
| QC-CPL-R04 | 同意赔偿金额 > 0 时，结案后发布 `ComplaintClaimAgreedEvent`，财务据此登记应收折让（或其他应付） | — |
| QC-CPL-R05 | 业务员只能看到自己客户的客诉（按 CRM 客户负责人） | — |

## 5. 接口

`/quality/complaints`（CRUD、start、reply、handling、close、cancel、create-ncr、create-capa、print-data）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| QC-CPL-T01 | — | 登记致命客诉 | 品质主管、总经理收到通知；自动生成 CAPA |
| QC-CPL-T02 | 回复期限明天 | — | QE 收到提醒 |
| QC-CPL-T03 | 未回复 | 结案 | 提示“结案前需要：客户回复” |
| QC-CPL-T04 | 同意赔偿 500 USD | 结案 | 财务收到折让事件 |

# 10-07 质量追溯与报表

## 1. 质量追溯

路由 `/quality/trace`，权限 `qc:trace:query`，优先级 P1。

复用生产模块的追溯引擎（`TraceApi`）与出货记录，页面在生产追溯的基础上叠加质量信息：

- **反向**（客诉/成品批次 → 原材料）：每个节点显示该批次的检验记录（IQC/FQC 结果、特采标记、NCR 链接）。
- **正向**（问题原材料批次 → 成品 → 客户）：显示受影响的成品批次、库存分布（当前还在各仓库的数量，可一键冻结）、已出货客户与数量，导出召回清单。
- 顶部操作：[冻结全部在库批次]（`qc:ncr:create` 权限，需关联 NCR，调用 `BatchApi.freeze`）。

## 2. 质量报表

路由 `/quality/report`（多个页签），权限 `qc:report:query`。

### 2.1 来料质量（IQC）

- 查询：期间、供应商、物料类别、物料。
- 指标：检验批次、合格批次、批次合格率、特采批次、拒收批次、检验数量、不良率（样本不良数 ÷ 样本数）。
- 维度：按供应商（排名）、按物料、按月趋势。
- 图表：供应商批次合格率排名柱状图（最低的 10 家）、月度趋势。

### 2.2 制程质量（IPQC + 生产良率）

- 数据：IPQC 检验结果 + 生产模块良率（`/production/reports/yield` 同口径）。
- 指标：IPQC 批次合格率、工序一次良率、直通率、不良 Pareto。

### 2.3 成品与出货质量（FQC / OQC）

- 指标：FQC 一次合格率、OQC 合格率、出货批次数、客诉率（客诉件数 ÷ 出货批次）。

### 2.4 NCR / CAPA / 客诉统计

- NCR：按来源、责任、处置方式、物料统计数量和金额；平均关闭周期。
- CAPA：按期关闭率、超期清单、平均周期。
- 客诉：按客户、产品、类型、严重度统计；首次回复及时率；月度趋势。

### 2.5 缺陷分析

- 缺陷代码 Pareto（可选来源：IQC / IPQC / FQC / OQC / 生产不良 / 客诉），支持下钻到明细。

## 3. 接口

`GET /quality/trace/backward`、`/forward`、`POST /quality/trace/freeze`；`GET /quality/reports/iqc`、`/process`、`/outgoing`、`/ncr-capa-complaint`、`/defect-pareto`，均有 `/export`。

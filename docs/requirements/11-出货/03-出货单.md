# 11-03 出货单

## 1. 功能说明

出货单是“货物离厂”的正式单据：由出货通知（已装箱、OQC 合格或免检）生成，提交后生成仓库销售出库单，仓管员确认出库后出货单变为“已出货”，并发布出货确认事件（销售回写已出货、财务生成应收、回款计划计算到期日、PMC 更新需求）。

- 使用者：船务
- 优先级：P0

## 3. 页面

### 3.1 出货单列表（T1）

查询：单号、客户、订单号、出货通知、提单号、状态、出货日期（默认近 30 天）、运输方式、物流状态。
列：单号、客户、出货日期、运输方式、目的港、数量、金额（字段权限）、箱数、提单号、ETD/ETA、物流状态、状态、船务、操作。
工具栏：[导出]。

### 3.2 生成与编辑（T4）

从出货通知 [生成出货单]：默认带入全部已装箱且未出货的行（批次来自拣货），可取消部分行（分批出货时按箱选择：勾选箱号，行数量自动汇总）。
单头可编辑：出货日期、货代、柜号、封条号、备注；其余取通知只读。
页头：[保存] [提交]。

### 3.3 详情页（T5）

| 按钮 | 状态 | 权限 | 行为 |
|---|---|---|---|
| 编辑 / 删除 / 提交 | 草稿 | update / delete / submit | 提交：R02～R04 → 待出库（或待审批） |
| 撤回 | 待出库（出库单未确认） | withdraw | 作废出库单，回到草稿 |

## 4. 状态与流转与事件

| 当前 | 动作 | 结果 | 副作用 |
|---|---|---|---|
| 草稿 | 提交 | 待出库（有审批流时先待审批） | 调用 `InventoryDocApi.createStockOut(SALES_OUT)`，行带批次；参数自动确认时直接出库 |
| 待出库 | 仓库确认出库（`StockOutConfirmedEvent`） | 已出货 | 回写 out_qty、通知 shipped_qty；发布 `ShipmentConfirmedEvent`（销售已出货、财务应收、回款计划、PMC 需求、CRM 信用） |
| 已出货 | 仓库反确认（`StockOutReversingEvent` 校验：财务未核销、未开票 → 允许） | 待出库 | 发布 `ShipmentReversedEvent` 冲回各方数据 |
| 已出货 | 登记提单 | 已出货 | 发布 `BillOfLadingReceivedEvent`（回款计划到期日） |
| 已出货 | 登记签收 / 提单（外销以提单为完成） | 已完成 | 发布 `ShipmentSignedEvent` |
| 草稿 | 作废 | 已作废 | |

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SHP-SH-R01 | 生成 | 出货通知状态为已装箱（免 OQC）或待出货（OQC 合格）；未装箱启用时要求拣货完成 | `出货通知尚未完成装箱/OQC` |
| SHP-SH-R02 | 提交 | 客户不在黑名单；订单行未关闭；出货数量 ≤ 订单行未出货数量 × (1 + 超出货比例) | `订单「{no}」行 {n} 已关闭` |
| SHP-SH-R03 | 提交 | 信用再次检查（WARN 提示、BLOCK 阻止）；出货前款项检查按参数 | CRM/销售提示原文 |
| SHP-SH-R04 | 提交 | OQC：需要 OQC 的物料必须有合格（或特采）的 OQC 结果 | `物料「{code}」OQC 未合格，不能出货` |
| SHP-SH-R05 | 金额 | 出货金额按订单单价（含税）× 出货数量；汇率取出货日期汇率（与订单汇率可能不同，应收按出货汇率） | — |
| SHP-SH-R06 | 反确认 | 财务已核销应收或已开票时，财务阻止（在 StockOutReversingEvent 中抛出） | `该出货已开票/已收款核销，不能反确认` |
| SHP-SH-R07 | 提单 | 提单日期不能早于出货日期 | `提单日期不能早于出货日期` |

## 6. 接口

`/shipping/shipments`（CRUD、submit、withdraw、void、print-data）、`POST /shipping/notices/{id}/shipments`（生成）、`PUT /shipping/shipments/{id}/logistics`、`POST /shipping/shipments/{id}/sign`；`ShipmentQueryApi`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SHP-SH-T01 | 通知已装箱，免 OQC | 生成出货单并提交 | 仓库出现销售出库单（带批次） |
| SHP-SH-T02 | 仓库确认出库 | — | 出货单已出货；订单已出货数量增加；财务生成应收；回款计划生成本批尾款 |
| SHP-SH-T03 | 需要 OQC 未判定 | 生成出货单 | 提示“出货通知尚未完成装箱/OQC” |
| SHP-SH-T04 | 已出货 | 登记提单日期 | 回款计划 BL 节点有了到期日 |
| SHP-SH-T05 | 应收已核销 | 仓库反确认出库 | 提示不能反确认 |
| SHP-SH-T06 | 15 箱分两批出 | 第一批勾选箱 1-10 | 出货单数量 = 10 箱内容 |

# 11-05 物流跟踪

## 1. 功能说明

维护货代资料，登记已出货的物流信息（订舱、装柜、离港、到港、清关、签收）与关键日期，跟踪在途货物。

- 使用者：船务
- 优先级：P1

## 2. 数据表

### shp_forwarder 货代

`code`*（唯一）、`name`*、`contact`、`phone`、`email`、`services`（海运/空运/快递，多选）、`status`、`remark`。

### shp_logistics_event 物流记录

| 字段 | 类型 | 说明 |
|---|---|---|
| shipment_id | id | |
| status | dict(shp_logistics_status) | |
| occurred_at | datetime | |
| location | str(128) | |
| remark | str(256) | |
| operator_id | id | |

出货单上的 `logistics_status` 为最新一条记录的状态。

## 3. 页面

### 3.1 物流跟踪（T1）

路由 `/shipping/logistics`。查询：客户、运输方式、物流状态（默认未签收）、ETD/ETA 范围、货代。
列：出货单、客户、运输方式、货代、提单号、柜号、ETD、ETA（已过 ETA 未到港橙色）、当前物流状态、最近更新时间、操作（[更新状态]：状态*、时间*、地点、备注；[登记提单]；[登记签收]）。

### 3.2 货代（T1 + T2）

路由 `/shipping/forwarder`，权限 `shp:forwarder:manage`。

## 4. 业务规则

| 编号 | 规则 |
|---|---|
| SHP-LOG-R01 | 物流状态按顺序推进（可跳过，不可倒退；倒退需说明原因） |
| SHP-LOG-R02 | 状态为“已签收”时出货单自动完成，发布 `ShipmentSignedEvent` |
| SHP-LOG-R03 | ETA 已过 3 天仍未到港的出货，提醒船务 |

## 5. 接口

`/shipping/forwarders`（CRUD）、`GET /shipping/logistics`、`POST /shipping/shipments/{id}/logistics-events`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SHP-LOG-T01 | 已出货 | 更新状态为已离港 | 列表显示已离港 |
| SHP-LOG-T02 | 更新为已签收 | — | 出货单状态已完成 |

# 11-02 拣货与装箱

## 1. 功能说明

- **拣货单**：出货通知审核后生成，系统按 FIFO/FEFO 推荐批次和库位，仓管员按单拣货并录入实际拣货批次和数量。拣货不改变库存（出库在出货单确认时发生），但会**预留**所拣批次，防止被其他出库占用。
- **装箱**：记录每个箱号装了哪些物料、多少、毛净重、尺寸，打印箱唛；装箱数据用于 Packing List。

- 使用者：仓管员
- 优先级：P0

## 2. 数据表

### shp_picking 拣货单（BaseDocDO，编码规则 SHP_PICKING）

`notice_id`*、`warehouse_id`*、`picker_id`（拣货人）、`picking_status`（enum：WAITING 待拣 / PICKING 拣货中 / DONE 已完成 / CANCELED 已取消）。

### shp_picking_line

| 字段 | 类型 | 说明 |
|---|---|---|
| notice_line_id | id | |
| material_id | id | |
| location_id | id | 库位 |
| batch_no | str(64) | |
| suggested_qty | qty | 推荐数量 |
| picked_qty | qty | 实拣数量 |
| serial_nos | text | 序列号（按需） |

一行通知可以对应多行拣货（不同批次/库位）。

### shp_carton 箱

| 字段 | 类型 | 说明 |
|---|---|---|
| notice_id | id | |
| carton_no | int | 箱号（1 开始，通知内连续） |
| carton_spec | dict(shp_carton_spec) | 外箱规格 |
| length_cm / width_cm / height_cm | rate | 尺寸 |
| gross_weight_kg | rate | 毛重 |
| net_weight_kg | rate | 净重（默认按物料单位净重 × 数量计算） |
| cbm | rate | 体积 = 长 × 宽 × 高 ÷ 1,000,000 |
| pallet_no | str(16) | 托盘号（可选） |

### shp_carton_line 箱内明细

`carton_id`、`notice_line_id`、`material_id`、`batch_no`、`qty`、`serial_nos`。

## 3. 页面

### 3.1 拣货单（T1 + 拣货录入）

列表：单号、出货通知、客户、出货日期、仓库、行数、状态、拣货人、操作（开始拣货、打印）。
打印：按库位编码排序的拣货清单（库位、物料、批次、推荐数量、实拣栏）。

**拣货录入**（专用页，支持扫码枪）：每行显示物料、推荐库位/批次/数量；实拣数量输入；[更换批次]（BatchSelect，可选其他批次）；扫码：扫描库位码、物料批次标签后自动定位行并数量 +1 或录入整批数量。[完成拣货]：校验每个通知行实拣合计 = 通知数量（不足时可选择“按实拣数量完成”，差额回到通知“缺货”并提示船务）。

### 3.2 装箱（专用）

路由 `/shipping/packing?noticeId=`。

```
┌ 装箱：SN-202609-0003  ABC Ltd  共 3 行 1,500 PCS            [打印全部箱唛] [完成装箱] ┐
│ 待装：FG00001 控制板 批次 MO-12  剩余 300                                            │
│ ─────────────────────────────────────────────────────────────────────────────── │
│ [按规格批量装箱]：物料[FG00001▾] 每箱数量[100] 箱规格[A箱 60×40×40▾] 箱数=自动 3 [生成] │
│ 箱号  物料        批次    数量  规格          毛重  净重  CBM     操作               │
│ 1-12  FG00001    MO-12   100/箱 60×40×40    12.5  11.0  0.096/箱  编辑 拆分 删除     │
│ 13    FG00001+FG2 混装   …                                                          │
│ 合计：15 箱  毛重 187.5 kg  净重 165.0 kg  体积 1.440 m³                               │
└──────────────────────────────────────────────────────────────────────────────────┘
```

- 批量装箱：指定物料、每箱数量、箱规格，自动生成连续箱号（相同内容的箱合并显示为“1-12”）；尾箱数量自动为余数。
- 手工新增箱：可混装多个物料。
- 毛重可按“净重 + 箱皮重”自动计算并允许修改。
- [打印箱唛]：每箱一张标签（客户、PO、料号、数量、毛净重、箱号 “1/15”、产地 MADE IN CHINA；中英文模板）。
- [完成装箱]：校验装箱数量 = 实拣数量 → 通知状态“已装箱”；需要 OQC 时可一并 [申请 OQC]。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SHP-PK-R01 | 生成拣货单 | 推荐：出货仓中合格未冻结未过期批次，按物料出库规则（FIFO/FEFO）；库存不足时推荐可用部分并标记缺货 | — |
| SHP-PK-R02 | 拣货 | 实拣批次必须有足够可用量；开始拣货时对推荐批次调用 `ReservationApi.reserve`（P1，未上线预留时仅做校验） | `批次「{batch}」可用数量不足` |
| SHP-PK-R03 | 完成拣货 | 每个通知行实拣合计 = 通知数量，或选择“按实拣完成”（差额释放） | `第 {n} 行拣货数量 {picked} 与通知数量 {qty} 不一致` |
| SHP-PK-R04 | 装箱 | 每个物料 + 批次的装箱数量 = 实拣数量；箱号连续不重复 | `装箱数量与拣货数量不一致：{material}` |
| SHP-PK-R05 | 装箱 | 修改装箱后若已申请 OQC 且未判定，需要确认“将重新提交 OQC” | — |
| SHP-PK-R06 | 取消拣货 | 通知关闭/反审核时拣货单作废并释放预留 | — |

## 5. 接口

`GET /shipping/pickings`、`GET /shipping/pickings/{id}`、`PUT /shipping/pickings/{id}/lines`、`POST /shipping/pickings/{id}/start`、`/complete`、`/print-data`；`GET /shipping/notices/{id}/cartons`、`POST /shipping/notices/{id}/cartons/batch`、`PUT /shipping/cartons/{id}`、`DELETE /shipping/cartons/{id}`、`POST /shipping/notices/{id}/pack-complete`、`GET /shipping/notices/{id}/labels`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SHP-PK-T01 | FG1 成品仓批次 B1 200、B2 500 | 通知 600 审核 | 拣货推荐 B1 200、B2 400 |
| SHP-PK-T02 | 实拣 580 | 完成拣货 | 提示数量不一致；选择按实拣完成后通知缺货 20 |
| SHP-PK-T03 | 580 个，每箱 100 | 批量装箱 | 生成 6 箱：1-5 每箱 100，第 6 箱 80 |
| SHP-PK-T04 | 装箱合计 570 | 完成装箱 | 提示装箱数量与拣货数量不一致 |
| SHP-PK-T05 | — | 打印箱唛 | 每箱一张，显示 “1/6” … “6/6” |

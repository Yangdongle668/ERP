# 09-02 工单派工

## 1. 功能说明

把生产订单的某道工序按日期、产线、班次、班组拆分成**工单**，下发到现场执行；工单是现场报工的对象，打印的派工单带条码，扫码即可报工。

- 使用者：班组长、生产主管
- 优先级：P1（参数 `mfg.report.require-work-order` 为否时，可以不派工，直接对生产订单工序报工）

## 2. 数据表

### mfg_work_order 工单（BaseDocDO，编码规则 MFG_WORK_ORDER）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| prod_order_id | id | 是 | |
| operation_seq | int | 是 | 工序号 |
| work_center_id | id | 是 | 默认工序的工作中心，可改为同车间其他工作中心 |
| plan_date | date | 是 | 计划生产日期 |
| shift | dict(mfg_shift) | 是 | |
| team_leader_id | id | 否 | 班组长 |
| plan_qty | qty | 是 | 派工数量 |
| good_qty / defect_qty / scrap_qty | qty | 是 | 报工回写 |
| wo_status | enum(DISPATCHED/RUNNING/DONE/CANCELED) | 是 | 已派工 / 进行中 / 已完成 / 已取消 |
| remark | str(256) | 否 | 作业要点 |

## 3. 页面

### 3.1 派工（专用页面）

路由 `/production/work-order/dispatch`。

```
┌ 待派工 ─────────────────────────────────────┬ 派工 ───────────────────────────────┐
│ 车间[SMT▾] 日期[2026-09-25]                 │ MO-202609-0012  FG1  工序 10 SMT    │
│ 生产订单   产品   工序    订单数  已派  未派  │ 未派 600                            │
│ MO-…0012  FG1   10 SMT  1000    400   600  │ 日期*   班次*  工作中心*  数量*  班组长 │
│ MO-…0015  FG2   20 DIP  500     0     500  │ 09-25   白班   SMT1      300    张三   │
│                                            │ 09-25   夜班   SMT1      300    李四   │
│                                            │ [+ 添加]            [取消] [确认派工]  │
└────────────────────────────────────────────┴──────────────────────────────────────┘
```

左侧列出已下达/生产中订单的工序（未派数量 > 0），按优先级、计划开工排序；右侧对选中工序拆分派工。底部显示所选工作中心当天已派工时 / 日产能（超出红色提示，不阻止）。

### 3.2 工单列表（T1）

查询：单号、生产订单、工序、工作中心、日期（默认今天）、班次、状态。
列：工单号、生产订单、产品、工序、工作中心、日期、班次、派工数量、合格、不良、报废、完成率、班组长、状态、操作（报工、取消、打印）。
工具栏：[批量打印派工单]。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| MFG-WO-R01 | 同一工序已派数量 ≤ 订单计划数量 × (1 + 超产比例) − 已报工合格数中未经派工的部分 | `派工数量超过工序可派数量 {qty}` |
| MFG-WO-R02 | 生产订单暂停、关闭时不能派工；未报工的工单随订单关闭自动取消 | — |
| MFG-WO-R03 | 已有报工的工单不能取消；取消未报工的工单后数量回到“未派” | `工单已有报工，不能取消` |
| MFG-WO-R04 | 工单合格 + 不良 + 报废 ≥ 派工数量时自动完成；也可手工完成（剩余不再生产） | — |

## 5. 接口

`GET /production/work-orders/dispatchable?deptId=&date=`、`POST /production/work-orders/batch`（派工）、`/production/work-orders`（列表、详情、取消、完成、打印）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| MFG-WO-T01 | 工序未派 600 | 派白班 300、夜班 300 | 生成 2 张工单，未派 0 |
| MFG-WO-T02 | 未派 600 | 派 700 | 提示派工数量超过可派数量 |
| MFG-WO-T03 | SMT1 日产能 17h，已派 16h | 再派 2h 的量 | 显示产能超出提示，可继续 |

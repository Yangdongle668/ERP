# 09-01 生产订单

## 1. 功能说明

生产订单回答“生产什么、生产多少、何时完工、用什么料、走哪些工序”。它是领料、报工、完工入库的依据，也是成本归集对象。

- 使用者：计划员（创建、下达）、生产主管（下达、暂停、关闭）
- 优先级：P0

### 1.1 订单类型

| 类型 | 编码 | 来源 | 说明 |
|---|---|---|---|
| 标准 | NORMAL | MRP、手工 | 按 BOM 领料生产 |
| 样品 | SAMPLE | 研发工程·样品单 | 同标准，完工后回写样品单 |
| 返工 | REWORK | 手工（不良品、退货品返工） | 投入物料 = 产品本身（从不良品仓/退货仓领出）+ 可选补充料；产出同一产品 |
| 拆解 | DISASSEMBLY | 手工（P1） | 投入产品，产出其 BOM 子件（逆向），子件以“生产退料入库”形式入库 |

### mfg_prod_order_material 用料清单（下达时由 BOM 多级展开一层生成，虚拟件透过）

## 3. 页面

### 3.1 生产订单列表（T1）

查询：单号、产品、类型、状态（默认已计划、已下达、生产中、暂停）、车间、计划开工（范围）、销售订单号、计划员。
列：单号（链接）、类型、产品编码、名称、规格、计划数量、完工数量、入库数量、完工进度（进度条）、计划开工、计划完工（逾期未完工红色）、车间、优先级、销售订单号、状态（草稿灰、已计划蓝 plain、已下达蓝、生产中蓝、暂停橙、已完工绿、已关闭灰）、操作。
工具栏：[新建]、[批量下达]、[齐套检查]（勾选订单 → 跳转 PMC 缺料分析）、[导出]、[批量打印流程卡]。

### 3.2 编辑页（T4）

**单头**

| 字段 | 控件 | 必填 | 默认 | 可编辑 | 校验 |

| 批次号 | 输入框 | 是 | 订单号 | 草稿 | |
| 备注 | 文本域 | 否 | | | |

**用料预览**（草稿时根据 BOM 实时展开，只读；下达后变为实际用料清单并可调整，见 3.3）：子件、单位用量、损耗、应领、发料方式、可用库存（不足红色）。

**工序预览**：工序号、工序、工作中心、标准工时、报工点、检验点。

返工订单：没有 BOM，用料清单默认一行“产品本身 × 1”，并可增加补充料。

页头：[保存] [提交]（手工新建订单按审批流；来自 MRP 的订单保存后即为“已计划”）。

## 4. 状态与流转

| 当前 | 动作 | 条件 | 结果 | 副作用 |
|---|---|---|---|---|
| 草稿 | 提交 | R01、R02 | 已计划（审批流通过后） | |
| 已计划 | 下达 | R03、R04 | 已下达 | 固化用料和工序快照；发布 `ProductionOrderReleasedEvent`（PMC 在制、分配量） |
| 已下达 | 撤销下达 | 无领料、无报工 | 已计划 | 删除快照 |
| 已下达 | 首次领料确认或首次报工 | | 生产中 | 记录实际开工 |
| 已下达/生产中 | 暂停 | 原因 | 暂停 | 暂停期间不能领料、报工 |
| 暂停 | 恢复 | | 恢复到暂停前状态 | |

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| MFG-MO-R01 | 保存 | 产品为启用的自制件；标准/样品订单必须有已审核 BOM | `产品「{code}」没有已审核的 BOM` |
| MFG-MO-R02 | 保存 | 计划完工 ≥ 计划开工 | `计划完工日期不能早于开工日期` |
| MFG-MO-R03 | 下达 | 齐套检查（参数）：按用料清单与可用库存（扣除其他已下达订单的未领需求，按下达先后分配）计算缺料；WARN 时列出缺料确认后下达，BLOCK 时阻止 | `以下物料不齐套：{list}` |
| MFG-MO-R04 | 下达 | BOM 展开时虚拟件透过；替代料不自动使用（需要时手工替代）；应领数量按子件单位精度向上取整 | — |
| MFG-MO-R05 | 调整用料 | 应领数量不能小于已领 − 已退；删除行要求已领 = 0；每次调整记录原因（操作日志） | `应领数量不能小于已领数量` |
| MFG-MO-R06 | 修改数量 | 已下达后修改计划数量需通过“调整用料 + 修改数量”操作（数量只能 ≥ 已完工数量），用料应领按比例重算（不低于已领） | `计划数量不能小于已完工数量` |
| MFG-MO-R07 | ECN | 监听 `EcnEffectiveEvent`：对 ECN 中处理方式为“更新用料”的在制订单，替换未领部分的用料并记录日志；已领的旧料按 ECN 处理方式退料 | — |
| MFG-MO-R08 | 关闭 | 原因必填（正常完工除外）；存在未确认的领料/退料/入库单据时不能关闭；按参数检查余料（已领 − 已退 − 理论耗用(合格+报废) × 单位用量 > 0 时提示退料）；未报工的在制数量按报废处理需确认 | `还有未完成的领料/退料/入库单据` / `还有余料未退回：{list}` |
| MFG-MO-R09 | MRP 生成 | `createFromMrp`：状态直接为“已计划”；按计划员合并；记录来源建议 | — |
| MFG-MO-R10 | 样品 | `createSampleOrder` 生成类型 SAMPLE 的已计划订单；完工入库确认后发布 `ProductionOrderCompletedEvent`，样品单监听 | — |

# 09-05 完工入库

## 1. 功能说明

生产订单末道工序的合格品申请入库：需要 FQC 的产品入**待检仓**，由品质检验后调拨到半成品仓/成品仓（不合格调拨到不良品仓）；不需要 FQC 的直接入半成品仓/成品仓。

- 使用者：班组长（申请）、仓管员（确认入库）、品质（FQC）
- 优先级：P0

## 2. 数据表

### mfg_finish 完工入库申请（BaseDocDO，编码规则 MFG_FINISH）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| prod_order_id | id | 是 | |
| material_id | id | 是 | 产品 |
| qty | qty | 是 | 申请入库数量（基本单位） |
| batch_no | str(64) | 是 | 默认生产订单批次号 |
| fqc_required | bool | 是 | 取物料“完工检验”属性 |
| warehouse_id | id | 是 | 需检：待检仓；否则：物料默认仓（半成品/成品仓） |
| serial_nos | text | 条件 | 序列号管理产品必填 |
| stock_in_id | id | 否 | 生成的入库单 |
| stocked_qty | qty | 是 | 入库确认回写 |
| qualified_qty / rejected_qty | qty | 是 | FQC 判定回写（免检：qualified = stocked） |
| finish_status | enum(SUBMITTED/STOCKED/JUDGED/CANCELED) | 是 | 已提交 / 已入库 / 已判定 / 已取消 |

## 3. 页面

- **生产订单详情 [完工入库]**：弹窗显示可申请数量（= completed_qty − finished_request_qty），输入本次数量*（默认全部）、批次号、序列号（按需）、备注 → 提交生成仓库入库单（`PRODUCTION_IN`）。
- **完工入库记录（T1）** 路由 `/production/finish`：查询生产订单、产品、状态、日期；列：申请号、生产订单、产品、数量、批次、入库仓、入库单号、已入库、FQC 结果（合格/不合格数）、状态、申请人、日期、操作（取消——入库单未确认时）。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| MFG-FN-R01 | 提交 | 本次数量 ≤ completed_qty − finished_request_qty | `可申请入库数量为 {qty}` |
| MFG-FN-R02 | 提交 | 生成入库单；参数 `inv.in.auto-confirm-source` 打开时自动确认 | — |
| MFG-FN-R03 | 入库确认 | 回写 stocked_qty 和生产订单 stocked_qty；免检：qualified_qty = stocked_qty，订单 qualified_stocked_qty 增加 | — |
| MFG-FN-R04 | FQC 判定 | 监听 `InspectionJudgedEvent`（FQC，来源为本申请的入库）：回写合格/不合格；订单 qualified_stocked_qty += 合格；不合格数量在生产订单上显示为“FQC 不良”，可建返工订单 | — |
| MFG-FN-R05 | 取消 | 入库单未确认时取消（作废入库单），finished_request_qty 扣回 | `入库单已确认，不能取消` |
| MFG-FN-R06 | 完工判断 | 订单 qualified_stocked_qty + scrapped_qty ≥ 计划数量时订单变为已完工 | — |

## 5. 接口

`POST /production/prod-orders/{id}/finish`、`GET /production/finishes`、`POST /production/finishes/{id}/cancel`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| MFG-FN-T01 | FG1 需 FQC，完工 90 | 申请入库 90 | 生成入库单到待检仓 |
| MFG-FN-T02 | 仓库确认 | — | 品质生成 FQC 检验单 |
| MFG-FN-T03 | FQC 合格 88、不合格 2 | — | 检验调拨 88 → 成品仓、2 → 不良品仓；订单合格入库 88 |
| MFG-FN-T04 | 已申请 90 | 再申请 1 | 提示“可申请入库数量为 0” |
| MFG-FN-T05 | 半成品免检 | 申请入库 | 入半成品仓，确认后直接合格 |

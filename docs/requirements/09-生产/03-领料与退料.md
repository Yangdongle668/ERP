# 09-03 领料与退料

## 1. 功能说明

- **领料单**：班组长按生产订单用料申请领料（按套数或按行），提交后生成仓库“生产领料出库单”，仓管员按批次发料确认；实发数量回写用料清单。
- **超领单**：超过应领数量的补料，需要审批。
- **倒冲**：发料方式为“倒冲”的物料不申请领料，报工审核时自动扣料。
- **退料单**：多领的良品余料、生产中发现的来料不良，退回仓库。

- 使用者：班组长、生产主管、仓管员
- 优先级：P0

## 2. 数据表

### mfg_issue 领料单（BaseDocDO，编码规则 MFG_ISSUE）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| issue_type | enum(NORMAL/OVER/BACKFLUSH) | 是 | 正常领料 / 超领 / 倒冲（系统生成） |
| prod_order_id | id | 是 | 一张领料单对应一个生产订单 |
| warehouse_id | id | 是 | 发料仓（默认按用料的物料默认仓；多仓物料拆单） |
| kit_qty | qty | 否 | 按套领料的套数 |
| over_reason | dict(mfg_over_issue_reason) | 条件 | 超领必填 |
| over_remark | str(256) | 否 | |
| stock_out_id | id | 否 | 生成的出库单 |

状态：草稿 → （超领：待审批）→ 已提交（已生成出库单，待发料）→ 已完成（出库确认）；已提交且出库单未确认可撤回。

### mfg_issue_line

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| material_line_id | id | 是 | 生产订单用料行 |
| material_id | id | 是 | |
| request_qty | qty | 是 | 申请数量（基本单位） |
| issued_qty | qty | 是 | 实发（出库确认回写） |

### mfg_return 退料单（BaseDocDO，编码规则 MFG_RETURN）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| prod_order_id | id | 是 | |
| return_type | enum(GOOD/DEFECT) | 是 | 良品退料（余料）/ 不良退料（来料不良、制程损坏） |
| warehouse_id | id | 是 | 良品：物料默认仓；不良：不良品仓 |
| stock_in_id | id | 否 | |

### mfg_return_line

`material_line_id`*、`material_id`*、`qty`*（基本单位）、`batch_no`（退回批次，默认原发料批次）、`defect_desc`（不良退料必填：不良描述）、`received_qty`（入库确认回写）。

## 3. 页面

### 3.1 领料单列表（T1）

查询：单号、生产订单、类型、状态（默认草稿、待审批、已提交）、发料仓、物料、日期。列：单号、类型、生产订单、产品、发料仓、行数、状态、出库单号、申请人、日期、操作。
工具栏：[新建领料]（选择生产订单）、[批量领料]（勾选多张生产订单按套数生成领料单）。

### 3.2 新建领料（T4）

单头：生产订单*（已下达/生产中）、领料方式（单选：按套数 / 按行）、套数（按套数时：申请数量 = min(套数 × 单位用量 × (1+损耗), 未领数量)）、备注。
明细（从用料清单带出发料方式为“领料”且未领 > 0 的行）：子件、应领、已领、未领、可用库存（发料仓）、申请数量*（默认未领）、备注。

提交后按发料仓拆分生成仓库出库单（`PRODUCTION_ISSUE`），状态“已提交”。

### 3.3 超领单

从生产订单“用料”页签的行操作 [超领]，或领料单列表 [新建超领]：选择用料行、超领数量*、超领原因*、说明；提交按审批流（MFG_ISSUE_OVER，条件：超领比例、金额），审批通过后生成出库单。

### 3.4 退料单（T1 / T4）

新建：生产订单*、退料类型*、退入仓库（按类型默认）、明细（用料行、可退数量 = 已领 − 已退 − 理论耗用（可为负时取 0，良品退料可退数量以已领 − 已退为上限）、退料数量*、批次、不良描述）。提交后生成仓库入库单（`PRODUCTION_RETURN`）。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| MFG-ISS-R01 | 提交 | 生产订单为已下达/生产中（未暂停）；申请数量 ≤ 未领 × (1 + 参数超领比例)，超出需超领单 | `物料「{code}」申请数量超过未领数量 {qty}，请走超领` |
| MFG-ISS-R02 | 提交 | 发料方式为倒冲的物料不能申请领料（除非超领） | `物料「{code}」为倒冲物料，不需要领料` |
| MFG-ISS-R03 | 出库确认 | 监听 `StockOutConfirmedEvent`：回写 issued_qty、用料行 issued_qty（超领同时记 over_issued_qty），并写生产追溯（批次）；首次领料时订单进入生产中 | — |
| MFG-ISS-R04 | 实发少于申请 | 出库确认后领料单完成；未发部分仍体现为用料行“未领”，可再申请 | — |
| MFG-ISS-R05 | 倒冲 | 报工审核时：对该工序（或无工序时末道工序）的倒冲用料，扣料数量 = (合格 + 报废) × 单位用量 × (1 + 损耗)，生成 BACKFLUSH 领料单和出库单（从物料默认仓，自动确认，按 FIFO 分配批次）；库存不足时报工审核失败并提示缺料 | `倒冲物料「{code}」库存不足，需要 {need}，可用 {have}` |
| MFG-ISS-R06 | 报工反审核 | 倒冲出库单反确认并作废对应倒冲领料单 | — |
| MFG-RET-R01 | 提交 | 退料数量 ≤ 可退数量；不良退料必须填写不良描述 | `物料「{code}」退料数量超过可退数量 {qty}` |
| MFG-RET-R02 | 入库确认 | 回写 received_qty、用料行 returned_qty；不良退料发布 `DefectMaterialReturnedEvent`（品质可据此开 NCR，追溯供应商） | — |

## 5. 接口

`/production/issues`（CRUD、submit、withdraw、print-data）、`POST /production/issues/by-kit`（按套数生成）、`POST /production/issues/over`（超领）、`/production/returns`（CRUD、submit、print-data）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| MFG-ISS-T01 | 订单 100，PCBA×1、螺丝×4（2%） | 按套数 50 领料 | PCBA 50、螺丝 204 |
| MFG-ISS-T02 | 仓库实发螺丝 200 | 出库确认 | 用料螺丝已领 200、未领 208 |
| MFG-ISS-T03 | 螺丝已领 408 | 再申请 10 | 提示走超领；超领单审批通过后发料 |
| MFG-ISS-T04 | 胶水为倒冲，单耗 0.5g | 报工合格 90、报废 2 | 自动生成倒冲出库 46g |
| MFG-ISS-T05 | 倒冲库存不足 | 报工审核 | 提示倒冲物料库存不足，报工未审核 |
| MFG-RET-T01 | PCBA 已领 100，合格 90、报废 5 | 良品退料 5 | 入库确认后用料 PCBA 已退 5 |
| MFG-RET-T02 | 发现来料不良 3 个 | 不良退料到不良品仓 | 品质收到事件，可开 NCR 追溯到供应商批次 |

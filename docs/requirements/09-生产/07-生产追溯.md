# 09-07 生产追溯

## 1. 功能说明

记录“成品/半成品批次 ← 投入的原材料批次”的关系，支持：

- **反向追溯**：某个成品批次用了哪些原材料批次、来自哪些供应商（客诉分析）；
- **正向追溯**：某个原材料批次被用在哪些生产订单、哪些成品批次、出货给了哪些客户（召回范围）。

- 使用者：品质、生产主管、业务
- 优先级：P1（数据在一期就开始记录，查询页面 P1）

## 2. 数据表

### mfg_trace 追溯关系（只增不改）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | |
| prod_order_id | id | |
| product_material_id | id | 产品 |
| product_batch_no | str(64) | 产品批次（= 生产订单批次号） |
| component_material_id | id | 投入物料 |
| component_batch_no | str(64) | 投入批次（不管理批次的物料为空） |
| qty | qty | 投入数量（领料为正，退料为负） |
| source_doc_type / source_doc_no | | 领料出库单、倒冲出库单、退料入库单 |
| created_at | datetime | |

索引：`idx_product(product_material_id, product_batch_no)`、`idx_component(component_material_id, component_batch_no)`。按月分区。

写入时机：生产领料出库确认、倒冲出库确认（+），生产退料入库确认（−），均在监听事件中与回写同一事务写入。

## 3. 页面：追溯查询（专用）

路由 `/production/trace`。

```
┌ 追溯方向：(●) 反向：成品批次 → 原材料   ( ) 正向：原材料批次 → 成品/客户 ┐
│ 物料 [FG00001 ▾]  批次 [MO-202609-0012]  [查询]                          │
├─────────────────────────────────────────────────────────────────────────┤
│ ▾ FG00001 控制板  批次 MO-202609-0012  （生产订单 MO-202609-0012，完工 88）   │
│   ▾ SF00003 PCBA  批次 MO-202609-0009（半成品，继续展开）                      │
│       ELEC00012 电阻  批次 B260901003  1,000  供应商 V1  到货 RC-…  IQC 合格   │
│       FPC00001 排线   批次 B260905001  100    供应商 V2  到货 RC-…  IQC 特采   │
│     SCREW 螺丝   —   408                                                    │
└─────────────────────────────────────────────────────────────────────────┘
```

- 反向：多级展开（半成品批次继续追溯到其生产订单的投入），每个原材料批次显示供应商、到货单、IQC 结果（链接品质检验单）、特采标记。
- 正向：原材料批次 → 生产订单 → 产品批次 → （多级向上）→ 成品批次 → 出货单 → 客户（调用出货模块按批次查询出货记录）；顶部汇总：涉及生产订单 N 张、成品批次 N 个、已出货客户 N 家、出货数量。
- 结果可导出 Excel（召回清单）。

## 4. 业务规则

| 编号 | 规则 |
|---|---|
| MFG-TRC-R01 | 追溯层级最多 10 层，防止数据异常死循环 |
| MFG-TRC-R02 | 不管理批次的物料只显示数量，不能继续正向追溯（页面提示“该物料未启用批次管理，无法精确追溯”） |
| MFG-TRC-R03 | 查询受数据权限约束：需要 `mfg:trace:query`；供应商、客户信息按用户对 CRM/资材的查看权限决定是否显示名称 |

## 5. 接口

`GET /production/trace/backward?materialId=&batchNo=&levels=`、`GET /production/trace/forward?materialId=&batchNo=&levels=`、`/export`；Java `TraceApi.forward/backward`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| MFG-TRC-T01 | FG1 批次 MO-12 领用了电阻批次 B1、B2 | 反向追溯 MO-12 | 显示 B1、B2 及供应商、IQC 结果 |
| MFG-TRC-T02 | 电阻 B1 用于 MO-9（PCBA），PCBA 用于 MO-12（FG1），FG1 出货给 ABC | 正向追溯 B1 | 显示 MO-9 → MO-12 → 出货单 → ABC |
| MFG-TRC-T03 | 退料 B2 10 个 | 反向追溯 | B2 数量为领料 − 退料 |

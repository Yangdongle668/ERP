# 09-06 不良与良率

## 1. 功能说明

- **不良登记**：报工时登记不良明细（不良代码、数量、描述、位置），并对“待处理不良”做处置：返修（修好后转合格）或报废；严重或批量不良可一键生成品质 NCR。
- **良率统计**：工序良率、直通率（FPY）、不良 Pareto。

- 使用者：班组长、生产主管、QE
- 优先级：不良登记 P0；良率报表 P1

## 3. 页面

### 3.1 不良记录（T1）

路由 `/production/defect`。查询：生产订单、产品、工序、不良代码、处置状态（默认待处理）、日期。
列：日期、生产订单、产品、工序、不良代码、数量、位置、描述、照片（缩略图）、处置状态、已返修、已报废、NCR 号、操作。
行操作：
- [返修完成]：输入返修合格数量（≤ 待处理数量）→ 这些数量作为本工序的合格数补报（生成一张合格数 = 返修数、不良数 0 的补充报工单，备注“返修”），状态更新。
- [报废]：输入数量、报废原因 → 本工序报废数增加（生成补充报工单：报废数）。
- [生成 NCR]（`mfg:defect:to-ncr`）：调用品质模块创建 NCR（来源：制程，带生产订单、产品、不良代码、数量、照片）。

### 3.2 良率报表（T7）

路由 `/production/yield`。
查询：日期范围（默认本月）、车间、产品、工序、维度（按产品 / 工序 / 工作中心 / 班组 / 日期）。
指标：
- 工序良率 = 合格 ÷ (合格 + 不良 + 报废)（按一次报工口径，返修合格不计入分子）
- 直通率 FPY = Π 各报工点一次良率
- 不良率、报废率
图表：良率趋势折线（按日）、不良代码 Pareto 图（柱状 + 累计百分比折线）、工序良率对比柱状图。
明细表：维度值、投入、合格、不良、报废、返修合格、一次良率、最终良率。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| MFG-DEF-R01 | 报工时不良明细数量合计 = 报工不良数 | `不良明细合计 {sum} 与不良数 {qty} 不一致` |
| MFG-DEF-R02 | 返修 + 报废 ≤ 不良数量；全部处置后状态为已返修/已报废（混合时以数量多者显示，并显示两项数量） | `处置数量超过待处理数量` |
| MFG-DEF-R03 | 返修补报和报废补报受报工规则约束（工序累计不超过上道合格） | 同报工 |
| MFG-DEF-R04 | 生产订单关闭时仍有待处理不良，提示处理（视为报废需确认） | `还有 {qty} 待处理不良` |
| MFG-DEF-R05 | 同一产品同一不良代码当天累计 ≥ 参数阈值（品质模块参数）时，工作台提醒 QE | — |

## 5. 接口

`GET /production/defects`、`POST /production/defects/{id}/repair`、`/{id}/scrap`、`/{id}/to-ncr`、`GET /production/reports/yield`（报表，含 export）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |

| MFG-DEF-T01 | 报工不良 5，登记短路 3、虚焊 2 | 保存 | 生成 2 条不良记录 |
| MFG-DEF-T02 | 待处理 5 | 返修完成 4、报废 1 | 工序合格 +4、报废 +1 |
| MFG-DEF-T03 | 工序 1 合格 95/投入 100，工序 2 合格 90/投入 95 | 良率报表 | 工序 1 一次良率 95%，工序 2 94.74%，FPY 90% |
| MFG-DEF-T04 | — | 生成 NCR | 品质模块出现制程 NCR，带照片 |

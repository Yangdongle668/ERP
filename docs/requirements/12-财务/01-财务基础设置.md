# 12-01 财务基础设置

## 1. 功能说明

会计科目、会计期间、银行账户、科目映射规则（业务类型 → 借贷科目）。

- 使用者：财务主管
- 优先级：P0（科目映射在启用凭证时必需）

## 2. 数据表

### fin_account 会计科目

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| code | str(32) | 是 | 科目编码，唯一，按级次编码（4-2-2，如 1122、112201） |
| name | str(64) | 是 | |
| parent_code | str(32) | 否 | |
| account_type | enum(ASSET/LIABILITY/EQUITY/COST/PROFIT_LOSS) | 是 | 资产 / 负债 / 权益 / 成本 / 损益 |
| direction | enum(DEBIT/CREDIT) | 是 | 余额方向 |
| aux_types | str(64) | 否 | 辅助核算：CUSTOMER、SUPPLIER、DEPT、MATERIAL、PROJECT（多个） |
| currency_accounting | bool | 是 | 外币核算 |
| is_leaf | bool | 是 | 末级科目才能用于凭证 |
| status | enum(ENABLED/DISABLED) | 是 | |

初始数据：按《企业会计准则》常用一级科目（1001 库存现金、1002 银行存款、1122 应收账款、1123 预付账款、1221 其他应收款、1403 原材料、1405 库存商品、1411 周转材料、2202 应付账款、2203 预收账款、2221 应交税费（222101 应交增值税）、5001 生产成本（500101 直接材料、500102 直接人工、500103 制造费用）、5101 制造费用、6001 主营业务收入、6401 主营业务成本、6603 财务费用（660301 汇兑损益）等）。

### fin_period 会计期间

`period`（yyyyMM，唯一）、`start_date`、`end_date`、`period_status`（NOT_OPEN / OPEN / CLOSED）、`closed_by`、`closed_at`。启用期间与仓库启用期间相同。

### fin_bank_account 银行账户（本公司）

`code`*、`name`*（如“中行美元户”）、`bank_name`*、`account_no`*、`currency`*、`swift`、`bank_address`、`account_code`（对应会计科目，如 100201）、`is_default`（同币别默认）、`status`。

### fin_account_mapping 科目映射

| 字段 | 类型 | 说明 |
|---|---|---|
| biz_type | enum | 业务类型：SALES_AR（出货应收）、SALES_RETURN_AR、RECEIPT、PURCHASE_AP、PAYMENT、STOCK_IN_PURCHASE、STOCK_OUT_SALES_COST、PRODUCTION_ISSUE、PRODUCTION_IN、FX_GAIN_LOSS 等 |
| condition | json | 条件（如币别、物料类别、客户是否外销），为空表示默认 |
| priority | int | 条件匹配优先级 |
| entries | json | 分录模板：`[{direction, accountCode, amountField(如 amount/tax/totalAmount/cost), summaryTemplate, auxFrom}]` |

## 3. 页面

路由 `/finance/setting`，四个页签：

- **会计科目**（T6 树形表格）：编码、名称、类型、方向、辅助核算、外币、末级、状态；新增下级、编辑、停用。
- **会计期间**：年度列表，[初始化年度]（生成 12 个期间）、期间状态（结账在月结页面）。
- **银行账户**（T1 + T2）。
- **科目映射**（T1 + 编辑弹窗）：业务类型、条件描述、分录（借/贷、科目、金额取值、摘要模板）；[测试]：选择一张业务单据预览生成的凭证。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| FIN-SET-R01 | 科目编码唯一；下级编码以上级编码开头；已有凭证的科目不能删除、不能新增下级（需先转移） | `科目已使用，不能新增下级` |
| FIN-SET-R02 | 科目映射引用的科目必须是启用的末级科目 | `科目「{code}」不是末级科目` |
| FIN-SET-R03 | 同一业务类型只能有一条无条件的默认映射 | — |

## 5. 接口

`/finance/accounts`（树、CRUD）、`/finance/periods`（列表、init-year）、`/finance/bank-accounts`（CRUD、simple）、`/finance/account-mappings`（CRUD、preview）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| FIN-SET-T01 | — | 在 1002 下新增 100201 中行美元户（外币核算） | 成功 |
| FIN-SET-T02 | 映射 SALES_AR：借 1122 / 贷 6001（不含税）/ 贷 222101（税额） | 测试一张出货应收 | 预览凭证借贷平衡 |

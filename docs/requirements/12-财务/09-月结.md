# 12-09 月结

## 1. 功能说明

财务期末处理与结账：检查 → 外币期末重估（汇兑损益）→ 成本计算锁定 → 生成期末凭证 → 结账。结账后该期间所有财务单据、凭证、核销不能修改。

- 使用者：财务主管
- 优先级：P1

## 2. 结账顺序（全系统）

```
1. 仓库月结（08-仓库/09）→ 2. 成本计算并锁定（07）→ 3. 外币重估 → 4. 生成并过账期末凭证 → 5. 财务结账
```

## 3. 数据表

### fin_fx_revaluation 外币重估

`period`、`doc_type`（AR/AP/BANK）、`doc_id`、`currency`、`fc_balance`（原币余额）、`book_base`（账面本位币）、`period_end_rate`（月末汇率）、`revalued_base`、`diff`、`voucher_id`。下月初自动冲回（参数，默认冲回）。

## 4. 页面（专用）

路由 `/finance/close`。

**期间列表**：期间、状态（未开/已开/已结账）、结账人、时间、操作（结账向导、反结账）。

**结账向导**（步骤条）：

| 步骤 | 内容 | 通过条件 |
|---|---|---|
| 1. 检查 | 库存本期已月结；成本已锁定；无草稿应收/应付/收款/付款（列出，可跳转处理）；所有凭证已过账（启用凭证时）；进项发票差异已确认 | 阻止项全部通过 |
| 2. 外币重估 | 显示外币应收、应付、银行存款余额，月末汇率（取系统月末汇率 MONTH_END，缺失时提示先维护）→ 计算差异 → [生成重估凭证] | 已生成（无外币余额时跳过） |
| 3. 期末凭证 | 批量生成未生成凭证的业务单据（成本结转、汇兑损益）→ 审核过账 | 全部过账 |
| 4. 结账 | 确认 → 期间 CLOSED，下期 OPEN；发布 `FinPeriodClosedEvent` | — |

**反结账**：只能反结账最近一个已结账期间；需要 `fin:close:reopen`；反结账后成本解锁可重算；原因必填并记录日志。

## 5. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| FIN-CLS-R01 | 必须按期间顺序结账 | `请先结账 {period}` |
| FIN-CLS-R02 | 月末汇率缺失时不能重估 | `请先维护 {currency} {period} 的月末汇率` |
| FIN-CLS-R03 | 已结账期间：财务单据确认/反确认、核销/反核销、凭证操作全部阻止；仓库反结账该期间被阻止 | `会计期间 {period} 已结账` |
| FIN-CLS-R04 | 重估差异 = 原币余额 × 月末汇率 − 账面本位币；下月 1 日自动生成冲回凭证（参数） | — |

## 6. 接口

`GET /finance/close/periods`、`GET /finance/close/{period}/check`、`POST /finance/close/{period}/fx-revaluation`、`POST /finance/close/{period}/close`、`POST /finance/close/{period}/reopen`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| FIN-CLS-T01 | 成本未锁定 | 结账检查 | 显示阻止项“成本未锁定” |
| FIN-CLS-T02 | 应收 1,000 USD 账面 7,120，月末汇率 7.15 | 外币重估 | 差异 +30.00，生成凭证 |
| FIN-CLS-T03 | 9 月已结账 | 确认 9 月的应收单 | 提示会计期间已结账 |
| FIN-CLS-T04 | 9 月已结账 | 仓库反结账 9 月 | 提示财务期间已结账，请先由财务反结账 |

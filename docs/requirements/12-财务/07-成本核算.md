# 12-07 成本核算

## 1. 功能说明

月末（库存月结后）按**月加权平均法**计算材料出库成本；按生产订单归集直接材料，并按工时（或其他依据）分配人工和制造费用；计算完工产品单位成本，回填生产入库和销售出库成本；输出产品成本表和成本差异。

- 使用者：成本会计
- 优先级：P1

## 2. 计算步骤

```mermaid
flowchart TD
  A[库存月结完成 PeriodClosedEvent] --> B[录入本期人工费用、制造费用总额（按车间）]
  B --> C[按低位码从下往上逐层计算]
  C --> D[采购件：月加权平均单价 = (期初金额 + 本期采购入库金额) ÷ (期初数量 + 本期采购入库数量)]
  D --> E[领料成本 = 领料数量 × 该物料加权单价，归集到生产订单]
  E --> F[人工/制费按车间费用 × 订单工时占比 分配到订单]
  F --> G[订单总成本 = 期初在制 + 本期材料 + 人工 + 制费]
  G --> H[完工与在制分配：在制只留材料 或 约当产量法]
  H --> I[完工单位成本 → 回填生产入库流水单价 → 该自制件的加权平均单价]
  I --> J[上层物料领用本自制件时使用该单价，继续上一层]
  J --> K[所有物料加权单价确定后 → 回填全部出库流水成本（销售、其他出库、盘亏等）]
  K --> L[期末结存金额 → inv_period_balance；发布 CostCalculatedEvent]
```

### 2.1 关键口径

| 项 | 规则 |
|---|---|
| 加权单价 | 按“物料”全公司统一（不分仓库）；本期无入库时沿用期初单价；期初和本期都为 0 数量时取标准成本 |
| 入库金额来源 | 采购入库（流水单价）、委外入库（材料成本 + 加工费）、生产入库（本次计算结果）、其他入库/盘盈（流水单价）、退料入库（按领料时的加权单价，冲减订单材料成本） |
| 调拨 | 不影响加权单价 |
| 销售退货入库 | 按原出库成本（原出库期间的加权单价），不参与本期加权 |
| 人工、制费 | 成本会计按车间录入本期总额（或从凭证中取 5101 制造费用、应付职工薪酬科目发生额，P2）；按参数的分配依据分到本期有报工的订单 |
| 在制品 | MATERIAL_ONLY：期末在制只保留材料成本（已领未耗用的材料 + 未完工部分的材料），人工制费全部由完工产品承担；EQUIVALENT：按完工程度（默认 50%）计算约当产量分配 |
| 报废 | 生产报废成本计入合格品成本（正常损耗） |
| 返工订单 | 返工成本（补充料 + 人工制费）加到产品上，产品本身的成本从领用（不良品仓出库）转入 |

## 3. 数据表

| 表 | 内容 |
|---|---|
| fin_cost_run | 计算记录：期间、状态（RUNNING/SUCCESS/FAILED/LOCKED）、开始/结束时间、操作人、错误信息 |
| fin_cost_expense | 本期费用录入：期间、车间、人工总额、制费总额 |
| fin_cost_material | 物料加权结果：期间、物料、期初数量/金额、本期入库数量/金额、加权单价、本期出库数量/金额、期末数量/金额 |
| fin_cost_order | 订单成本：期间、生产订单、期初在制、本期材料、人工、制费、完工数量、完工成本、期末在制、单位成本 |
| fin_cost_order_material | 订单材料明细：物料、领用数量、退料数量、单价、金额 |

## 4. 页面

### 4.1 成本计算（专用）

路由 `/finance/cost`。

1. 选择期间（只能是库存已结账、财务未结账的期间），显示状态检查：库存已月结 ✓ / 未完成的生产订单数（在制）/ 本期费用是否已录入。
2. **费用录入**：按车间录入人工、制费总额（表格）。
3. [开始计算]：后台任务执行，进度显示；完成后显示结果摘要（物料数、订单数、总成本、异常）。
4. **异常清单**：负数结存、单价异常波动（与上期相比 ±30% 以上）、无单价出库（数量有而金额为 0）、订单无工时却有费用分配等，逐条列出供检查。
5. [锁定]（`fin:cost:lock`）：锁定后不能再计算（月结前必须锁定）；解锁需要先反结账。

计算可以重复执行（覆盖本期结果），直到锁定。

### 4.2 产品成本表（T7）

查询：期间、产品、类别。列：产品、完工数量、单位成本、其中材料/人工/制费、标准成本、差异、差异率。可下钻到订单成本和材料明细。

### 4.3 物料单价表（T7）

期间物料加权结果（期初、入库、出库、期末的数量和金额，加权单价）。

## 5. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| FIN-CST-R01 | 库存期间未结账不能计算 | `库存期间 {period} 尚未月结` |
| FIN-CST-R02 | 同一期间同时只能有一个计算 | `成本计算正在进行中` |
| FIN-CST-R03 | 计算失败回滚本次全部结果，保留上次成功结果 | — |
| FIN-CST-R04 | 回填流水成本时只更新该期间的流水，写入 unit_cost 与 amount | — |
| FIN-CST-R05 | 锁定后发布 `CostCalculatedEvent(period)`（BI 更新毛利） | — |

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| FIN-CST-T01 | 螺丝期初 1000×0.10，本期采购 3000×0.12 | 计算 | 加权单价 0.115 |
| FIN-CST-T02 | MO-12 领螺丝 400、PCBA 100（单价 20）；人工 1000、制费 500 全部分给 MO-12；完工 100 | 计算 | 完工成本 = 46 + 2000 + 1500 = 3,546；单位 35.46 |
| FIN-CST-T03 | FG1 本期销售出库 60 | 计算 | 销售出库流水单价回填为 FG1 加权单价 |
| FIN-CST-T04 | 库存未月结 | 计算 | 提示库存期间尚未月结 |

# 12-08 利润与报表

路由 `/finance/report`（多页签），权限 `fin:report:query`。

## 1. 报表清单

| 报表 | 优先级 | 说明 |
|---|---|---|
| 应收账龄表 | P0 | 按客户：未核销余额按到期日分段：未到期、逾期 1～30、31～60、61～90、91～180、>180 天；原币与本位币；下钻到应收单 |
| 应付账龄表 | P0 | 同上，按供应商 |
| 客户往来对账单 | P0 | 选择客户和期间：期初余额、本期应收（出货）、本期收款、本期核销、期末余额，逐笔明细；打印/导出（中英文）发客户对账 |
| 供应商往来对账单 | P0 | 同上 |
| 收付款日报 | P1 | 按日期、账户：收款、付款、余额变化 |
| 订单毛利表 | P1 | 已出货订单行：收入（出货不含税本位币）、成本（出库成本，成本计算后）、毛利、毛利率；按订单、客户、业务员汇总 |
| 产品毛利排名 | P1 | 按产品：销量、收入、成本、毛利、毛利率 |
| 客户毛利排名 | P1 | 按客户 |
| 月度损益简表 | P1 | 收入、销售成本、毛利、费用（取凭证科目发生额：销售费用、管理费用、财务费用）、利润；本月、本年累计、上年同期 |
| 科目余额表 / 明细账 | P1 | 启用凭证后提供：期初、借方发生、贷方发生、期末；明细账逐笔 |

成本未计算的期间，毛利类报表中成本显示“未计算”，并在顶部提示。

## 2. 规则

| 编号 | 规则 |
|---|---|
| FIN-RPT-R01 | 账龄以到期日为准；无到期日的按业务日期 + 客户信用期计算 |
| FIN-RPT-R02 | 外币余额按原币列示，本位币合计按期末汇率（未结账期间按当日汇率）折算，列头注明折算汇率 |
| FIN-RPT-R03 | 对账单期末余额 = 期初 + 本期应收 − 本期收款（含预收），与应收余额一致；不一致时标红（数据问题） |

## 3. 接口

`GET /finance/reports/ar-aging`、`/ap-aging`、`/customer-statement`、`/supplier-statement`、`/cash-daily`、`/order-margin`、`/product-margin`、`/customer-margin`、`/profit-loss`、`/account-balance`、`/ledger`，均有 `/export`，对账单另有 `/print-data`。

## 4. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| FIN-RPT-T01 | 应收 A 到期 08-20 未收 5,000；B 到期 10-10 未收 3,000；今天 09-24 | 账龄表 | A 在逾期 31～60（35 天）；B 在未到期 |
| FIN-RPT-T02 | 9 月出货 10,000、收款 6,000，期初 2,000 | 客户对账单 | 期末 6,000 |
| FIN-RPT-T03 | 成本未计算 | 订单毛利 | 成本列显示“未计算” |

# 12-06 凭证

## 1. 功能说明

根据科目映射规则，把业务单据（应收、收款、应付、付款、出入库、成本结转、汇兑损益）生成记账凭证草稿；财务审核、过账；支持手工凭证和导出到外部总账软件。

- 使用者：会计、财务主管
- 优先级：P1

## 2. 数据表

### fin_voucher 凭证（编码规则 FIN_VOUCHER：`记-yyyyMM-4`）

| 字段 | 类型 | 说明 |

| period | str(6) | |
| voucher_date | date | |
| source | enum(AUTO/MANUAL) | |
| source_type / source_ids | | 生成来源（可多张单据汇总一张凭证） |
| attachment_count | int | 附件张数 |
| total_debit / total_credit | amt | |
| voucher_status | enum(DRAFT/AUDITED/POSTED) | 草稿 / 已审核 / 已过账 |
| auditor_id / poster_id | id | |

### fin_voucher_line 分录

`line_no`、`summary`（摘要）、`account_code`、`debit`、`credit`（本位币）、`currency`、`fc_amount`（原币）、`exchange_rate`、`aux_customer_id`、`aux_supplier_id`、`aux_dept_id`、`aux_material_id`、`aux_project_id`。

## 3. 生成规则

- **生成方式**：单张生成（单据确认时，参数 `fin.voucher.auto-generate`）或批量生成（选择期间、业务类型，“按单据生成”或“按类型汇总生成”一张凭证）。
- 每张业务单据只能生成一次凭证（单据上记录 voucher_id）；凭证删除后可重新生成。
- 金额取值：按映射模板中的金额字段（不含税金额、税额、价税合计、成本）；本位币金额按单据汇率折算。
- 成本类凭证（销售成本结转、生产领料、完工入库）在成本计算完成后生成。

常用映射（初始化提供，财务可修改）：

| 业务类型 | 借 | 贷 |
|---|---|---|
| 出货应收 SALES_AR | 1122 应收账款（客户） | 6001 主营业务收入（不含税）；222101 应交增值税-销项（税额） |
| 收款 RECEIPT | 1002 银行存款（账户科目）；660302 手续费 | 1122 应收账款（客户） |
| 采购应付 PURCHASE_AP | 1403 原材料（按物料类别映射）；222101 应交增值税-进项 | 2202 应付账款（供应商） |
| 付款 PAYMENT | 2202 应付账款；660302 手续费 | 1002 银行存款 |
| 生产领料 PRODUCTION_ISSUE | 500101 生产成本-直接材料 | 1403 原材料 |
| 完工入库 PRODUCTION_IN | 1405 库存商品 | 5001 生产成本 |
| 销售成本 STOCK_OUT_SALES_COST | 6401 主营业务成本 | 1405 库存商品 |
| 汇兑损益 FX_GAIN_LOSS | 1122/2202 或 660301 | 660301 或 1122/2202 |

## 4. 页面

### 4.1 凭证列表（T1）

查询：期间（默认本期）、凭证号、状态、来源、科目、摘要、制单人。列：凭证号、日期、摘要（第一行）、借方合计、贷方合计、附件数、来源、状态、制单人、审核人、过账人、操作。
工具栏：[新建凭证]、[生成凭证]（弹窗：期间、业务类型多选、生成方式）、[批量审核]、[批量过账]、[导出]（选择格式：通用 Excel / 金蝶 K3 / 用友 U8 模板，P1 提供通用 Excel，具体软件模板 P2）。

### 4.2 凭证编辑（T4，经典凭证样式）

```
记 字第 0012 号      日期 [2026-09-30]      附件 [2] 张
摘要              科目                        借方金额      贷方金额
出货 SH-…07 ABC   1122 应收账款/ABC Ltd       28,480.00
出货 SH-…07 ABC   6001 主营业务收入                          28,480.00
合计                                          28,480.00     28,480.00
```

- 科目选择器：编码/名称搜索，只能选末级启用科目；科目有辅助核算时弹出辅助项选择（客户/供应商/部门…）；外币科目显示原币和汇率列。
- 借贷不平衡时底部合计红色，不能保存为已审核。
- 按钮：[保存]、[审核]（不能审核自己制的凭证）、[过账]、[反过账]、[反审核]、[删除]（草稿）。

## 5. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| FIN-VCH-R01 | 借贷必须相等才能审核 | `借贷不平衡，差额 {diff}` |
| FIN-VCH-R02 | 审核人不能是制单人 | `审核人不能与制单人相同` |
| FIN-VCH-R03 | 已结账期间不能新增、修改、过账、反过账凭证 | `会计期间 {period} 已结账` |
| FIN-VCH-R04 | 凭证号在期间内连续：删除草稿凭证后可执行“整理凭证号”（按日期重排草稿与已审核凭证号，已过账的不变） | — |
| FIN-VCH-R05 | 业务单据反确认时，其凭证必须为草稿（自动删除）；已审核/过账的凭证需先反审核/反过账 | `单据的凭证已审核，请先反审核凭证` |

## 6. 接口

`/finance/vouchers`（CRUD、audit、unaudit、post、unpost、export、renumber）、`POST /finance/vouchers/generate`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| FIN-VCH-T01 | 9 月 20 张出货应收 | 批量生成（按类型汇总） | 1 张凭证：借应收（按客户辅助）/ 贷收入、销项税 |
| FIN-VCH-T02 | 借 100 贷 99 | 审核 | 提示借贷不平衡，差额 1.00 |
| FIN-VCH-T03 | 自己制的凭证 | 审核 | 提示审核人不能与制单人相同 |

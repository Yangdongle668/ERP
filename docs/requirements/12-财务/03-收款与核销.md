# 12-03 收款与核销

## 1. 功能说明

出纳登记银行收款（收款单）；应收会计把收款**核销**到应收单（或作为订单的预收款），核销后更新应收余额、销售回款计划和客户信用。外币核销产生汇兑差异。

- 使用者：出纳、应收会计
- 优先级：P0

## 2. 数据表

### fin_receipt 收款单（BaseDocDO，编码规则 FIN_RECEIPT）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| customer_id | id | 是 | |
| receipt_type | enum(SALES/ADVANCE/OTHER/REFUND) | 是 | 销售收款 / 预收款（针对订单）/ 其他收款 / 退款（负数，退给客户） |
| bank_account_id | id | 是 | 收款账户 |
| settlement_method | dict(sys_settlement_method) | 是 | |
| receipt_date | date | 是 | 到账日期 |
| currency | str(3) | 是 | 与收款账户币别一致 |
| exchange_rate | rate | 是 | 到账日汇率 |
| amount | amt | 是 | 到账金额 |
| bank_fee | amt | 是 | 银行手续费（客户付款金额 = 到账 + 手续费，手续费计入财务费用） |
| amount_base | amt | 是 | |
| bank_ref_no | str(64) | 否 | 银行流水号 |
| order_id | id | 条件 | 预收款对应的销售订单 |
| allocated_amount | amt | 是 | 已核销（原币，含手续费部分） |
| receipt_status | enum(DRAFT/CONFIRMED/VOIDED) | 是 | |
| voucher_id | id | 否 | |

**未核销金额** = amount + bank_fee − allocated_amount（客户付款金额中尚未分配的部分）。

### fin_verification 核销记录（收款与应收、付款与应付共用）

| 字段 | 类型 | 说明 |
|---|---|---|
| verify_type | enum(RECEIPT_AR/ADVANCE_AR/RED_BLUE_AR/PAYMENT_AP/PREPAY_AP/RED_BLUE_AP) | 收款-应收 / 预收冲应收 / 红蓝应收对冲 / 付款-应付 / 预付冲应付 / 红蓝应付对冲 |
| doc_a_type / doc_a_id | | 收款单/付款单/红字单 |
| doc_b_type / doc_b_id | | 应收/应付 |
| amount | amt | 核销金额（原币） |
| amount_base_a / amount_base_b | amt | 两边按各自汇率折算的本位币 |
| fx_diff | amt | 汇兑差异 = base_a − base_b（正为收益） |
| verified_at | datetime | |
| operator_id | id | |
| reversed | bool | 是否已反核销 |

## 3. 页面

### 3.1 收款单列表（T1）

查询：单号、客户、类型、收款账户、到账日期（默认本月）、状态、未核销（开关）。
列：单号、客户、类型、账户、到账日期、币别、到账金额、手续费、本位币、已核销、未核销、订单号（预收）、状态、操作。
工具栏：[新建收款]、[导入银行流水]（模板：日期、金额、币别、付款方名称、流水号 → 按付款方名称匹配客户，生成草稿收款单；无法匹配的行需手工选择客户）、[导出]。

### 3.2 收款单编辑（T4）

字段：客户*、收款类型*、收款账户*（选择后币别固定）、结算方式*、到账日期*、汇率、到账金额*、手续费、银行流水号、订单（预收款必填：该客户未完成订单）、备注、附件（水单）。
保存后 [确认]（`fin:receipt:confirm`）；确认后才能核销。

### 3.3 核销（专用）

路由 `/finance/receipt/verify?customerId=`。

```
┌ 客户 [ABC Ltd ▾]  币别 [USD]                                           [自动核销] [确认核销] ┐
├ 收款（未核销）──────────────────────────┬ 应收（未核销）─────────────────────────────────┤
│ ☑ RV-…0003 09-20 到账 3,975 手续费 25   │ ☑ AR-…0011 SH-…07 09-10 到期 09-10 4,000.00     │
│   可核销 4,000.00  本次 [4,000.00]      │   本次 [4,000.00]                               │
│ ☐ 预收 RV-…0001 订单 SO-…12 3,000.00    │ ☐ AR-…0015 09-18 到期 10-18 2,000.00             │
│ ☐ 红字 AR-…0020 −500.00                 │                                                 │
├──────────────────────────────────────┴────────────────────────────────────────────┤
│ 本次核销：收款 4,000.00 = 应收 4,000.00    汇兑差异：+ 12.00 CNY                          │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

- 左侧：该客户同币别已确认的未核销收款、预收、红字应收；右侧：未核销蓝字应收（按到期日排序）。
- 勾选并输入本次金额，两侧合计相等才能确认。
- [自动核销]：按到期日先后，把勾选的收款金额依次分配到应收（预收优先冲对应订单的应收）。
- 预收款核销到应收：只能核销该订单产生的应收（参数可放开）。

### 3.4 预收款（订单收款）

收款类型为“预收款”时，确认后立即发布 `ReceiptAllocatedEvent(orderId, amount)`（销售回款计划按节点顺序记为已收，如定金），此时还没有应收单；后续出货生成应收后，再在核销页面用该预收冲销应收（不再重复更新回款计划）。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| FIN-RV-R01 | 保存 | 币别 = 收款账户币别；汇率 > 0（本位币为 1） | `收款币别必须与收款账户币别一致` |
| FIN-RV-R02 | 核销 | 双方同客户、同币别；本次金额 ≤ 各自未核销金额；两侧合计相等 | `核销金额不平衡` |
| FIN-RV-R03 | 核销 | 汇兑差异 = 收款侧本位币（按收款汇率）− 应收侧本位币（按应收汇率），写入核销记录，月末生成汇兑损益凭证 | — |
| FIN-RV-R04 | 核销 | 核销后：更新双方已核销金额；发布 `ReceiptAllocatedEvent`（按应收单关联的订单与金额，预收冲销时不发布）、`ReceivableBalanceChangedEvent` | — |
| FIN-RV-R05 | 反核销 | 核销所在会计期间未结账；记录 reversed，反向更新并发布事件 | `会计期间已结账，不能反核销` |
| FIN-RV-R06 | 反确认 | 收款单有核销记录时不能反确认 | `收款已核销，请先反核销` |
| FIN-RV-R07 | 退款 | 退款（负数收款单）只能核销红字应收或冲减预收 | — |

## 5. 接口

`/finance/receipts`（CRUD、confirm、unconfirm、void、import-bank）、`GET /finance/verifications/candidates?customerId=&currency=`、`POST /finance/verifications/receipt`（核销）、`POST /finance/verifications/auto`、`POST /finance/verifications/{id}/reverse`、`GET /finance/verifications?docType=&docId=`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| FIN-RV-T01 | 应收 4,000 USD（汇率 7.12），到账 3,975 + 手续费 25（汇率 7.123） | 核销 4,000 | 应收已核销；汇兑差异 +12.00 CNY；手续费 25 USD 计入财务费用 |
| FIN-RV-T02 | 订单 SO-12 定金 3,000 USD 预收 | 确认收款 | 销售回款计划定金节点已收 |
| FIN-RV-T03 | 出货后应收 7,000，预收 3,000 | 核销预收 3,000 + 新收款 4,000 | 应收核销完；回款计划只增加 4,000 |
| FIN-RV-T04 | 左右合计不相等 | 确认核销 | 提示“核销金额不平衡” |
| FIN-RV-T05 | 已核销 | 反确认收款单 | 提示“收款已核销，请先反核销” |

# 08-01 仓库与库位

## 1. 功能说明

维护仓库、库位、仓库负责人（数据权限）、物料类别默认仓。

- 使用者：仓库主管
- 优先级：P0

## 2. 数据表

### inv_warehouse 仓库

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| code | str(16) | 是 | | 仓库编码，唯一 |
| name | str(64) | 是 | | |
| warehouse_type | enum(RAW/SEMI/FG/FPC/ELEC/PKG/AUX/NG/QC/RTN) | 是 | | 仓库类型，创建后不可修改 |
| org_id | id | 是 | 当前用户公司 | 所属公司 |
| manager_id | id | 否 | | 仓库主管 |
| address | str(256) | 否 | | |
| location_enabled | bool | 是 | 0 | 启用库位管理 |
| allow_negative | bool | 是 | 0 | 允许负库存（仅当全局参数也允许时生效） |
| is_default | bool | 是 | 0 | 同类型的默认仓（每个类型最多一个） |
| status | enum(ENABLED/DISABLED) | 是 | ENABLED | |
| remark | str(256) | 否 | | |

### inv_location 库位

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| warehouse_id | id | 是 | |
| code | str(32) | 是 | 库位编码，仓库内唯一，如 `A-01-02-03`（区-排-层-位） |
| name | str(64) | 否 | |
| status | enum(ENABLED/DISABLED) | 是 | |
| remark | str(128) | 否 | |

### inv_warehouse_user 仓库操作人员（技术表）

`warehouse_id`、`user_id`。仓管员只能确认、新建、查询自己负责仓库的单据和库存（仓库数据权限）。拥有“全部”数据范围的角色不受限。

### inv_category_warehouse 类别默认仓

| 字段 | 类型 | 说明 |
|---|---|---|
| category_id | id | 物料类别（可以是非末级，子类别继承） |
| warehouse_id | id | 默认仓（必须是可用仓） |

唯一：`uk_category(category_id)`。

默认仓确定规则（`WarehouseApi.getDefaultWarehouse`）：沿物料类别向上查找第一个有映射的类别 → 找不到时按物料类型取该类型的默认仓（原材料→RAW、半成品→SEMI、成品→FG、包材→PKG、辅料→AUX）→ 仍找不到时报错“物料「{code}」没有默认仓库，请在仓库管理中配置类别默认仓”。

|---|---|---|---|

## 3. 页面

### 3.1 仓库管理（三个页签）

路由 `/inventory/warehouse`，权限 `inv:warehouse:query`。

**页签一：仓库**（T1，不分页）

- 查询：关键字、仓库类型、状态。
- 列：编码（100）、名称（140）、类型（100，可用仓绿色标签，不可用仓灰色标签）、默认（60 ✓）、库位管理（80）、主管（100）、操作人员（200，姓名逗号分隔）、状态（70）、操作（编辑、库位、人员、停用/启用、删除）。
- 表单（T2 中弹窗）：编码*（仅新建，1～16 位大写字母数字 `-`）、名称*、类型*（仅新建）、主管、地址、启用库位管理（开关，已有库存时不能关闭）、允许负库存（开关，不可用仓不显示）、设为同类型默认、备注。
- [库位]：抽屉，库位列表（编码、名称、状态、操作），支持新建、批量生成（输入区 A～C、排 1～10、层 1～5、位 1～4，预览将生成的编码后确认）、导入、停用。
- [人员]：弹窗，UserSelect 多选。

**页签二：类别默认仓**（T1）

- 列：物料类别（全路径）、默认仓库、操作（编辑、删除）。
- [新建映射]：类别（树选择）、仓库（WarehouseSelect，只列可用仓）。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| INV-WH-R01 | 保存 | 编码唯一 | `仓库编码「{code}」已存在` |
| INV-WH-R02 | 保存 | 类型创建后不可修改 | — |
| INV-WH-R03 | 设为默认 | 同类型只有一个默认仓，自动取消原默认 | — |
| INV-WH-R04 | 停用 | 仓库有库存或有未确认的单据时不能停用 | `仓库还有库存或未完成单据，不能停用` |
| INV-WH-R05 | 删除 | 从未发生过出入库的仓库才能删除 | `仓库已有出入库记录，不能删除` |
| INV-WH-R06 | 关闭库位管理 | 仓库有库存时不能关闭；开启库位管理时，已有库存全部放入自动创建的库位 `DEFAULT` | `仓库有库存，不能关闭库位管理` |
| INV-WH-R07 | 库位 | 库位编码仓库内唯一；有库存的库位不能停用/删除 | `库位「{code}」有库存，不能停用` |
| INV-WH-R08 | 类别默认仓 | 默认仓必须是可用仓 | `默认仓必须是可用仓（不能是待检仓、不良品仓、退货仓）` |
| INV-WH-R09 | 数据权限 | 仓管员只能看到自己负责的仓库（WarehouseSelect、库存查询、单据列表均按此过滤） | — |

| POST | /inventory/warehouses/{id}/enable、/disable | update |
| PUT | /inventory/warehouses/{id}/users | update |
| GET / POST / PUT / DELETE | /inventory/warehouses/{id}/locations[/{locId}] | query / update |

| GET | /inventory/locations/simple?warehouseId= | 登录即可 |
| GET / POST / PUT / DELETE | /inventory/category-warehouses[/{id}] | query / update |

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| INV-WH-T01 | 初始化后 | 打开仓库管理 | 10 个仓库，每类一个且为默认 |
| INV-WH-T02 | ELEC 下有子类别 IC，只配置了 ELEC→W-ELEC | 查询 IC 物料默认仓 | W-ELEC（继承） |
| INV-WH-T03 | — | 类别默认仓选择 W-QC | 下拉中没有待检仓；接口返回 R08 提示 |
| INV-WH-T04 | 仓管员 A 只负责 W-RAW | A 打开库存查询 | 只显示 W-RAW 的库存 |
| INV-WH-T05 | W-RAW 有库存 | 停用 W-RAW | 提示“仓库还有库存或未完成单据，不能停用” |
| INV-WH-T06 | — | 批量生成库位：区 A～B、排 1～2、层 1～2、位 1 | 预览 8 个编码 A-01-01-01…B-02-02-01，确认后生成 |

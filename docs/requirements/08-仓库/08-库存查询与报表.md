# 08-08 库存查询与报表

## 1. 功能说明

仓库模块内的操作型查询和报表：即时库存、库存流水、收发存汇总、库龄、呆滞料、库存预警、待检超时。跨模块的经营分析在 BI 模块。

- 使用者：仓库人员；其他部门（查询权限）
- 优先级：即时库存、库存流水、收发存汇总 P0；其余 P1
- 所有查询按仓库数据权限过滤；金额类字段需要 `inv:stock:cost`。

## 2. 页面

### 2.1 库存查询（T1）

路由 `/inventory/stock`，权限 `inv:stock:query`。

**查询条件**

| 条件 | 控件 | 默认 |
|---|---|---|
| 物料 | 输入框（编码前缀 / 名称规格模糊） | |
| 物料类别 | 树选择（含下级） | |
| 仓库类型 | 下拉多选（原材料、半成品、成品、FPC、电子料、包材、辅料、不良品、待检、退货） | |
| 仓库 | WarehouseSelect 多选 | |
| 批次号 | 输入框 | （展开区） |
| 库位 | LocationSelect | （展开区） |
| 显示零库存 | 开关 | 关 |
| 汇总方式 | 单选：按物料 / 按物料+仓库 / 按物料+仓库+批次（明细） | 按物料+仓库 |

**列表列**（随汇总方式变化）

| 列 | 说明 |
|---|---|
| 物料编码、名称、规格、单位、类别 | |
| 仓库、仓库类型 | 按物料汇总时不显示 |
| 库位、批次、生产日期、到期日期、特采/冻结标记 | 仅明细方式 |
| 现存量 | 右 |
| 可用量 | 右；不可用仓显示 0（灰） |
| 预留量 | 右（P1） |
| 待检量 | 按物料汇总时：待检仓数量 |
| 不良量 | 按物料汇总时：不良品仓数量 |
| 在途采购量 | 按物料汇总时，调用资材（P1） |
| 安全库存 | 按物料汇总时；可用量 < 安全库存时整行浅红底色 |
| 参考单价、金额 | 字段权限 |
| 最近入库 / 最近出库日期 | |

表格底部显示合计（现存量合计仅在单一单位时有效，否则只显示金额合计）。
行操作：[流水]（跳转库存流水并带入条件）、[批次]（按物料汇总时，打开批次分布抽屉）。
工具栏：[导出]。

### 2.2 库存流水（T1）

路由 `/inventory/stock/txn`（库存查询页的第二个页签）。

查询：物料、仓库、批次、出入方向、出入库类型（多选）、单号/来源单号、业务日期（默认本月，最大跨度 1 年）。
列：业务日期、单号（链接）、类型、来源单号（链接）、物料编码、名称、规格、仓库、库位、批次、入库数量（右）、出库数量（右）、结存数量（右，该库存维度结存）、单价、金额（字段权限）、操作人、时间。冲销流水显示灰色“冲销”标签。

### 2.3 收发存汇总（T7）

路由 `/inventory/analysis`（库存分析页的“收发存”页签）。

查询：期间（月份范围，默认本月）、仓库、物料类别、物料、汇总层级（物料 / 物料+仓库）、显示无发生额物料（默认否）。

列：物料编码、名称、规格、单位、[仓库]、期初数量、期初金额、本期入库数量（可展开按入库类型细分：采购、生产、退料、退货、其他、盘盈、调入）、本期入库金额、本期出库数量（可展开：领料、销售、退货、其他、盘亏、调出）、本期出库金额、期末数量、期末金额。

- 数量来自流水实时汇总；金额：已结账期间取 `inv_period_balance`，未结账期间出库金额为“未计算”（灰色 `-`），并在页面顶部提示“本期出库成本在月末成本计算后显示”。
- 期初 = 上期期末；首期期初 = 期初导入数据。
- 校验：期初 + 入库 − 出库 = 期末，不一致的行标红（数据异常，正常不会出现）。

### 2.4 库龄分析（T7，P1）

查询：截止日期（默认今天）、仓库类型（默认可用仓）、物料类别、账龄区间设置（默认 0～30、31～90、91～180、181～365、>365 天）。
计算：批次管理物料按批次首次入库日期；非批次物料按先进先出倒推（现存量从最近的入库流水往前分配）。
列：物料、规格、现存量、各区间数量（和金额，字段权限）、最长库龄天数。
图表：各区间金额占比柱状图。

### 2.5 呆滞料（T1，P1）

条件：无出库天数 ≥ `inv.alert.slow-moving-days`（页面可临时修改）、仓库类型、类别。
列：物料、现存量、金额、最近入库日期、最近出库日期、无出库天数、是否被启用 BOM 引用（是/否，否表示可能已淘汰）。

### 2.6 库存预警（T1，P1）

页签：**低于安全库存**（可用量 + 在途采购 < 安全库存；列：物料、安全库存、可用量、在途、缺口、采购员）、**超过最高库存**、**临期/过期批次**、**待检超时**（待检仓中首次入库超过 `inv.qc.overdue-hours` 小时仍有库存的批次；列：物料、批次、数量、入库时间、已等待小时、来源到货单）。

定时任务每小时计算一次并发布 `StockAlertEvent` 到工作台（同一物料同一预警类型未处理前不重复发送）。

## 3. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| INV-RPT-R01 | 流水查询时间跨度不超过 1 年 | `查询时间范围不能超过 1 年` |
| INV-RPT-R02 | 导出超过同步行数上限转后台任务 | — |
| INV-RPT-R03 | 库存查询“按物料汇总”方式下，只统计当前用户有权限的仓库 | — |

## 4. 接口

`GET /inventory/stocks`（汇总方式参数 `groupBy=MATERIAL|WAREHOUSE|BATCH`）、`GET /inventory/stock-txns`、`GET /inventory/reports/in-out-summary`、`GET /inventory/reports/aging`、`GET /inventory/reports/slow-moving`、`GET /inventory/alerts?type=`，均有对应 `/export`。

## 5. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| INV-RPT-T01 | A 在电子料仓 980、待检仓 100、不良品仓 20 | 按物料汇总查询 | 现存 1100、可用 980、待检 100、不良 20 |
| INV-RPT-T02 | 本月 A 采购入库 1000、领料 300 | 收发存汇总 | 入库 1000（采购 1000）、出库 300（领料 300），期末 = 期初 + 700 |
| INV-RPT-T03 | A 安全库存 500，可用 400，在途 50 | 库存预警 | A 出现在“低于安全库存”，缺口 50 |
| INV-RPT-T04 | 无成本权限 | 库存查询 | 不显示单价、金额列 |
| INV-RPT-T05 | 待检仓批次入库 30 小时未检，阈值 24 | 预警页“待检超时” | 显示该批次，已等待 30 小时 |

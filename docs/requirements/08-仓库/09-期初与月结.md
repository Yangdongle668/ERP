# 08-09 期初与月结

## 1. 功能说明

- **期初库存**：系统上线时导入各仓库的期初数量、批次和成本。
- **库存期间与月结**：按月管理库存期间。月结关闭当期，之后该期间不能再过账；月结后财务进行成本计算。

- 使用者：仓库主管、财务
- 优先级：P0

## 2. 数据表

### inv_period 库存期间

| 字段 | 类型 | 说明 |
|---|---|---|
| period | str(6) 唯一 | yyyyMM |
| start_date / end_date | date | |
| period_status | enum(OPEN/CLOSED) | |
| closed_by / closed_at | | |
| is_opening | bool | 启用期间（上线首月） |

### inv_period_balance 期末结存（月结时生成）

| 字段 | 类型 | 说明 |
|---|---|---|
| period | str(6) | |
| material_id / warehouse_id | id | 按物料 + 仓库结存（不到批次） |
| qty | qty | 期末数量 |
| amount | amt | 期末金额（财务成本计算后回填） |
| avg_cost | price | 期末加权平均单价（财务回填） |

唯一：`(period, material_id, warehouse_id)`。

## 3. 期初导入

### 3.1 启用设置

路由 `/inventory/period`，页签“期初”。首次使用时设置**启用期间**（如 202610），系统创建该期间（OPEN）；启用期间之前的日期不能有任何出入库。

### 3.2 期初导入

模板列：仓库编码*、库位编码（启用库位的仓库必填）、物料编码*、批次号（批次管理物料必填）、供应商批号、生产日期、到期日期、数量*（基本单位）、单价*（本位币不含税）、序列号（序列号物料，多个用逗号分隔）。

- 导入生成一张类型为“期初入库”（`OPENING`，入库类型扩展值）的入库单，单据日期 = 启用期间第一天的前一天，自动确认，流水期间标记为 `OPENING`。
- 可多次导入（按仓库分批）；[清空期初]：在启用期间还没有任何其他单据过账前，可以删除全部期初重新导入。
- [完成期初]：确认后不能再导入或清空期初，按钮变为“期初已完成”。未完成期初前，不允许确认其他出入库单（`请先完成期初库存导入`）。

## 4. 月结

### 4.1 月结检查（点击 [月结] 时执行，结果以清单展示）

| 检查项 | 级别 | 说明 |
|---|---|---|
| 本期存在草稿/待确认的出入库单、调拨单 | 警告 | 列出单号，可继续（这些单据确认时业务日期需在下期） |
| 本期存在盘点中的盘点单 | 阻止 | `盘点单 {no} 尚未完成` |
| 存在负库存 | 阻止 | 列出物料和仓库 |
| 上一期间未结账 | 阻止 | `请先结账 {period}` |

### 4.2 月结动作

1. 生成 `inv_period_balance`（数量）；
2. 本期状态改为 CLOSED，创建下一期间（OPEN）；
3. 发布 `PeriodClosedEvent(period)`，财务模块据此进行成本计算，计算完成后回填出库流水成本和期末金额。

### 4.3 反结账

- 权限 `inv:period:reopen`；只能反结账最近一个已结账期间；
- 财务该期间已结账（成本已锁定）时不允许：`财务期间已结账，请先由财务反结账`；
- 反结账后删除该期间的 `inv_period_balance`，状态改回 OPEN。

### 4.4 页面

期间列表：期间、开始/结束日期、状态、结账人、结账时间、操作（月结、反结账）。月结时弹出检查结果，全部通过或只有警告时可确认结账。

## 5. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| INV-PRD-R01 | 已结账期间不能过账、不能反确认该期间的单据 | `库存期间 {period} 已结账` |
| INV-PRD-R02 | 单据日期早于启用期间不能过账 | `单据日期早于系统启用期间 {period}` |
| INV-PRD-R03 | 期初未完成不能确认其他单据 | `请先完成期初库存导入` |
| INV-PRD-R04 | 月结检查中“阻止”级别的项必须全部解决 | 见 4.1 |

## 6. 接口

`GET /inventory/periods`、`POST /inventory/periods/init`（启用期间）、`POST /inventory/periods/{period}/check`、`POST /inventory/periods/{period}/close`、`POST /inventory/periods/{period}/reopen`、`GET /inventory/opening/import-template`、`POST /inventory/opening/import/check`、`POST /inventory/opening/import`、`POST /inventory/opening/clear`、`POST /inventory/opening/complete`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| INV-PRD-T01 | 启用期间 202610 | 导入期初 200 行并完成期初 | 库存查询显示期初库存；收发存 10 月期初数量正确 |
| INV-PRD-T02 | 期初未完成 | 确认一张采购入库单 | 提示“请先完成期初库存导入” |
| INV-PRD-T03 | 10 月有盘点中的盘点单 | 月结 | 检查结果显示阻止项，不能结账 |
| INV-PRD-T04 | 10 月已结账 | 确认单据日期为 10-31 的入库单 | 提示“库存期间 202610 已结账” |
| INV-PRD-T05 | 财务 10 月已结账 | 仓库反结账 10 月 | 提示“财务期间已结账，请先由财务反结账” |

# 08-07 批次与序列号

## 1. 功能说明

- **批次**：批次管理物料每次入库形成一个批次，记录供应商批号、生产日期、到期日、来源、质量标记（特采）、冻结状态。批次是追溯、先进先出、保质期管理的基础。
- **序列号**：序列号管理物料按件管理，每件一个唯一序列号。
- 优先级：批次 P0；序列号 P1

## 2. 数据表

### inv_batch 批次档案

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| material_id | id | 是 | | |
| batch_no | str(64) | 是 | | 批次号，同一物料内唯一 |
| supplier_id | id | 否 | | |
| supplier_batch_no | str(64) | 否 | | 供应商批号 |
| production_date | date | 否 | | |
| expire_date | date | 否 | | |
| first_in_date | date | 是 | | 首次入库日期（FIFO 依据） |
| source_type / source_no | | 是 | | 首次入库的来源（采购到货、生产订单等） |
| is_concession | bool | 是 | 0 | 特采批次 |
| frozen | bool | 是 | 0 | 冻结 |
| frozen_reason | str(256) | 否 | | |
| remark | str(256) | 否 | | |

唯一：`uk_material_batch(material_id, batch_no)`。

批次号生成：入库时为空则按编码规则 INV_BATCH 生成（如 `B260924001`）；采购入库可配置“使用供应商批号作为批次号”（物料采购属性，P1）。生产入库的批次号默认使用生产订单号。

### inv_serial 序列号

## 3. 页面

### 3.1 批次查询（T1）

路由 `/inventory/batch`，权限 `inv:stock:query`。

**查询条件**：物料（MaterialSelect）、批次号（前缀）、供应商批号、供应商、到期状态（全部 / 已过期 / 30 天内到期 / 正常）、冻结（全部/是/否）、有库存（默认是）。

**列表列**：物料编码、名称、规格、批次号、供应商批号、供应商、生产日期、到期日期（过期红色、临期橙色）、剩余天数、首次入库日期、现存量（右，全部仓库合计）、可用量、标记（特采橙色标签、冻结红色标签）、操作（明细、冻结/解冻、编辑）。

- [明细]：抽屉显示该批次在各仓库/库位的数量，以及全部出入库流水（追溯：来源单据、出库去向）。
- [冻结]（`inv:batch:freeze`）：原因必填；[解冻]：原因必填。均记录操作日志。
- [编辑]（`inv:batch:update`）：可修改供应商批号、生产日期、到期日期（修改到期日期需要原因，如“品质评估延期”）、备注。

### 3.2 序列号查询（批次查询页的第二个页签，P1）

查询：物料、序列号（精确或前缀）、状态、客户。列：物料、序列号、批次、状态、仓库、库位、客户、最近单据。[履历]：该序列号的全部出入库记录。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| INV-BAT-R01 | 入库 | 批次已存在时，本次入库的生产日期、到期日期若与档案不同则提示（不同实物不应共用批次号） | `批次「{batch}」已存在且生产日期不同，请确认批次号` |
| INV-BAT-R02 | 入库 | 到期日期 = 生产日期 + 保质期天数（物料有保质期时）；采购到货时剩余保质期比例低于物料的“最小剩余保质期”时提示 | `批次剩余保质期 {pct}%，低于要求的 {min}%` （警告） |
| INV-BAT-R03 | 出库 | 冻结、过期批次不能出库（例外见 02 过账规则 R05） | |
| INV-BAT-R04 | 预警 | 每天 07:00 检查：到期前 `inv.alert.expiry-warn-days` 天的有库存批次，发布临期预警；已过期的有库存批次发布过期预警（给仓库主管和品质） | — |
| INV-BAT-R05 | 冻结 | 品质模块可通过 `BatchApi.freeze/unfreeze` 冻结批次（如 NCR 调查中）；冻结来源为品质时，仓库人员不能手工解冻 | `该批次由品质冻结（{no}），请联系品质部门解冻` |
| INV-BAT-R06 | 序列号 | 同一物料序列号唯一；序列号入库时若已存在且为“已出库”（如退货），允许再次入库，状态改为在库 | — |

## 5. 接口

`GET /inventory/batches`、`GET /inventory/batches/{id}`（含分布与流水）、`POST /inventory/batches/{id}/freeze`、`/unfreeze`、`PUT /inventory/batches/{id}`、`GET /inventory/serials`、`GET /inventory/serials/{id}/history`。Java：`BatchApi.get(materialId, batchNo)`、`freeze(materialId, batchNo, reason, sourceNo)`、`unfreeze(...)`、`trace(materialId, batchNo)`（批次的全部流水）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| INV-BAT-T01 | 物料保质期 180 天 | 入库生产日期 2026-09-01 | 到期日期 2027-02-28 |
| INV-BAT-T02 | 批次 B1 在两个仓库各有库存 | 批次明细 | 显示两个仓库的数量和全部流水 |
| INV-BAT-T03 | 品质冻结 B1 | 仓管员解冻 | 提示“该批次由品质冻结（NCR-…），请联系品质部门解冻” |
| INV-BAT-T04 | B2 20 天后到期，临期天数 30 | 次日 07:00 | 工作台出现临期预警 |
| INV-BAT-T05 | 序列号 SN001 已销售出库 | 销售退货入库 SN001 | 允许入库，状态变为在库 |

# 08-05 调拨单

## 1. 功能说明

库存在仓库之间、库位之间移动。调拨不改变物料总量和成本，只改变存放位置和可用性。

- 使用者：仓管员
- 优先级：P0
- 采用**直接调拨**：确认时同时完成调出和调入（不设“在途”状态）。

### 1.1 调拨类型

| 类型 | 编码 | 来源 | 调出仓 → 调入仓 | 说明 |
|---|---|---|---|---|
| 普通调拨 | NORMAL | 手工 | 可用仓 ↔ 可用仓；可用仓 → 不良品仓；同仓库位间移库 | 不良品仓 → 可用仓 不允许手工调拨（需经品质判定） |
| 检验调拨 | INSPECTION | 品质·检验判定（IQC/FQC/退货判定/复检） | 待检仓 → 可用仓 / 不良品仓；退货仓 → 成品仓 / 不良品仓；不良品仓 → 可用仓（复检合格、特采） | 系统生成 |
| 复检送检 | RECHECK | 手工 | 可用仓 / 不良品仓 → 待检仓 | 库存超期、质量存疑时送回待检，同时通知品质创建复检单 |

## 3. 页面

### 3.1 调拨单列表（T1）

路由 `/inventory/transfer`。查询：单号、类型、调出仓、调入仓、状态（默认草稿）、物料、日期（近 30 天）。
列：单号（链接）、类型、调出仓 → 调入仓（显示“待检仓 → 电子料仓”）、物料摘要、总数量、来源检验单（链接）、日期、状态、确认人/时间、操作（确认、编辑、作废）。
工具栏：[新建调拨]、[复检送检]、[批量确认]、[导出]。

### 3.2 调拨单编辑（T4）

单头：类型（只读）、调出仓*、调入仓*（按类型过滤可选仓库）、日期、原因、备注。
明细：物料（MaterialSelect，只列调出仓有库存的物料）、批次（BatchSelect，调出仓）、调出库位、调入库位、数量（≤ 该批次可用量）、序列号、备注。
工具栏：[按库存添加]（弹窗列出调出仓的库存明细，勾选并填写数量）。
页头：[保存] [确认调拨]。

检验调拨单由系统生成：明细按判定结果分为两张单（合格/特采 → 可用仓；不合格 → 不良品仓），仓管员只需补充调入库位后确认（参数 `inv.transfer.auto-confirm-inspection` 为是时自动确认）。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| INV-TF-R01 | 保存 | 调出、调入仓组合必须符合 1.1 | `不允许从【{from}】调拨到【{to}】` |
| INV-TF-R02 | 保存 | 调出仓 = 调入仓时必须启用库位且库位不同 | `同一仓库调拨请选择不同的库位` |
| INV-TF-R03 | 确认 | 一次过账：调出行 OUT + 调入行 IN，同批次、同成本；任一行失败全部回滚 | — |
| INV-TF-R04 | 检验调拨 | 由 `InspectionJudgedEvent` 生成：判定数量按合格/特采/不合格拆分；特采的批次在确认后标记 `is_concession=1` | — |
| INV-TF-R05 | 检验调拨 | 检验调拨单不能手工修改物料和数量，只能补充库位；不能作废（需品质重判后由系统作废重建） | `检验调拨单不能修改数量` |
| INV-TF-R06 | 复检送检 | 确认后发布 `RecheckRequestedEvent`，品质模块生成复检单 | — |
| INV-TF-R07 | 确认 | 发布 `TransferConfirmedEvent`；检验调拨确认后品质检验单状态更新为“已处理” | — |

## 5. 接口

`/inventory/transfers`（GET 列表/详情、POST 新建、PUT 修改、DELETE）、`/{id}/confirm`、`/batch-confirm`、`/{id}/void`、`/{id}/print-data`。`InventoryDocApi.createTransfer(TransferRequest)` 供品质模块调用。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| INV-TF-T01 | IQC 判定：A 批次 B1 1000 中合格 980、不合格 20 | — | 生成 2 张检验调拨单：980 待检仓 → 电子料仓，20 待检仓 → 不良品仓 |
| INV-TF-T02 | 同上 | 仓管员确认两张单 | 待检仓 A 为 0；电子料仓可用 980；不良品仓 20；检验单状态“已处理” |
| INV-TF-T03 | — | 手工新建调拨：不良品仓 → 原材料仓 | 调入仓下拉中没有原材料仓；接口返回“不允许从【不良品仓】调拨到【原材料仓】” |
| INV-TF-T04 | 物料超期存疑 | 复检送检 100 到待检仓 | 可用量减少 100；品质模块出现复检单 |
| INV-TF-T05 | IQC 特采 | 检验调拨确认 | 批次标记“特采”，批次查询中显示特采标签 |

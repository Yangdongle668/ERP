# 08-04 出库单

## 1. 功能说明

所有出库都通过出库单完成。与入库单相同，分为业务生成（仓管员确认出库）和手工新建（其他出库）。出库单的核心工作是**分配批次/库位**：业务生成的出库单只有物料和数量，仓管员确认时选择或自动分配批次。

- 使用者：仓管员
- 优先级：P0

### 1.1 出库类型

| 出库类型 | 编码 | 来源单据 | 允许的出库仓 | 实发数量 |
|---|---|---|---|---|
| 生产领料出库 | PRODUCTION_ISSUE | 生产·领料单 | 可用仓 | 可少于申请数量（缺料时），不能多于 |
| 委外发料出库 | OUTSOURCE_ISSUE | 资材·委外单发料 | 可用仓 | 同上 |
| 销售出库 | SALES_OUT | 出货·出货单 | 可用仓（通常成品仓） | 必须等于申请数量 |
| 采购退货出库 | PURCHASE_RETURN | 资材·采购退货单 | 不良品仓、可用仓、待检仓（IQC 判退且未调拨时） | 必须等于 |
| 其他出库 | OTHER_OUT | 手工；研发工程·样品单 | 可用仓；原因为“报废”时也可以是不良品仓 | 手工单可改 |
| 盘亏出库 | COUNT_LOSS | 仓库·盘点单 | 盘点仓库 | 系统生成并自动确认 |

“实发少于申请”时，来源单据保留未发数量，可再次生成出库单（如领料单“补发”）。

## 3. 页面

### 3.1 出库单列表（T1）

路由 `/inventory/out`。查询条件、列、按钮与入库单列表一致（类型换为出库类型；“供应商/客户”列同时可显示领用部门）。快捷筛选：`待出库 (n)`、`今日已出库`、`全部`。

### 3.2 出库单编辑 / 确认（T4）

**单头**：单号、出库类型（只读）、仓库（手工单可选）、单据日期、领用部门（OrgTreeSelect）、领用人（UserSelect）、原因（其他出库）、来源单号（只读）、备注。

**明细**

| 列 | 控件 | 说明 |
|---|---|---|
| 物料 / 名称 / 规格 / 单位 | 业务单只读；手工单可编辑 | |
| 申请数量 | 只读 | |
| 可用库存 | 只读 | 本仓库该物料可用量（实时查询） |
| 实发数量 | QtyInput | 规则见 1.1 |
| 库位 | LocationSelect | 条件必填 |
| 批次 | BatchSelect（列出本仓库该物料可用批次：批次号、库位、数量、生产日期、到期日，按 FIFO/FEFO 排序） | 条件必填 |
| 序列号 | 按钮“录入(n)”（弹窗中可从在库序列号列表勾选或扫码） | 条件必填 |
| 备注 | 输入框 | |

工具栏：[自动分配批次]：对所有未指定批次的批次管理物料行，按物料出库规则（FIFO：入库日期最早；FEFO：到期日最早）从可用批次中分配，数量不够一个批次时自动拆成多行；库存不足时剩余数量保留在一行并标红“库存不足 {n}”。[拆分行]：把当前行按数量拆分，用于手工指定多个批次。

页头按钮：[保存] [确认出库]（业务单）/ [保存] [提交]（手工单）。

### 3.3 出库单详情（T5）

按钮矩阵与入库单一致（确认入库 → 确认出库）。页签：明细（显示申请数量、实发数量、批次）、关联单据、审批记录、操作日志、附件。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| INV-OUT-R01 | 生成 | 同一来源行可生成多张出库单，但所有未作废出库单的申请数量之和不能超过来源行未出数量（由来源模块保证并由本模块复核） | `申请出库数量超过来源单据未出数量` |
| INV-OUT-R02 | 保存/确认 | 出库仓符合 1.1 约束 | `{出库类型}只能从【{允许的仓库类型}】出库` |
| INV-OUT-R03 | 确认 | 实发数量规则：领料/委外发料 0 < 实发 ≤ 申请（同一来源行拆分的多行合计）；销售出库、采购退货合计必须等于申请 | `第 {n} 行实发数量不能大于申请数量` / `销售出库实发数量必须等于申请数量 {qty}` |
| INV-OUT-R04 | 确认 | 批次、库位、序列号按物料属性必填；库存校验见 02 过账规则 | `第 {n} 行：请选择批次` |
| INV-OUT-R05 | 确认 | 过账成功后发布 `StockOutConfirmedEvent`（每个来源行的实发基本单位数量、批次明细），来源模块回写已出数量 | — |
| INV-OUT-R06 | 批次推荐 | FEFO 排除已过期批次；FIFO 按批次首次入库日期；同一日期按库位编码 | — |
| INV-OUT-R07 | 退回 | 同入库单 INV-IN-R06 | |
| INV-OUT-R08 | 反确认 | 期间未结账；来源模块校验（`StockOutReversingEvent`，如销售出库已开票则阻止）；成功后回到草稿，发布 `StockOutReversedEvent` | 来源模块提示原文 |
| INV-OUT-R09 | 其他出库 | 原因为“报废”时单据额外要求附件或备注说明（二选一） | `报废出库请上传附件或填写说明` |
| INV-OUT-R10 | 自动确认 | 参数 `inv.out.auto-confirm-source` 为是且物料均不需要指定批次/序列号（或能按规则自动分配且库存充足）时自动确认 | — |

## 5. 接口

与入库单一致，路径为 `/inventory/stock-outs`，另有：

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | /inventory/stock-outs/{id}/auto-allocate | `inv:out:update` | 自动分配批次，返回分配后的行（不保存） |
| GET | /inventory/batches/available?materialId=&warehouseId= | 登录即可 | BatchSelect 数据 |

`InventoryDocApi.createStockOut(StockOutRequest)`：`{outType, warehouseId, docDate?, sourceType, sourceId, sourceNo, receiverDeptId?, receiverId?, customerId?, supplierId?, lines:[{sourceLineId, materialId, uom, qty, batchNo?}]}`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| INV-OUT-T01 | 领料单申请 A 500；W-RAW 有 B1 300（9-01 入）、B2 400（9-10 入） | 自动分配批次 | 拆为两行：B1 300、B2 200 |
| INV-OUT-T02 | 同上，库存只有 350 | 自动分配 | B1 300、B2 50，另有一行 150 标红“库存不足 150”；可把实发改为 350 后确认 |
| INV-OUT-T03 | 实发 350 确认 | — | 领料单已发 350、未发 150，可生成补发出库单 |
| INV-OUT-T04 | 销售出库申请 100 | 实发改为 90 | 提示“销售出库实发数量必须等于申请数量 100” |
| INV-OUT-T05 | 物料 FEFO，B3 已过期 | 自动分配 | 不分配 B3 |
| INV-OUT-T06 | 其他出库原因报废，无附件无备注 | 提交 | 提示“报废出库请上传附件或填写说明” |
| INV-OUT-T07 | 销售出库已开票 | 反确认 | 提示财务模块的阻止原因 |

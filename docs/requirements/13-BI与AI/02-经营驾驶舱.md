# 13-02 经营驾驶舱

## 1. 功能说明

管理层一屏查看经营全貌：收入、回款、毛利、订单、交付、库存、质量关键指标及趋势，支持期间切换和下钻。

- 路由 `/bi/dashboard`，权限 `bi:dashboard:view`（财务类卡片另需 `bi:finance:view`）
- 优先级：P1

## 2. 页面布局

```
┌ 经营分析   期间 [本月 ▾] [2026-09]   对比 [环比 ▾]         数据更新于 10:05  [导出PDF] ┐
├───────────────────────────────────────────────────────────────────────────────┤
│ 接单额      出货额       回款额       毛利额/率      应收余额(逾期)   库存金额          │ 第一行 KPI
│ ¥12.5M     ¥10.2M      ¥9.8M       ¥2.1M/20.6%   ¥8.0M(¥1.2M)   ¥15.3M           │
│ ↑8.2%      ↑3.1%       ↓2.0%       ↓1.2pt        ↑5%            ↑4%              │
├───────────────────────────────────────┬───────────────────────────────────────┤
│ 近 12 个月 接单/出货/回款 趋势（折线）   │ 客户 Top10 出货额（条形）                  │
├───────────────────────────────────────┼───────────────────────────────────────┤
│ 交期达成率 & 在手订单（仪表 + 数字）      │ 产品类别 出货额占比（环形）                 │
├───────────────────────────────────────┼───────────────────────────────────────┤
│ 来料合格率 / 直通率 / 客诉数（三个小趋势） │ 库存结构：按仓库类型金额（堆叠柱）/ 呆滞金额  │
└───────────────────────────────────────┴───────────────────────────────────────┘
```

## 3. 卡片与图表定义

| 区块 | 指标 | 下钻 |
|---|---|---|
| KPI 行 | 接单额、出货额、回款额、毛利额与毛利率、应收余额与逾期、库存金额；每个显示对比期变化（环比/同比/目标达成，P2 目标） | 点击 → 对应专题分析页并带入期间 |
| 趋势 | 近 12 个月接单、出货、回款（三条线） | 点击某月 → 销售分析该月 |
| 客户 Top10 | 本期出货额前 10 客户及占比 | 点击客户 → 客户分析 |
| 交付 | 交期达成率（仪表盘）、在手订单金额、延期订单数 | → PMC 交期预警 |
| 品类占比 | 按物料类别出货额 | → 销售分析按类别 |
| 质量 | 来料批次合格率、直通率、客诉数（近 6 个月迷你趋势） | → 品质分析 |
| 库存 | 各仓库类型库存金额（原材料、FPC、电子料、包材、辅料、半成品、成品、不良品、待检、退货）、呆滞金额 | → 库存分析 |

## 4. 规则

| 编号 | 规则 |
|---|---|
| BI-DSH-R01 | 期间可选：本月、上月、本季、本年、自定义；对比：环比（上一个同长度期间）、同比（去年同期） |
| BI-DSH-R02 | 无 `bi:finance:view` 的用户不显示毛利、应收卡片 |
| BI-DSH-R03 | 图表遵循 dataviz 规范：统一配色（类别色板不超过 8 色）、深浅色主题适配、数值千分位 |
| BI-DSH-R04 | [导出 PDF]：以当前页面生成 A4 横向 PDF（前端截图方案），用于经营会议 |

## 5. 接口

`GET /bi/dashboard?period=&compare=`（一次返回全部卡片数据，内部并行查询指标）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| BI-DSH-T01 | 本月出货 10.2M、上月 9.89M | 打开驾驶舱（环比） | 出货额 ↑3.1% |
| BI-DSH-T02 | 无财务权限 | 打开 | 不显示毛利、应收卡片 |
| BI-DSH-T03 | 点击出货额 | — | 跳转销售分析，期间相同 |

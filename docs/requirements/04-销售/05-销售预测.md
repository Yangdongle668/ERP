# 04-05 销售预测

## 1. 功能说明

业务按月录入未来几个月的产品需求预测（可按客户），发布后作为 PMC 的独立需求（用于提前备料、备货）。实际订单审核后自动**冲销**预测，避免订单和预测重复计算。

- 使用者：业务员、业务主管、计划员（查看）
- 优先级：P1

## 2. 数据表

### sal_forecast 预测单（BaseDocDO，编码规则 SAL_FORECAST）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | str(128) | 是 | 如“2026 Q4 预测” |
| start_period / end_period | str(6) | 是 | 起止月份 yyyyMM，最多 12 个月 |
| forecast_status | enum(DRAFT/PUBLISHED/CLOSED) | 是 | 草稿 / 已发布（生效）/ 已关闭（失效） |
| published_at | datetime | 否 | |

### sal_forecast_line

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| customer_id | id | 否 | 空表示不区分客户 |
| material_id | id | 是 | 成品/半成品 |
| period | str(6) | 是 | 月份 |
| qty | qty | 是 | 预测数量（基本单位） |
| consumed_qty | qty | 是 | 已被订单冲销数量 |
| remark | str(256) | 否 | |

唯一：`(forecast_id, customer_id, material_id, period)`。**净预测** = max(0, qty − consumed_qty)。

### sal_forecast_consumption 冲销记录（技术表）

`forecast_line_id`、`order_line_id`、`qty`、`created_at`。订单反审核/变更/关闭时按记录回退。

## 3. 冲销规则

订单行审核时，按“客户 + 物料”（预测行客户为空时只按物料）查找已发布预测中的行：

1. 先冲销订单**要求交期所在月**的预测；
2. 不够时按参数 `sal.forecast.consume-window`（默认向前 0 个月、向后 1 个月）依次冲销邻近月份；
3. 同时存在指定客户和不区分客户的预测时，先冲指定客户的；
4. 冲销数量 = min(订单未冲销数量, 预测净数量)；订单超出预测的部分不产生负数。

订单数量减少、关闭、反审核时按冲销记录回退（先回退最晚的记录）。

## 4. 页面

### 4.1 预测列表（T1）

查询：标题、状态、月份、业务员、物料。列：单号、标题、起止月份、行数、预测总量、已冲销总量、冲销率、状态、业务员、发布时间、操作（编辑、发布、关闭、复制）。

### 4.2 编辑页（矩阵录入）

单头：标题*、起止月份*。
明细为矩阵：行 = 客户（可空）+ 物料，列 = 月份，单元格录入数量；[添加物料行]（选择客户、物料）；[导入]（模板：客户编码、物料编码*、月份*、数量*）；[从上期复制]（复制上一张预测的数量）。行尾显示合计。

### 4.3 详情页

按钮：编辑（草稿）、发布（草稿 → 已发布，发布 `ForecastPublishedEvent`）、关闭（已发布 → 已关闭，原因，净预测不再计入 PMC）、复制。
矩阵只读显示，每个单元格显示“预测 / 已冲销”，冲销率 > 100% 时说明订单超预测（红色）。行操作 [冲销明细]：列出冲销该行的订单行。

## 5. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| SAL-FC-R01 | 月份跨度不超过 12 个月；预测月份不能早于当前月 | `预测月份不能早于当前月` |
| SAL-FC-R02 | 同一物料（+ 客户）同一月份只能出现在一张已发布预测中；发布时冲突则提示先关闭旧预测 | `物料「{code}」{月份}已在预测「{no}」中` |
| SAL-FC-R03 | 已发布的预测修改：通过“修订”复制为新草稿，发布新版时自动关闭旧版，并把旧版的冲销记录迁移到新版 | — |
| SAL-FC-R04 | 已过去的月份：月末后该月的净预测自动失效（不再计入 PMC 需求） | — |

## 6. 接口

`/sales/forecasts`（CRUD、publish、close、copy、revise、import）、`GET /sales/forecasts/{id}/lines/{lineId}/consumptions`；`ForecastApi.getNetForecast(fromPeriod, toPeriod)`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SAL-FC-T01 | 预测 FG1 10 月 1000、11 月 1000（已发布） | 审核 FG1 订单 1500，要求交期 10-20 | 10 月冲销 1000，11 月冲销 500；PMC 净预测 10 月 0、11 月 500 |
| SAL-FC-T02 | 同上 | 订单变更为 800 | 回退：11 月冲销恢复为 0，10 月冲销 800 |
| SAL-FC-T03 | 10 月已过去 | 11 月初查看 PMC 需求 | 10 月剩余净预测不再计入 |

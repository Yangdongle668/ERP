# 04-01 价格表

## 1. 功能说明

维护标准销售价格：可以针对某个客户、某个客户等级或所有客户，按币别、数量阶梯和有效期定价。报价、下单时自动取价。

- 使用者：业务主管（维护）、业务员（查询）
- 优先级：P1（上线初期可不维护价格表，订单手工录价）

## 2. 数据表

### sal_price_list 价格表（BaseDocDO，编码规则 SAL_PRICE_LIST）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | str(64) | 是 | 如“ABC 2027 年度价格”“A 级客户标准价” |
| scope | enum(CUSTOMER/LEVEL/ALL) | 是 | 适用：指定客户 / 客户等级 / 所有客户 |
| customer_id | id | 条件 | scope=CUSTOMER |
| customer_level | dict(crm_customer_level) | 条件 | scope=LEVEL |
| currency | str(3) | 是 | |
| tax_included | bool | 是 | 价格是否含税 |
| effective_from | date | 是 | |
| effective_to | date | 否 | |

状态：草稿 → 待审批 → 已审核（生效）→ 已关闭（手工失效）。

### sal_price_list_item

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| material_id | id | 是 | |
| uom | str(16) | 是 | 销售单位 |
| min_qty | qty | 是 | 阶梯起始数量（销售单位），第一档 0 |
| price | price | 是 | 单价（按 tax_included 为含税或不含税） |
| remark | str(256) | 否 | |

唯一：`(price_list_id, material_id, uom, min_qty)`。

## 3. 取价规则（`SalesPriceApi.getPrice`，报价单和订单共用）

按优先级依次查找，找到即返回，并返回价格来源：

1. **客户价格表**：scope=CUSTOMER、该客户、币别相同、单据日期在有效期内、已审核；
2. **等级价格表**：scope=LEVEL、客户当前等级；
3. **通用价格表**：scope=ALL；
4. **有效报价**：该客户该物料最近一张已审核、未过期的报价单行（数量阶梯匹配）；
5. **最近成交价**：该客户该物料最近一张已审核订单的单价（同币别）；
6. 都没有：返回空，由用户手工录入。

同一层级有多张价格表同时有效时，取生效日期最晚的一张。阶梯：取 min_qty ≤ 数量的最大一档。价格表含税/不含税与单据不一致时按行税率换算。

## 4. 页面

### 4.1 价格表列表（T1）

查询：名称、适用范围、客户、等级、币别、状态（默认已审核）、物料（包含该物料）、有效日期（该日期有效）。
列：编号、名称、适用范围、客户/等级、币别、含税、生效日期、失效日期、物料数、状态、操作（编辑、复制、关闭）。
工具栏：新建、导入（模板：物料编码*、单位*、起始数量*、单价*、备注；导入到草稿价格表）、导出。

### 4.2 编辑页（T4）

单头：名称*、适用范围*、客户/等级（条件必填）、币别*、含税*、生效日期*、失效日期、备注。
明细：物料*、名称、规格、单位*（销售单位）、起始数量*、单价*、参考成本（物料标准成本，字段权限 `sales:order:cost`）、毛利率（只读计算，低于最低毛利率红色）、备注。
工具栏：添加行、批量添加物料、导入、[批量调价]（对选中行按百分比或固定金额调整）。

### 4.3 详情页（T5）

按钮：编辑、提交、审批、关闭（已审核，原因）、复制为新价格表、打印（P2）。

## 5. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| SAL-PL-R01 | 同一物料 + 单位必须有起始数量为 0 的档 | `物料「{code}」必须有起始数量为 0 的阶梯` |
| SAL-PL-R02 | 已审核的价格表不能修改，只能关闭或复制新建 | `已审核的价格表不能修改` |
| SAL-PL-R03 | 失效日期 ≥ 生效日期 | `失效日期不能早于生效日期` |
| SAL-PL-R04 | 价格表不影响已保存的单据价格 | — |

## 6. 接口

`/sales/price-lists`（CRUD、submit、close、copy、import、export）、`GET /sales/prices/lookup?customerId=&materialId=&qty=&uom=&date=&currency=`（返回价格、含税标记、来源、来源单号）。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SAL-PL-T01 | ABC 客户价格表 FG1 0→10.00、1000→9.50 | 订单 FG1 1200 | 带出 9.50，来源“客户价格表 PL-2026-001” |
| SAL-PL-T02 | 无客户价格表，A 级价格表 FG1 11.00，ABC 为 A 级 | 下单 | 带出 11.00，来源“等级价格表” |
| SAL-PL-T03 | 都没有，上次成交 10.80 | 下单 | 带出 10.80，来源“最近成交价 SO-…” |
| SAL-PL-T04 | 标准成本 9.00，最低毛利 15% | 价格表录入 10.00 | 毛利率 10% 显示红色 |

# 04-08 销售报表

## 1. 功能说明

销售模块内的操作型报表（路由 `/sales/report`，多个页签），按业务员数据权限过滤；成本、毛利需 `sales:order:cost`。跨模块经营分析见 BI 模块。

- 优先级：订单明细、未交订单 P0；其余 P1

## 2. 报表清单

### 2.1 订单明细查询（P0）

以订单行为单位：订单号、日期、客户、客户 PO、业务员、物料、客户料号、数量、单价、金额（原币、本位币）、要求交期、承诺交期、已出货、未出货、已开票、行状态、毛利率（字段权限）。查询条件同订单列表并增加物料类别。底部合计（本位币金额）。

### 2.2 未交订单（P0）

已审核/执行中、未出货数量 > 0 的订单行：订单号、客户、物料、订单数量、已出货、未出货、可用库存（成品仓可用量）、在制数量（生产模块：来源本订单行的在制数量）、要求交期、承诺交期、距交期天数（≤3 天橙色、已过期红色）、业务员。支持按“距交期”排序。用于每日跟单。

### 2.3 订单执行跟踪（P1）

选择一个订单或订单行，时间线展示：下单 → 审核 → PMC 承诺交期 → 生产订单下达/完工 → 出货通知 → 出库 → 提单 → 开票 → 回款，每一步显示日期、单号、数量。

### 2.4 业务员业绩（P1）

查询：期间（月/季/年）、业务员、部门。指标（本位币）：接单额（审核订单价税合计）、出货额（出货确认金额）、回款额（收款分配）、毛利额（出货额 − 出货成本，月结后可用；字段权限）、新客户数（期内首次下单客户）、订单数。图表：业务员接单额排名柱状图、月度趋势。

### 2.5 报价成功率（P1）

期间内报价单：按业务员 / 客户 / 物料类别统计报价数、成交数、成交率、未成交原因分布（饼图）、平均报价周期（RFQ 到报价的天数）。

### 2.6 客户销售排名（P1）

期间内按客户：接单额、出货额、占比、同比增长；ABC 分类（累计占比 80% 为 A、95% 为 B、其余 C）。

## 3. 接口

`GET /sales/reports/order-lines`、`/open-orders`、`/order-trace/{orderLineId}`、`/performance`、`/quotation-success`、`/customer-ranking`，均支持 `/export`。

## 4. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SAL-RPT-T01 | 3 个订单行未出完 | 未交订单 | 3 行，距交期正确，可用库存与在制数据正确 |
| SAL-RPT-T02 | 业务员 A 只能看自己 | A 打开业绩 | 只显示 A 的数据 |
| SAL-RPT-T03 | 10 张报价成交 4 张 | 报价成功率 | 40% |

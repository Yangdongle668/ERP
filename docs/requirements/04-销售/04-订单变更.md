# 04-04 订单变更

## 1. 功能说明

已审核的销售订单不能直接修改，必须通过订单变更单：记录变更内容和原因，审批通过后更新订单、保存旧版本快照，并通知 PMC 和出货。

- 使用者：业务员、业务主管
- 优先级：P0

## 2. 数据表

### sal_order_change 变更单（BaseDocDO，编码规则 SAL_ORDER_CHANGE）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| order_id | id | 是 | |
| order_version_from | int | 是 | 变更前版本 |
| change_reason | dict(sal_change_reason) | 是 | |
| reason_remark | str(512) | 是 | 原因说明 |
| amount_change_base | amt | 是 | 变更金额差（本位币，审批条件） |
| header_changes | json | 否 | 单头字段变更（交易条件、地址、客户 PO 号等）：`[{field, old, new}]` |

状态：草稿 → 待审批 → 已审核（已应用到订单）；草稿可作废。

### sal_order_change_line

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| change_type | enum(ADD/MODIFY/CANCEL) | 是 | 新增行 / 修改行 / 取消行 |
| order_line_id | id | 条件 | MODIFY/CANCEL 必填 |
| material_id | id | 是 | |
| old_qty / new_qty | qty | 条件 | |
| old_price / new_price | price | 条件 | |
| old_required_date / new_required_date | date | 条件 | |
| new_customer_part_no / new_description | str | 否 | |
| remark | str(256) | 否 | |

## 3. 页面

### 3.1 变更单列表（T1）

路由 `/sales/order-change`。查询：单号、订单号、客户、原因、状态、日期。列：单号、订单号（链接）、客户、版本（V1 → V2）、原因、金额差（正绿负红）、状态、业务员、日期。

### 3.2 编辑页（T4）

从订单详情 [变更] 进入，自动带入订单当前内容：

- **单头变更区**：可修改的单头字段（客户 PO 号、付款条件、贸易条款、港口、收货地址、联系人、合同条款、备注），修改过的字段黄色底色。币别、客户、订单类型不可变更。
- **明细**：列出订单全部行（当前值只读 + 新值可编辑）：数量（新）、单价（新）、要求交期（新）、客户料号、描述；每行操作 [取消行]；工具栏 [新增行]。修改过的单元格黄色底色，取消行整行删除线。
- **变更原因***、原因说明*。
- 底部：变更前价税合计、变更后价税合计、差额。

页头：[保存] [提交]。

### 3.3 详情页（T5）

按钮：编辑/删除/提交（草稿）、审批、作废（草稿）。页签：变更对比（旧值 → 新值表格）、审批记录、操作日志。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SAL-SC-R01 | 新建 | 订单为已审核/执行中；同一订单只能有一张未完成（草稿/待审批）的变更单 | `订单已有未完成的变更单「{no}」` |
| SAL-SC-R02 | 保存 | 新数量 ≥ 已通知出货数量（noticed_qty，按基本单位换算）；取消行要求 noticed_qty = 0 | `第 {n} 行新数量不能小于已通知出货数量 {qty}` |
| SAL-SC-R03 | 保存 | 已开票的数量部分单价不能修改（新单价仅影响未开票数量时不允许，提示整行不可改价） | `第 {n} 行已开票，不能修改单价` |
| SAL-SC-R04 | 审核 | 应用前检查订单版本仍为 order_version_from（期间没有其他变更） | `订单已被修改，请作废本变更单后重新发起` |
| SAL-SC-R05 | 审核 | 保存快照 → 应用变更 → order_version + 1 → 重算金额、毛利、回款计划（未收款节点按新金额重算）→ 发布 `SalesOrderChangedEvent(orderId, lines 变化明细)`、`SalesOrderOpenAmountChangedEvent` | — |
| SAL-SC-R06 | 通知 | PMC 收到数量减少/取消的行，若已有生产订单，给计划员推送待办“订单减量，请评估是否调整生产订单” | — |
| SAL-SC-R07 | 信用 | 变更后金额增加时对增加部分做信用检查 | CRM 提示原文 |

## 5. 接口

`POST /sales/order-changes?orderId=`（创建并带入）、`/sales/order-changes`（GET/PUT/DELETE）、`/{id}/submit`、`/{id}/void`、`GET /sales/orders/{id}/snapshots`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SAL-SC-T01 | 订单 V1 行 1000，已通知 300 | 变更为 800，要求交期推后 | 审核后订单 V2，行数量 800；版本记录可查看 V1 |
| SAL-SC-T02 | 同上 | 变更为 200 | 提示“新数量不能小于已通知出货数量 300” |
| SAL-SC-T03 | 订单已有草稿变更单 | 再次变更 | 提示已有未完成变更单 |
| SAL-SC-T04 | 行已有生产订单 | 数量减少审核后 | 计划员收到待办 |
| SAL-SC-T05 | 变更单待审批期间订单被另一张变更修改（异常情况） | 审核 | 提示“订单已被修改，请作废本变更单后重新发起” |

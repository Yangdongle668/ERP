# 04-03 销售订单

## 1. 功能说明

记录客户订单并跟踪执行：录入（手工、报价转入、导入客户 PO）→ 审批 → PMC 回复交期 → 出货 → 开票 → 回款 → 完成/关闭。打印销售合同和 Proforma Invoice（PI）。

- 使用者：业务员、业务助理、业务主管
- 优先级：P0

### 3.4 从报价生成

SourceDocPicker 列出客户的已审核/已发送、未过期报价单行（报价单号、物料、阶梯、单价、交期）。勾选后生成草稿订单（同一客户、同一币别的行合并到一张订单），数量需要填写，单价按数量匹配阶梯。

### 3.5 导入客户 PO

模板列：客户编码*、客户 PO 号*、客户 PO 日期、物料编码或客户料号*（二选一）、数量*、单价（空则自动取价）、要求交期*、备注。同一客户 + PO 号的行生成一张草稿订单。

## 4. 状态与流转

| 当前 | 动作 | 前置 | 结果 | 副作用 |
|---|---|---|---|---|
| 草稿 | 提交 | R01～R07 | 待审批 / 已审核 | |
| 待审批 | 通过 | 再次信用检查（BLOCK 时审批失败） | 已审核 | 生成回款计划（07）；发布 `SalesOrderApprovedEvent`（PMC 需求池、CRM 商机、客户最近下单）、`SalesOrderOpenAmountChangedEvent` |
| 已审核 | 反审核 | R08 | 草稿 | 删除回款计划；发布 `SalesOrderUnapprovedEvent` |
| 已审核 | 首次出货通知/出货 | | 执行中 | |
| 执行中 | 所有行已出齐或关闭 | | 已完成（参数 auto-complete=否时需全部回款） | |
| 已审核/执行中 | 关闭 | R10 | 已关闭 | 发布 `SalesOrderClosedEvent` |
| 已审核/执行中 | 变更单审核 | 见 04-订单变更 | 状态不变，版本 + 1 | 发布 `SalesOrderChangedEvent` |

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SAL-SO-R01 | 提交 | 客户 `validateCanOrder`（正式客户） | `客户「{name}」不是正式客户，不能下单` / `客户「{name}」在黑名单中` |
| SAL-SO-R02 | 保存 | 同一客户 + 客户 PO 号非空时唯一（未作废订单中） | `客户 PO 号「{po}」已存在于订单「{no}」` |
| SAL-SO-R03 | 提交 | 物料启用；汇率 > 0；至少一行；要求交期 ≥ 单据日期 | 各字段通用提示 |
| SAL-SO-R04 | 行保存 | 数量 < 物料 MOQ 时按参数警告或阻止；非 MPQ 倍数提示 | `物料「{code}」数量低于最小订购量 {moq}` |
| SAL-SO-R05 | 提交 | 计算毛利与底价，填 min_margin_rate、below_floor（审批条件） | — |
| SAL-SO-R06 | 提交/审核 | 信用检查 `CreditApi.check(客户, 本单本位币价税合计, ORDER)`：WARN 时提交人看到确认框并设置 credit_warning=1；BLOCK 时阻止（补货订单不检查） | CRM 提示原文 |
| SAL-SO-R07 | 金额 | 计算规则同采购订单（含税/不含税录入互算，尾差处理）；本位币金额 = ROUND(原币 × 汇率, 2) | — |
| SAL-SO-R08 | 反审核 | 无出货通知、无预收款核销、无生产订单引用（PMC 通过 `SalesOrderReferenceChecker` 检查）时才能反审核 | `订单已有出货通知/收款/生产订单，不能反审核，请使用订单变更` |
| SAL-SO-R09 | 交期回复 | PMC 调用 `updatePromisedDate` 写入承诺交期；承诺交期 > 要求交期时设置 delivery_risk 并通知业务员 | — |
| SAL-SO-R10 | 关闭 | 原因必填；有未完成（未出库）的出货通知时不能关闭；关闭的剩余数量从 PMC 需求中移除 | `订单还有未完成的出货通知「{no}」` |
| SAL-SO-R11 | 回写 | 监听出货确认/冲销事件回写 shipped_qty；出货通知保存/删除回写 noticed_qty；开票回写 invoiced_qty；所有回写使用乐观锁并校验不超过允许数量 | — |
| SAL-SO-R12 | 提醒 | 承诺交期（无则要求交期）前 `sal.order.delivery-warn-days` 天仍有未出货数量，提醒业务员 | — |
| SAL-SO-R13 | 业务员转移 | 监听 `CustomerOwnerChangedEvent(transferDocs=true)`：未完成订单的业务员（owner_id、dept_id）改为新负责人 | — |

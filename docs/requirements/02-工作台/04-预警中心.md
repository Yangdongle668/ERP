# 02-04 预警中心

## 1. 功能说明

集中显示各模块发出的预警（库存低于安全库存、批次临期、待检超时、交期延期、证书到期、工装寿命、应收逾期等），支持按级别和类型筛选、处理、忽略。预警条件消除时自动关闭。

- 优先级：P1

## 2. 预警类型（由各模块发布）

| 类型编码 | 名称 | 来源 | 默认接收人 |
|---|---|---|---|
| STOCK_LOW | 低于安全库存 | 仓库 | 物料计划员、采购员 |
| STOCK_HIGH | 超过最高库存 | 仓库 | 仓库主管 |
| BATCH_EXPIRING / BATCH_EXPIRED | 批次临期 / 过期 | 仓库 | 仓库主管、品质 |
| QC_OVERDUE | 待检超时 | 仓库 / 品质 | 品质主管 |
| DELIVERY_DELAY | 交期延期 | PMC | 计划员、业务员（CRITICAL 加 PMC 主管） |
| PO_OVERDUE | 采购逾期未到货 | 资材 | 采购员 |
| CERT_EXPIRING | 证书到期 | 研发工程 | 认证工程师 |
| SUPPLIER_CERT_EXPIRING | 供应商资质到期 | 资材 | 采购员、SQE |
| TOOLING_LIFE | 工装寿命 | 研发工程 | 工艺工程师 |
| AR_OVERDUE | 应收逾期 | 财务 | 业务员、应收会计 |
| RATE_MISSING | 汇率未维护 | 系统管理 | 财务 |
| DEFECT_SPIKE | 不良突增 | 品质 | QE |

## 4. 页面（`/workbench/alert`）

顶部统计：严重 / 警告 / 提示（未处理）数量卡片，点击筛选。
查询：级别、类型、状态（默认未处理）、时间。
列：级别标签、类型、标题、内容、首次预警时间、最近更新、状态、操作（[查看]：跳转 route；[处理]：处理说明*；[忽略]：原因*，忽略后同一 alert_key 在 7 天内不再提醒，除非级别升高）。

## 5. 业务规则

| 编号 | 规则 |
|---|---|
| WB-ALT-R01 | `AlertRaisedEvent`：alert_key 存在且为 OPEN → 更新内容与级别（级别升高时重新通知）；为 HANDLED/IGNORED → 级别升高或忽略期已过时重新打开；为 RESOLVED 或不存在 → 新建 |
| WB-ALT-R02 | `AlertResolvedEvent` → 状态 RESOLVED |
| WB-ALT-R03 | CRITICAL 预警同时发送站内消息（和邮件，参数启用时） |
| WB-ALT-R04 | 用户只看到接收人包含自己的预警 |

## 6. 接口

`GET /workbench/alerts`、`GET /workbench/alerts/stats`、`POST /workbench/alerts/{id}/handle`、`POST /workbench/alerts/{id}/ignore`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| WB-ALT-T01 | 螺丝低于安全库存 | — | 采购员、计划员预警中心出现警告 |
| WB-ALT-T02 | 采购到货后高于安全库存 | — | 预警自动变为已消除 |
| WB-ALT-T03 | 交期延期从 5 天增加到 9 天 | — | 级别由警告升为严重，PMC 主管收到消息 |
| WB-ALT-T04 | 忽略某预警 | 同一条件 3 天后再次发生（同级别） | 不重新提醒 |

# 01-05 编码规则

## 1. 功能说明

统一生成主数据编码和单据编号。每个编码对象（业务编码 `biz_code`）一条规则，规则由业务模块声明默认值（`CodeRuleDefinition`），管理员可在界面上修改。

- 使用者：系统管理员
- 优先级：P0
- 已有实现：前缀 + 日期 + 流水号、按周期重置、并发安全。本文档新增：分隔符、变量前缀、允许手工输入、流水号查看与调整。

### 1.1 编码组成

```
编码 = 前缀 + 日期 + 分隔符 + 流水号
示例：SO-  + 202609 + -  + 0001  =  SO-202609-0001
      M    +        +    + 000123 =  M000123
      {categoryPrefix} + 00001    =  FPC00001（前缀变量由调用方提供）
```

| 片段 | 说明 |
|---|---|
| 前缀 | 固定文字，可含变量 `{变量名}`，由调用方在生成时传入（如物料类别前缀）。含变量时，**每个不同的前缀取值独立计数** |
| 日期 | 空 / `yyyy` / `yyMM` / `yyyyMM` / `yyMMdd` / `yyyyMMdd`，取**生成时**的日期（服务器时区 Asia/Shanghai） |
| 分隔符 | 空 或 `-`，位于日期和流水号之间；日期为空时忽略 |
| 流水号 | 固定位数左补 0；超过位数时继续增长（如 4 位用完后变为 10000），并在日志中告警 |
| 重置周期 | 不重置 / 按年 / 按月 / 按日；重置周期必须与日期片段匹配（R03） |

## 2. 数据表

### sys_code_rule 编码规则（已有表，补充字段）

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| biz_code | str(64) | 是 | | 业务编码，唯一 |
| name | str(64) | 是 | | 名称，如“销售订单号” |
| module_code | str(32) | 是 | | 所属模块 |
| prefix | str(32) | 是 | '' | 前缀，可含 `{var}` |
| date_pattern | str(16) | 是 | '' | 日期格式 |
| separator | str(4) | 是 | '' | 分隔符 |
| seq_length | int | 是 | | 流水号位数 1～12 |
| reset_cycle | enum(NEVER/YEAR/MONTH/DAY) | 是 | | 重置周期 |
| allow_manual | bool | 是 | 0 | 允许用户手工输入编码（主数据常用）；为 1 时表单编码框可编辑，留空才自动生成 |

### sys_code_seq 流水号（已有技术表，重置键规则变更）

`reset_key` = 周期键（`ALL` / `2026` / `202609` / `20260924`）+ `|` + 解析后的前缀（前缀含变量时），例如 `ALL|FPC`。

## 3. 页面

### 3.1 编码规则列表（T1）

路由 `/system/code-rule`，权限 `system:code-rule:query`。

**查询条件**：模块（下拉）、关键字（业务编码/名称）。不分页（规则数量有限），按模块、业务编码排序。

**列表列**

| 列 | 字段 | 宽度 | 说明 |
|---|---|---|---|
| 模块 | module_code | 100 | 模块中文名 |
| 业务编码 | biz_code | 200 | |
| 名称 | name | 160 | |
| 规则 | — | 260 | 以片段形式展示：`[SO-][yyyyMM][-][0000]` |
| 示例 | — | 180 | 按当前日期计算的下一个编码示例（不占用流水号） |
| 重置周期 | reset_cycle | 90 | |
| 手工输入 | allow_manual | 80 | 是/否 |
| 操作 | — | 160 | 编辑、流水号 |

### 3.2 编辑规则（T2 中弹窗）

| 字段 | 控件 | 必填 | 可编辑 | 校验与说明 |
|---|---|---|---|---|
| 业务编码 | 文本 | — | 否 | |
| 名称 | 输入框 | 是 | 是 | ≤64 |
| 前缀 | 输入框 | 否 | 是 | ≤32；只能包含字母、数字、`-` `_` `/` 和已声明的变量 `{xxx}`；R02 |
| 日期格式 | 下拉 | 否 | 是 | 选项见 1.1 |
| 分隔符 | 下拉（无 / `-`） | 否 | 是 | |
| 流水号位数 | 数字框 | 是 | 是 | 1～12 |
| 重置周期 | 下拉 | 是 | 是 | R03 |
| 允许手工输入 | 开关 | 是 | 是 | |
| 示例预览 | 只读文本 | — | — | 随输入实时刷新 |

保存时二次确认：“修改规则只影响之后生成的编码，已生成的编码不变。确定保存吗？”

### 3.3 流水号（抽屉）

列出该规则的所有流水号记录：重置键、当前值、最后更新时间。操作 [调整]：输入新值，只能大于当前值（R04）。

## 4. 状态与流转

无。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SYS-COD-R01 | 生成 | 并发安全不重号；允许跳号（事务回滚导致） | — |
| SYS-COD-R02 | 保存 | 前缀中的变量必须是模块声明中允许的变量 | `前缀中的变量「{var}」不可用，可用变量：{vars}` |
| SYS-COD-R03 | 保存 | 重置周期为按年时日期格式必须包含年；按月必须包含年月；按日必须包含年月日；日期格式为空时重置周期只能是“不重置” | `重置周期为“按月”时，日期格式必须包含年和月` |
| SYS-COD-R04 | 调整流水号 | 新值必须大于当前值 | `新值必须大于当前值 {current}` |
| SYS-COD-R05 | 生成 | 规则未配置且无模块声明 | `未配置编码规则【{bizCode}】` |
| SYS-COD-R06 | 手工输入 | 规则 `allow_manual = 0` 时，业务接口忽略前端传入的编码（始终自动生成）；为 1 时，手工输入的编码由业务模块校验唯一性 | — |
| SYS-COD-R07 | 生成 | 生成的编码长度超过 64 时报错 | `生成的编码过长，请检查编码规则【{bizCode}】` |

| GET | /system/code-rules/{id}/seqs | `system:code-rule:query` | 流水号记录 |
| PUT | /system/code-rules/{id}/seqs | `system:code-rule:update` | 调整（resetKey、newValue） |

## 8. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SYS-COD-T01 | SAL_ORDER 规则默认 | 2026-09 创建两张销售订单 | 单号依次为 SO-202609-0001、SO-202609-0002 |
| SYS-COD-T02 | 上月最后单号 SO-202609-0150 | 2026-10-01 创建订单 | SO-202610-0001 |
| SYS-COD-T03 | ENG_MATERIAL 前缀 `{categoryPrefix}` | 分别在 FPC 类别和 ELEC 类别下新建物料 | FPC00001、ELEC00001，两个类别独立计数 |
| SYS-COD-T04 | 编辑规则：日期格式清空，重置周期仍为按月 | 保存 | 提示“重置周期为“按月”时，日期格式必须包含年和月” |
| SYS-COD-T05 | 当前流水 150 | 调整为 100 | 提示“新值必须大于当前值 150” |
| SYS-COD-T06 | 8 个线程并发各生成 25 个 | — | 200 个编号互不相同（已有自动化测试） |
| SYS-COD-T07 | SAL_ORDER 允许手工输入 | 新建销售订单时编码框输入 SO-MANUAL-1 | 保存后单号为 SO-MANUAL-1；清空编码框保存则自动生成 |

# 01-07 币别与汇率

## 1. 功能说明

维护币别、本位币和汇率。所有涉及金额的单据都记录币别和汇率，并同时保存原币金额和本位币金额。

- 使用者：系统管理员、财务
- 优先级：P0

**汇率定义**：1 单位外币 = 汇率 × 本位币。例：本位币 CNY，USD 汇率 7.1000 表示 1 USD = 7.1 CNY。

**汇率类型**

| 类型 | 编码 | 用途 |
|---|---|---|
| 日汇率 | DAILY | 业务单据默认取值（下单、出货、收付款） |
| 月末汇率 | MONTH_END | 财务期末外币重估（12-财务） |

## 2. 数据表

### sys_currency 币别

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| code | str(3) | 是 | | ISO 4217 代码，唯一，如 CNY、USD |
| name | str(16) | 是 | | 中文名称 |

| symbol | str(4) | 否 | | 符号，如 ¥、$ |
| amount_precision | int | 是 | 2 | 金额小数位 0～2（JPY 为 0） |
| is_base | bool | 是 | 0 | 本位币，全系统唯一一个 |
| sort | int | 是 | 0 | |
| status | enum(ENABLED/DISABLED) | 是 | ENABLED | |

### sys_exchange_rate 汇率

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| currency | str(3) | 是 | | 外币（不能是本位币） |
| rate_type | enum(DAILY/MONTH_END) | 是 | DAILY | |
| effective_date | date | 是 | | 生效日期（月末汇率为该月最后一天） |

| source | enum(MANUAL/IMPORT) | 是 | MANUAL | 来源 |
| remark | str(128) | 否 | | |

## 3. 页面

路由 `/system/currency`，权限 `system:currency:query`。页面两个页签：**币别**、**汇率**。

### 3.1 币别页签（T1，不分页）

- 列：代码（80）、名称（100）、英文名称（160）、符号（60）、金额精度（90，右）、本位币（80，✓ 绿色标签）、状态（70）、操作（编辑、停用/启用）。
- 工具栏：[新建]（`system:currency:create`）、[设为本位币]（`system:currency:set-base`，选中一行后可用，R03）。

**币别表单（T2 中弹窗）**

| 字段 | 控件 | 必填 | 可编辑 | 校验 |
|---|---|---|---|---|
| 代码 | 输入框 | 是 | 仅新建 | 3 位大写字母；R01 |
| 名称 | 输入框 | 是 | 始终 | ≤16 |
| 英文名称 | 输入框 | 否 | 始终 | ≤32 |
| 符号 | 输入框 | 否 | 始终 | ≤4 |
| 金额精度 | 数字框 0～2 | 是 | 未被使用时 | |
| 排序 | 数字框 | 是 | 始终 | |

### 3.2 汇率页签（T1）

**查询条件**：币别（CurrencySelect，排除本位币）、汇率类型（默认日汇率）、生效日期（日期范围，默认近 30 天）。

**列表列**

| 列 | 字段 | 宽度 | 格式 |
|---|---|---|---|
| 币别 | currency | 80 | |
| 汇率类型 | rate_type | 100 | |
| 生效日期 | effective_date | 110 | 可排序（默认倒序） |
| 汇率 | rate | 120 | 右对齐，4 位小数（悬停显示 6 位） |
| 说明 | — | 200 | “1 USD = 7.1000 CNY” |
| 来源 | source | 80 | |
| 修改人 / 修改时间 | updated_by / updated_at | 160 | |
| 操作 | — | 120 | 编辑、删除 |

**按钮**

| 按钮 | 权限 | 行为 |
|---|---|---|
| 新建 | `system:rate:create` | 汇率表单 |
| 批量录入 | `system:rate:create` | 小表格弹窗：选择日期和类型，每个启用外币一行输入汇率，一次保存 |
| 导入 | `system:rate:import` | 模板列：币别*、汇率类型*（日汇率/月末汇率）、生效日期*、汇率*；已存在同键记录时覆盖（导入预览中标注“覆盖”） |
| 导出 | `system:rate:export` | |
| 编辑 / 删除 | `system:rate:update` / `delete` | R06 |

**汇率表单（T2 小弹窗）**

| 字段 | 控件 | 必填 | 默认 | 校验 |
|---|---|---|---|---|
| 币别 | CurrencySelect（排除本位币） | 是 | | |
| 汇率类型 | 单选 | 是 | 日汇率 | |
| 生效日期 | 日期 | 是 | 今天 | 月末汇率自动调整为所选月份最后一天 |
| 汇率 | 数字框（6 位小数） | 是 | 最近一条汇率 | > 0；与最近一条相比变化超过 10% 时黄色提示“与上次汇率相差 x%，请确认”（不阻止） |
| 备注 | 输入框 | 否 | | |

## 4. 状态与流转

币别：启用 ⇄ 停用（本位币不可停用）。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SYS-CUR-R01 | 保存币别 | 代码唯一 | `币别「{code}」已存在` |
| SYS-CUR-R02 | 停用 | 本位币不能停用 | `本位币不能停用` |
| SYS-CUR-R03 | 设为本位币 | 只要任何业务单据中存在金额数据（由 `CurrencyReferenceChecker` 各模块提供检查），就不允许修改本位币 | `系统中已有业务数据，不能修改本位币` |
| SYS-CUR-R04 | 保存汇率 | 同一币别、类型、日期只能有一条 | `{currency} 在 {date} 已有{类型}` |
| SYS-CUR-R05 | 取汇率 | `CurrencyApi.getRate(currency, date, type=DAILY)`：本位币返回 1；否则取 `effective_date <= date` 的最近一条；一条都没有时报错 | `未维护币别 {currency} 在 {date} 及之前的汇率，请先维护汇率` |
| SYS-CUR-R06 | 删除/修改汇率 | 已被单据引用的汇率记录**可以**修改和删除（单据保存的是汇率值而非汇率记录 ID，不受影响），但需二次确认“修改不会影响已保存的单据” | — |
| SYS-CUR-R07 | 单据 | 业务单据选择币别后自动带出单据日期对应的日汇率，用户可修改；汇率必须 > 0；本位币单据汇率固定为 1 不可编辑 | `汇率必须大于 0` |
| SYS-CUR-R08 | 金额换算 | 本位币金额 = ROUND(原币金额 × 汇率, 本位币精度)；单头本位币金额 = 各行本位币金额之和（不对单头重新换算） | — |
| SYS-CUR-R09 | 汇率提醒 | 每个工作日 10:00 检查：启用外币当天没有日汇率时，向拥有 `system:rate:create` 权限的用户发送工作台提醒“今日汇率未维护：USD、EUR”（参数 `sys.rate.remind-enabled` 控制，默认开） | — |

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SYS-CUR-T01 | USD 日汇率：09-20 7.10，09-23 7.12 | 取 09-24 汇率 | 7.12（命中 09-23） |
| SYS-CUR-T02 | 同上 | 取 09-21 汇率 | 7.10 |
| SYS-CUR-T03 | EUR 无任何汇率 | 新建 EUR 销售订单 | 汇率框为空并提示“未维护币别 EUR 在 2026-09-24 及之前的汇率，请先维护汇率” |
| SYS-CUR-T04 | 已有销售订单 | 把 USD 设为本位币 | 提示“系统中已有业务数据，不能修改本位币” |
| SYS-CUR-T05 | — | 批量录入 09-24 的 USD、EUR、HKD 汇率 | 一次保存 3 条 |
| SYS-CUR-T06 | 订单行原币金额 100.005 USD，汇率 7.12 | 保存 | 原币金额 100.01（行金额按原币精度舍入），本位币 712.07 |
| SYS-CUR-T07 | 上次 USD 7.12 | 录入 8.00 | 显示黄色提示“与上次汇率相差 12.36%，请确认”，仍可保存 |

# 01-09 打印模板

## 1. 功能说明

为每种单据维护打印模板（中文、英文可各有多套），用户在单据列表或详情页点击“打印”，选择模板后预览并打印或另存为 PDF。

- 使用者：系统管理员维护模板；所有用户打印
- 优先级：P1（各业务模块在开发单据时同步提供内置模板）

### 1.1 技术方案

- 模板是 **HTML + CSS**，使用 **Handlebars** 语法引用数据：`{{docNo}}`、`{{#each lines}}…{{/each}}`、`{{formatAmount amount}}`。
- 打印时前端调用业务模块的打印数据接口取得 JSON 数据 → 用模板渲染成 HTML → 在新窗口预览（CSS `@page` 控制纸张和边距）→ 用户点击“打印”调用浏览器打印（可选“另存为 PDF”）。
- 选择理由：不需要服务端 PDF 渲染组件，模板可直接用 HTML 编写，排版灵活；浏览器打印支持跨页表头（`thead { display: table-header-group }`）。
- 内置帮助函数（前端注册）：`formatDate`、`formatDateTime`、`formatQty`（按单位精度）、`formatAmount`（千分位 2 位）、`formatPrice`、`amountInWordsCn`（人民币大写）、`amountInWordsEn`（英文金额大写，如 `SAY US DOLLARS ONE THOUSAND ... ONLY`）、`barcode`（Code128 条码 SVG）、`qrcode`、`dict`（字典标签）、`add`、`eq`。

## 3. 页面

### 3.1 打印模板列表（T1）

路由 `/system/print-template`，权限 `system:print:query`。

**查询条件**：单据类型（下拉，按模块分组）、语言、状态。

**列表列**：单据类型（140）、模板名称（200）、语言（80）、纸张（100）、默认（60，✓）、内置（60，✓）、状态（70）、修改时间（150）、操作。

**按钮**

| 按钮 | 权限 | 显示条件 | 行为 |
|---|---|---|---|
| 新建 | `system:print:create` | 始终 | 打开编辑器（空白模板或从同类型内置模板复制） |
| 编辑 | `system:print:update` | 非内置 | 打开编辑器 |
| 查看 | `system:print:query` | 内置 | 编辑器只读模式 |
| 复制 | `system:print:create` | 始终 | 复制为新模板（名称加“-副本”，非内置、非默认） |
| 设为默认 | `system:print:update` | 非默认且启用 | |
| 停用/启用 | `system:print:update` | 非默认 | 默认模板不能停用 |
| 删除 | `system:print:delete` | 非内置、非默认 | 二次确认 |

### 3.2 模板编辑器（全屏页面）

路由 `/system/print-template/:id/edit`（隐藏菜单）。

```
┌ ← 编辑模板：销售订单（标准）    单据类型[销售订单] 语言[中文] 纸张[A4纵向] 边距[10mm…] [保存] ┐
├ 变量（240px）──────┬ 模板代码（HTML）───────────────┬ 预览（示例数据）───────────────┤
│ ▾ 单头            │ <div class="header">            │  ┌──────────────────┐          │
│   docNo 单号      │   <h1>销售订单</h1>              │  │ 销售订单          │          │
│   docDate 日期    │   单号：{{docNo}}               │  │ 单号：SO-...      │          │
│ ▾ customer 客户   │ ...                             │  │ ...               │          │
│ ▾ lines 明细(数组) │                                 │  └──────────────────┘          │
│ ▾ 函数             │                                 │  [刷新预览] [用真实单据预览: ___] │
└───────────────────┴─────────────────────────────────┴──────────────────────────────┘
```

- 变量面板：树形展示 `variables`，点击变量在光标处插入 `{{path}}`；数组类型插入 `{{#each lines}}…{{/each}}` 片段。
- 代码区：带语法高亮的代码编辑器（CodeMirror 6，HTML 模式）。
- 预览区：输入内容 1 秒后自动用示例数据渲染；可输入真实单号预览。模板语法错误时预览区显示错误信息和行号。
- 保存时校验 R02。

### 3.3 打印操作（各业务页面通用，`PrintButton`）

- 单据详情页页头 [打印 ▾]：主按钮直接用当前语言的默认模板打印；下拉列出该单据类型的全部启用模板。
- 列表页工具栏 [打印]：勾选多张单据后批量打印（最多 50 张），每张单据分页。
- 打印预览窗口：顶部工具条 [打印] [关闭]，下方为渲染后的页面。
- 权限：打印需要该单据的 `xxx:print` 权限（各模块声明）。
- 草稿状态单据打印时在页面加灰色斜向水印“草稿”；已作废单据不允许打印（`已作废的单据不能打印`）。

## 4. 内置模板要求（各业务模块提供）

每个需要打印的单据至少提供一个中文内置模板，对外单据另提供英文模板。内置模板遵循《UI 设计规范》9.3 的版式：

1. 页眉：公司 Logo、公司名称（中文模板取组织名称/地址，英文模板取英文名称/英文地址，来自单据所属公司）、单据标题、右上角单号及其 Code128 条码。
2. 单头信息：两列或三列表格。
3. 明细表：带序号，表头每页重复；数量、金额右对齐。
4. 合计行、金额大写（中文模板）/ 英文大写（英文模板的 Invoice、PI）。
5. 备注、条款（如付款条件、交货条款）。
6. 签字栏：制单、审核、签收（按单据定义）。
7. 页脚：第 X 页 / 共 Y 页、打印时间、打印人。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SYS-PRT-R01 | 设为默认 | 同一单据类型 + 语言只有一个默认模板，设置新默认时自动取消旧默认 | — |
| SYS-PRT-R02 | 保存 | 模板能用示例数据渲染成功；内容 ≤ 200KB；不允许包含 `<script>`、`on*=` 事件属性、`javascript:` 链接（安全） | `模板渲染失败：{error}` / `模板中不允许包含脚本` |
| SYS-PRT-R03 | 打印 | 没有启用模板时 | `单据类型「{name}」没有可用的打印模板` |
| SYS-PRT-R04 | 打印 | 数据接口按当前用户权限返回；字段权限不足的字段在数据中为 `null`，模板显示 `***`（帮助函数统一处理） | — |
| SYS-PRT-R05 | 启动 | 内置模板不存在时从模块资源文件 `print-templates/<bizType>-<language>.html` 导入；已存在的不覆盖 | — |

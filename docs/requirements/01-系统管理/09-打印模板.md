# 01-09 打印模板

## 1. 功能说明

为每种单据维护打印模板（中文、英文可各有多套），用户在单据列表或详情页点击“打印”，选择模板后预览并打印或另存为 PDF。

- 使用者：系统管理员维护模板；所有用户打印
- 优先级：P1（各业务模块在开发单据时同步提供内置模板）

### 1.1 技术方案

- 模板是 **HTML + CSS**，使用 **Handlebars** 语法引用数据：`{{docNo}}`、`{{#each lines}}…{{/each}}`、`{{formatAmount amount}}`。
- 打印时前端调用业务模块的打印数据接口取得 JSON 数据 → 用模板渲染成 HTML → 在新窗口预览（CSS `@page` 控制纸张和边距）→ 用户点击“打印”调用浏览器打印（可选“另存为 PDF”）。
- 选择理由：不需要服务端 PDF 渲染组件，模板可直接用 HTML 编写，排版灵活；浏览器打印支持跨页表头（`thead { display: table-header-group }`）。
- 内置帮助函数（前端注册）：`formatDate`、`formatDateTime`、`formatQty`（按单位精度）、`formatAmount`（千分位 2 位）、`formatPrice`、`amountInWordsCn`（人民币大写）、`amountInWordsEn`（英文金额大写，如 `SAY US DOLLARS ONE THOUSAND ... ONLY`）、`barcode`（Code128 条码 SVG）、`qrcode`、`dict`（字典标签）、`add`、`eq`。

## 3. 页面

### 3.1 打印模板列表（T1）

路由 `/system/print-template`，权限 `system:print:query`。

**查询条件**：单据类型（下拉，按模块分组）、语言、状态。

**列表列**：单据类型（140）、模板名称（200）、语言（80）、纸张（100）、默认（60，✓）、内置（60，✓）、状态（70）、修改时间（150）、操作。

**按钮**

| 按钮 | 权限 | 显示条件 | 行为 |
|---|---|---|---|
| 新建 | `system:print:create` | 始终 | 打开编辑器（空白模板或从同类型内置模板复制） |
| 编辑 | `system:print:update` | 非内置 | 打开编辑器 |
| 查看 | `system:print:query` | 内置 | 编辑器只读模式 |
| 复制 | `system:print:create` | 始终 | 复制为新模板（名称加“-副本”，非内置、非默认） |
| 设为默认 | `system:print:update` | 非默认且启用 | |
| 停用/启用 | `system:print:update` | 非默认 | 默认模板不能停用 |
| 删除 | `system:print:delete` | 非内置、非默认 | 二次确认 |

### 3.2 模板编辑器（全屏页面）

路由 `/system/print-template/:id/edit`（隐藏菜单）。

```
┌ ← 编辑模板：销售订单（标准）    单据类型[销售订单] 语言[中文] 纸张[A4纵向] 边距[10mm…] [保存] ┐
├ 变量（240px）──────┬ 模板代码（HTML）───────────────┬ 预览（示例数据）───────────────┤
│ ▾ 单头            │ <div class="header">            │  ┌──────────────────┐          │
│   docNo 单号      │   <h1>销售订单</h1>              │  │ 销售订单          │          │
│   docDate 日期    │   单号：{{docNo}}               │  │ 单号：SO-...      │          │
│ ▾ customer 客户   │ ...                             │  │ ...               │          │
│ ▾ lines 明细(数组) │                                 │  └──────────────────┘          │
│ ▾ 函数             │                                 │  [刷新预览] [用真实单据预览: ___] │
└───────────────────┴─────────────────────────────────┴──────────────────────────────┘
```

- 变量面板：树形展示 `variables`，点击变量在光标处插入 `{{path}}`；数组类型插入 `{{#each lines}}…{{/each}}` 片段。
- 代码区：带语法高亮的代码编辑器（CodeMirror 6，HTML 模式）。
- 预览区：输入内容 1 秒后自动用示例数据渲染；模板语法错误时预览区显示错误信息和行号。
- 真实单据预览：输入**单号**（也可输入单据 ID）后点 [真实单据预览]，按单号查到单据，刷新右侧预览并**弹出与正式打印相同的预览窗口**（可直接试打）；单号为空时提示 `请输入单号`，找不到时提示 `没有找到{单据类型}「{单号}」，请确认单号（或没有查看权限）`。眼睛图标在新窗口打开当前数据（示例或真实单据）的预览。
- 设置栏另有：每页行数（固定分页，针式多联纸）、联次（`|` 分隔）、打印方式（多联纸一次打印 / 普通纸逐联打印），见第 8 节。
- 保存时校验 R02。

### 3.3 打印操作（各业务页面通用，`PrintButton`）

- 单据详情页页头 [打印 ▾]：主按钮直接用当前语言的默认模板打印；下拉列出该单据类型的全部启用模板。
- 列表页工具栏 [打印]：勾选多张单据后批量打印（最多 50 张），每张单据分页。
- 打印预览窗口：顶部工具条 [打印] [关闭]，下方为渲染后的页面。
- 权限：打印需要该单据的 `xxx:print` 权限（各模块声明）。
- 草稿状态单据打印时在页面加灰色斜向水印“草稿”（针式模板在标题旁印“草稿”方框，灰色水印针式打印机印不出）；已作废单据不允许打印（`已作废的单据不能打印`）。
- 补打：单据此前已打印过时，本次在标题旁印“补打”，页脚印“补打，第 N 次打印”（按打印记录计数）。

## 4. 内置模板要求（各业务模块提供）

每个需要打印的单据至少提供一个中文内置模板，对外单据另提供英文模板。内置模板遵循《UI 设计规范》9.3 的版式：

1. 页眉：公司 Logo、公司名称（中文模板取组织名称/地址，英文模板取英文名称/英文地址，来自单据所属公司）、单据标题、右上角单号及其 Code128 条码。
2. 单头信息：两列或三列表格。
3. 明细表：带序号，表头每页重复；数量、金额右对齐。
4. 合计行、金额大写（中文模板）/ 英文大写（英文模板的 Invoice、PI）。
5. 备注、条款（如付款条件、交货条款）。
6. 签字栏：制单、审核、签收（按单据定义）。
7. 页脚：第 X 页 / 共 Y 页、打印时间、打印人。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SYS-PRT-R01 | 设为默认 | 同一单据类型 + 语言只有一个默认模板，设置新默认时自动取消旧默认 | — |
| SYS-PRT-R02 | 保存 | 模板能用示例数据渲染成功；内容 ≤ 200KB；不允许包含 `<script>`、`on*=` 事件属性、`javascript:` 链接（安全） | `模板渲染失败：{error}` / `模板中不允许包含脚本` |
| SYS-PRT-R03 | 打印 | 没有启用模板时 | `单据类型「{name}」没有可用的打印模板` |
| SYS-PRT-R04 | 打印 | 数据接口按当前用户权限返回；字段权限不足的字段在数据中为 `null`，模板显示 `***`（帮助函数统一处理） | — |
| SYS-PRT-R05 | 启动 | 内置模板不存在时从模块资源文件 `print-templates/<bizType>-<language>.html` 导入；已存在的不覆盖。针式模板 `<bizType>-zh-CN-dot.html` 同样导入（变体 builtin_key = zh-CN-dot），导入时若中文默认模板仍是内置标准模板，则针式模板设为默认；内置针式模板只读，资源文件更新后启动时同步到已导入的模板 | — |
| SYS-PRT-R06 | 打印 | 设了每页行数的模板按固定行数分页：每页单独渲染（单头、表头、签名栏每页都有），不足补空行，合计只在最后一页（其余页“本页小计”）；页面高度固定为纸张高度，超出部分裁掉，保证每页落在一张多联纸上 | — |
| SYS-PRT-R07 | 打印 | 对内流转的针式单据（送货单、销售订单、销售退货单、出入库单等）中**客户只打印客户编号**，不打印客户名称、联系人、地址、客户 PO、客户料号；供应商照常打印名称 | — |

## 8. 针式多联打印

### 8.1 纸张与模板设置

| 纸张（sys_print_paper） | 尺寸 | 说明 |
|---|---|---|
| DOT_241_140 针式二等分 | 9.5 × 5.5 英寸（241 × 139.7mm） | **默认**，内置针式模板均为二等分 |
| DOT_241_93 针式三等分 | 9.5 × 3.67 英寸（241 × 93.1mm） | 明细很少的单据（复制模板后改纸张和每页行数，约 9 行） |
| DOT_241_280 针式整张 | 9.5 × 11 英寸（241 × 279.4mm） | 明细多的单据 |

按精确英寸设置页面尺寸，连续纸打印多页不会累积走纸误差。sys_print_template 新增：`rows_per_page`（每页行数，空为自动分页）、`copies_note`（联次说明）、`copy_mode`（CARBON 多联纸一次打印 / REPEAT 普通纸逐联打印，每页按联数重复并标出当前联）、`builtin_key`。

### 8.2 模板变量（打印引擎附加）

| 变量 | 说明 |
|---|---|
| company.name / nameEn / address / phone / taxNo / logo | 打印抬头（组织架构中公司的名称、英文名、Logo） |
| page.lines / page.no / page.count / page.isFirst / page.isLast / page.blanks | 固定分页：本页明细、页码、补空行用数组 |
| copies[].no / copies[].text、copy | 联次（逐联打印时 copy 为当前联） |
| print.count / print.reprint / print.draft / print.printedAt / print.printedBy | 第几次打印、是否补打、是否草稿、打印时间、打印人 |
| 帮助函数 sum、gt、or | `{{formatQty (sum page.lines "qty")}}` 本页小计 |

各单据打印数据统一补充：`createdByName`（制单）、`auditByName`（审核，系统无审核人时留空手签）、`ownerName`（责任人）、`deptName`（车间 / 部门）、`orgId`（打印抬头公司）、`status`（草稿判断）、`customerCode`（客户编号）。

### 8.3 内置针式模板（二等分，多联纸）

版式统一（二等分 241×140mm，边距 5/6/4/6mm）：
- 页眉：Logo + 公司中英文名 | 单据标题（领料单按领料原因）+ 草稿/补打 | 单号 + 宽条码（55mm，单条线约 2 个针点，不含文字）+ 日期 + 页码；页眉下一条细线。
- 单头：**不画线、不用表格**，4 列等宽的“标签 - 内容”网格，标签定宽、靠左对齐，内容加粗，同一列的内容上下对齐。
- 明细表：细线网格，正文与表头 8.5pt，行高约 4.6mm；每页 16 行（三行单头的采购订单 15 行）。名称、规格等文本左对齐；序号、单位居中；数量、金额、单价右对齐，并用 `decAlign` 帮助函数让小数点上下对齐。
- 合计行（非最后一页为“本页小计”）、备注一行。
- 签名栏：等分网格、纯文本（`制单：张三`），不画线，冒号后手签。
- 页脚：6.5pt 一行，左侧打印时间、打印人、补打次数，右侧公司地址电话；右侧竖排联次。

| 单据 | 联次 | 签名栏 |
|---|---|---|
| 入库单 INV_STOCK_IN | ①白 存根 ②红 财务 ③黄 仓库 | 制单、审核、仓管、送货/交料人、品质 |
| 出库单 INV_STOCK_OUT | ①白 存根 ②红 财务 ③黄 仓库 | 制单、审核、仓管（发料）、领料/提货人 |
| 调拨单 INV_TRANSFER | ①白 存根 ②红 调出仓 ③黄 调入仓 | 制单、审核、调出仓管、调入仓管、搬运人 |
| 领料单 MFG_ISSUE（标题按领料原因：生产 / 样品 / 重工 / 拆解领料单，超领为“××超领单”并印超领原因） | ①白 存根 ②红 仓库 ③黄 车间 | 制单、审核、责任人、仓管（发料）、领料人 |
| 退料单 MFG_RETURN | ①白 存根 ②红 仓库 ③黄 车间 | 制单、审核、退料人、品质、仓管（收料） |
| 完工入库单 MFG_FINISH（新增打印） | ①白 存根 ②红 仓库 ③黄 生产 | 制单、审核、生产主管、品质（FQC）、仓管（收货） |
| 到货单 PUR_RECEIPT | ①白 存根 ②红 供应商 ③黄 仓库 | 制单、收货、品质（IQC）、仓管、送货人 |
| 采购退货单 PUR_RETURN | ①白 存根 ②红 供应商 ③黄 仓库 | 制单、审核、仓管、品质、供应商签收 |
| 采购订单 PUR_ORDER | ①白 存根 ②红 供应商 | 制单、审核、采购员、供应商确认 |
| 送货单 SHP_SHIPMENT | ①白 存根 ②红 客户签收回单 ③黄 财务 ④蓝 仓库 | 制单、审核、仓管、送货人、客户签收（签字/盖章/日期） |
| 销售退货单 SAL_RETURN | ①白 存根 ②红 财务 ③黄 仓库 | 制单、审核、业务、品质、仓管（收货） |
| 销售订单 SAL_ORDER | ①白 存根 ②红 客户 | 制单、审核、业务员、客户确认 |

原 A4 标准模板保留，可在打印按钮下拉中切换；英文 PI / Invoice 等对外单据仍用标准模板。

## 9. 可视化版式（勾选打印条目）

模板可带一份**版式**（`sys_print_template.layout`，JSON，V11 新增）。带版式的模板在编辑器中默认进入「可视化」方式：

| 区块 | 可操作 |
|---|---|
| 页眉 | 是否打印公司 Logo、公司英文名、单号条码；标题 / 副标题（可含表达式，如领料单按领料原因）；正文字号 8～10pt |
| 单头信息 | 每个条目可勾选是否打印、改名称、占 1～4 列、上下移动、删除；可添加单据字段或「空白项」（只印标签，内容手写） |
| 明细列 | 勾选是否打印、改列名、相对宽度、对齐、数量 / 金额列是否合计、左右移动、删除；可添加明细字段或「空白列」。取消勾选的列不占位置，其余列按宽度比例铺满 |
| 签名栏 | 勾选、改名称、双倍宽、移动、删除；可添加空白签名项（手签）或带出姓名的人员字段（如制单人、审核人） |
| 备注与页脚 | 备注行、打印时间 / 打印人 / 补打次数、公司地址电话 |

规则：

- R01 每次修改版式即由前端重新生成模板代码（`utils/print/layoutTemplate.ts`），预览约 0.3 秒内刷新；预览按预览区宽度缩放显示整页，新窗口预览为实际尺寸。
- R02 带版式时模板代码只读（由版式生成）；点「改为代码编辑」确认后去掉版式，之后只能改代码。没有版式的模板可点「使用可视化版式」按单据字段生成一份（会替换现有代码）。
- R03 内置针式模板（第 8 节）随附版式文件 `print-templates/<biz>-zh-CN-dot.layout.json`，启动时与模板一起导入 / 同步；内置模板只读，复制后即可勾选条目。新建模板「从内置模板开始」时优先复制默认的内置模板（即针式模板）。
- R04 版式必须是 JSON 对象（≤ 100KB），否则提示「版式格式不正确」（1_001_015_009）；复制模板时版式一并复制。
- R05 修改内置针式模板的版式文件后执行 `cd erp-ui && node scripts/gen-dot-templates.mjs` 重新生成对应 `.html`，两者一起提交。

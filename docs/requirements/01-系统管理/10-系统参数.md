# 01-10 系统参数

## 1. 功能说明

集中维护影响业务行为的开关和数值，例如“是否允许负库存”“采购超收比例”。参数由各模块通过 `ParamDefinition` 声明（编码、名称、类型、默认值、说明、分组），管理员在界面上修改值。

- 使用者：系统管理员
- 优先级：P0

## 2. 数据表

### sys_param 系统参数

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| param_key | str(128) | 是 | | 参数编码，唯一，格式 `模块.分组.名称`，如 `inv.stock.allow-negative` |
| module_code | str(32) | 是 | | 模块 |
| group_name | str(32) | 是 | | 分组（页面上的小节），如“库存控制” |
| name | str(64) | 是 | | 参数名称 |
| value_type | enum(STRING/INT/DECIMAL/BOOL/ENUM/USER_LIST/TIME) | 是 | | 值类型 |
| options | json | 否 | | ENUM 的选项 `[{value, label}]` |
| min_value / max_value | str(32) | 否 | | INT/DECIMAL 的范围 |
| value | str(1024) | 否 | | 当前值（字符串存储） |
| default_value | str(1024) | 否 | | 默认值（来自声明） |
| description | str(512) | 是 | | 说明：作用、影响、建议值 |
| sort | int | 是 | 0 | |
| active | bool | 是 | 1 | 声明被移除时为 0，页面不显示 |

唯一：`uk_param_key(param_key)`。

## 3. 页面

### 3.1 系统参数（T8）

路由 `/system/param`，权限 `system:param:query`。

- 左侧导航：按模块列出（系统管理、销售、资材、仓库……），显示该模块参数数量。
- 右侧：选中模块的参数，按分组显示为卡片；每个参数一行：名称（加粗）、控件、说明（12px 灰色）、“已修改”标记（值 ≠ 默认值时显示橙色小标签，悬停显示默认值）、[恢复默认] 链接。
- 控件按类型：STRING 输入框、INT/DECIMAL 数字框（带范围）、BOOL 开关、ENUM 下拉、USER_LIST UserSelect 多选、TIME 时间选择（HH:mm）。
- 底部 [保存]（`system:param:update`）：只提交修改过的参数；保存前弹窗列出修改项“库存控制 / 允许负库存：否 → 是”，确认后保存。
- 顶部搜索框：按名称或编码过滤全部参数。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SYS-PAR-R01 | 保存 | 值必须符合类型和范围 | `参数「{name}」的值必须在 {min}～{max} 之间` |
| SYS-PAR-R02 | 保存 | 参数变更记录到操作日志（旧值、新值） | — |
| SYS-PAR-R03 | 读取 | `ParamApi` 读取带缓存；保存后立即清除缓存 | — |
| SYS-PAR-R04 | 启动 | 声明的参数不存在则按默认值创建；已存在的不覆盖值，但更新名称、说明、选项 | — |

## 6. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | /system/params?module= | `system:param:query` | 按模块获取参数（含分组） |
| PUT | /system/params | `system:param:update` | 批量保存 `[{key, value}]` |
| POST | /system/params/{key}/reset | `system:param:update` | 恢复默认 |
| GET | /system/params/public | 不需登录 | 登录页需要的公开参数（系统名称、验证码策略） |

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SYS-PAR-T01 | — | 把“登录失败锁定次数”改为 11 | 数字框最大只能输入 10；接口提交 11 返回范围错误 |
| SYS-PAR-T02 | — | 修改两个参数后保存 | 确认弹窗列出 2 项变更；操作日志中记录旧值新值 |
| SYS-PAR-T03 | 参数已修改 | 恢复默认 | 值恢复为默认值，“已修改”标记消失 |
| SYS-PAR-T04 | 仓库允许负库存=否 | 改为是并保存 | 立即生效，无需重启 |

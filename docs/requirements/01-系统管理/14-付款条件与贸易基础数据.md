# 01-14 付款条件与贸易基础数据

## 1. 功能说明

客户、供应商、销售订单、采购订单、应收应付共用的交易基础数据：

| 数据 | 形式 | 说明 |
|---|---|---|
| 付款条件 | 独立表 | 如“30% 定金，70% 见提单副本”“月结 60 天”。包含若干付款节点，销售/采购据此生成回款/付款计划，财务据此计算到期日 |
| 贸易条款 | 字典 `sys_trade_term` | EXW、FOB、CFR、CIF、DAP、DDP 等（Incoterms 2020） |
| 结算方式 | 字典 `sys_settlement_method` | 电汇 T/T、信用证 L/C、承兑汇票、现金、支票 |
| 国家/地区 | 内置静态数据 | ISO 3166-1 二位代码 + 中英文名称，不可维护 |

- 使用者：系统管理员、财务
- 优先级：P0

## 2. 数据表

### sys_payment_term 付款条件

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| code | str(32) | 是 | | 唯一，如 `NET60`、`TT30-70BL` |
| name | str(64) | 是 | | 中文名称，如“30% 定金，70% 见提单” |
| name_en | str(128) | 否 | | 英文，用于 PI、Invoice，如 `30% T/T in advance, 70% against B/L copy` |
| settlement_method | dict(sys_settlement_method) | 是 | TT | 结算方式 |
| usage | enum(SALES/PURCHASE/BOTH) | 是 | BOTH | 适用范围 |
| status | enum(ENABLED/DISABLED) | 是 | ENABLED | |
| remark | str(256) | 否 | | |

### sys_payment_term_node 付款节点

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| term_id | id | 是 | |
| seq | int | 是 | 顺序 |
| name | str(32) | 是 | 节点名称，如“定金”“尾款” |
| percent | pct | 是 | 比例，所有节点合计 = 100% |
| base_event | enum(ORDER_DATE/BEFORE_SHIPMENT/SHIPMENT/BL_DATE/INVOICE_DATE/RECEIPT_DATE/MONTH_END) | 是 | 起算事件：下单日 / 出货前 / 出货日 / 提单日 / 开票日 / 到货（入库）日 / 月结（出货或入库当月月末） |
| days | int | 是 | 起算后天数（0～365）；BEFORE_SHIPMENT 表示出货前必须收到，天数为 0 |

### 字典（内置项）

`sys_trade_term`：EXW、FCA、FOB、CFR、CIF、CPT、CIP、DAP、DPU、DDP（内置，值即代码，标签如“FOB 船上交货”）。

`sys_settlement_method`：TT 电汇、LC 信用证、BANK_ACCEPTANCE 银行承兑汇票、CASH 现金、CHECK 支票、OTHER 其他（内置）。

### 初始付款条件

| 编码 | 名称 | 节点 |
|---|---|---|
| PREPAID | 100% 预付 | 100%，下单日 0 天 |
| TT30-70BS | 30% 定金，70% 出货前付清 | 30% 下单日 0 天；70% 出货前 |
| TT30-70BL | 30% 定金，70% 见提单副本 | 30% 下单日 0 天；70% 提单日 0 天 |
| NET30 | 出货后 30 天 | 100% 出货日 30 天 |
| MONTHLY60 | 月结 60 天 | 100% 月结 60 天（当月月末 + 60 天） |
| PUR_MONTHLY30 | 采购月结 30 天 | 100% 月结 30 天（入库当月月末 + 30 天），usage=PURCHASE |

## 3. 到期日计算（全系统统一，`PaymentTermApi.calcDueDates`）

输入：付款条件、单据金额、各事件日期（下单日、出货日、提单日、开票日、入库日）。输出：每个节点的金额和到期日。

- 节点金额 = ROUND(单据金额 × 比例, 2)，最后一个节点 = 单据金额 − 前面节点之和（消除尾差）。
- 到期日 = 事件日期 + 天数；MONTH_END = 事件所在月最后一天 + 天数。
- 事件尚未发生（如尚未出货）时到期日为空，事件发生后由业务模块重新计算。

## 4. 页面

### 4.1 付款条件（T1 + T2）

路由 `/system/payment-term`（系统管理菜单“付款条件”），权限 `system:payment-term:query`。

- 查询：关键字、适用范围、状态。
- 列：编码、名称、英文名称、结算方式、适用范围、节点摘要（“30% 下单日 / 70% 提单日”）、状态、操作（编辑、停用/启用、删除）。
- 表单（大弹窗）：编码*、名称*、英文名称、结算方式*、适用范围*、备注；节点表格：名称*、比例(%)*、起算事件*、天数*；表格下方显示比例合计，≠100% 时红色。

### 4.2 国家列表

不提供维护页面。接口 `GET /system/countries` 返回 `[{code, nameCn, nameEn}]`，前端 `CountrySelect` 组件使用（支持中文、英文、代码搜索）。

## 5. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| SYS-PT-R01 | 编码唯一 | `付款条件编码「{code}」已存在` |
| SYS-PT-R02 | 至少一个节点，比例合计 100% | `付款节点比例合计必须等于 100%` |
| SYS-PT-R03 | 被客户、供应商或单据引用后不能删除，只能停用；修改节点只影响之后新建的单据（单据保存付款条件快照） | `该付款条件已被使用，只能停用` |

## 6. 接口

`/system/payment-terms`（CRUD、enable/disable）、`/system/payment-terms/simple?usage=`（登录即可）、`/system/countries`。Java：`PaymentTermApi.get(id)`、`calcDueDates(termId, amount, events)`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SYS-PT-T01 | TT30-70BL，订单 10,000.01 | 计算 | 定金 3,000.00（下单日到期），尾款 7,000.01（提单日未知，到期日为空） |
| SYS-PT-T02 | MONTHLY60，出货日 2026-09-15 | 计算 | 到期日 2026-11-29（9-30 + 60 天） |
| SYS-PT-T03 | 节点 30% + 60% | 保存 | 提示“付款节点比例合计必须等于 100%” |

# 01-04 数据字典

## 1. 功能说明

数据字典用于维护**可由用户扩展的选项**，例如岗位、客户行业、付款方式、缺陷分类、报废原因。

**字典与枚举的区别**（开发时必须遵守）：

| | 枚举（代码中定义） | 字典（数据库中维护） |
|---|---|---|
| 适用 | 程序逻辑依赖其取值：单据状态、物料类型、仓库类型、数据范围 | 程序逻辑不依赖具体取值，只做展示、筛选、统计 |
| 能否新增项 | 不能（需要改代码） | 管理员可在界面新增 |
| 存储 | 字段存枚举名 | 字段存字典项值 |

如果某个字典的个别项被程序逻辑使用（如“付款方式=预付”），该项必须标记为“内置”，内置项不可删除、不可停用、不可修改值。

- 使用者：系统管理员
- 优先级：P0

## 2. 数据表

### sys_dict_type 字典类型

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| code | str(64) | 是 | | 类型编码，唯一，小写字母数字下划线，建议以模块编码开头，如 `crm_industry` |
| name | str(64) | 是 | | 名称 |
| module_code | str(32) | 是 | | 所属模块；管理员新建的为 `custom` |
| is_builtin | bool | 是 | 0 | 由模块声明的为 1，不可删除，编码不可修改 |
| status | enum(ENABLED/DISABLED) | 是 | ENABLED | |
| remark | str(256) | 否 | | |

唯一：`uk_code(code)`。

### sys_dict_item 字典项

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| type_code | str(64) | 是 | | 所属类型 |
| value | str(32) | 是 | | 项值（存入业务表），类型内唯一，大写字母数字下划线 |
| label | str(64) | 是 | | 中文标签 |
| label_en | str(128) | 否 | | 英文标签（英文界面和英文单据使用，为空时用中文） |
| tag_type | enum(DEFAULT/PRIMARY/SUCCESS/WARNING/DANGER/INFO) | 是 | DEFAULT | 在 DictTag 中显示的颜色 |
| sort | int | 是 | 0 | |
| is_default | bool | 是 | 0 | 新建表单时的默认选项，每个类型最多一个 |
| is_builtin | bool | 是 | 0 | 内置项 |
| status | enum(ENABLED/DISABLED) | 是 | ENABLED | 停用项不能在新数据中选择，已有数据仍能显示标签 |
| remark | str(256) | 否 | | |

唯一：`uk_type_value(type_code, value)`。

## 3. 页面

### 3.1 数据字典（左右分栏）

路由 `/system/dict`，权限 `system:dict:query`。

```
┌ 字典类型（40%） ─────────────────────┬ 字典项：客户行业 crm_industry（60%） ────────────┐
│ [关键字____] [查询]      [+ 新建类型] │ [+ 新建字典项]                                 │
│ 编码           名称      模块   状态   │ 值         标签      英文标签   颜色  排序 默认 状态 操作 │
│ crm_industry  客户行业   CRM   启用 ● │ ELECTRONIC 电子      Electronics ■    10   ✓   启用 编辑 │
│ sys_position  岗位      系统   启用   │ ...                                            │
└──────────────────────────────────────┴───────────────────────────────────────────────┘
```

**左侧：字典类型列表**

- 查询条件：关键字（编码/名称，模糊）、模块（下拉）。
- 列：编码（160）、名称（140）、模块（90）、状态（70）、操作（编辑、删除）。
- 单击行选中，右侧显示该类型的字典项；默认选中第一行。
- 内置类型名称后显示“内置”标签，不显示删除按钮。

**右侧：字典项列表**（不分页，按排序升序）

| 列 | 字段 | 宽度 | 说明 |
|---|---|---|---|
| 值 | value | 140 | |
| 标签 | label | 140 | 以 DictTag 样式预览颜色 |
| 英文标签 | label_en | 160 | |
| 排序 | sort | 70 | |
| 默认 | is_default | 60 | ✓ |
| 状态 | status | 70 | |
| 操作 | — | 160 | 编辑、停用/启用、删除（内置项只显示编辑） |

**按钮**

| 按钮 | 权限 | 显示条件 | 行为 |

| 新建类型 | `system:dict:create` | 始终 | 类型表单弹窗 |

| 删除类型 | `system:dict:delete` | 非内置 | R04 |
| 新建字典项 | `system:dict:create` | 已选中类型 | 字典项表单弹窗 |
| 编辑字典项 | `system:dict:update` | 始终 | 内置项的值不可改 |
| 停用/启用字典项 | `system:dict:update` | 非内置 | |
| 删除字典项 | `system:dict:delete` | 非内置 | R05 |

## 4. 状态与流转

类型、字典项：启用 ⇄ 停用（内置不可停用）。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SYS-DIC-R01 | 保存类型 | 类型编码唯一 | `字典类型「{code}」已存在` |
| SYS-DIC-R02 | 保存项 | 同一类型下值唯一 | `字典值「{value}」已存在` |
| SYS-DIC-R03 | 保存项 | 同一类型下标签唯一 | `字典标签「{label}」已存在` |
| SYS-DIC-R04 | 删除类型 | 内置类型不能删除；有字典项时不能删除 | `内置字典不能删除` / `请先删除该类型下的字典项` |
| SYS-DIC-R05 | 删除项 | 内置项不能删除；已被业务数据使用的项不能删除（通过 `DictReferenceChecker` 扩展点，由声明该字典的模块提供检查；未提供检查的视为已使用，只能停用） | `该字典项已被使用，只能停用` |
| SYS-DIC-R06 | 启动 | 模块声明的内置字典：类型不存在则创建；内置项不存在则补充；已存在的不覆盖管理员修改的标签、颜色、排序 | — |
| SYS-DIC-R07 | 业务保存 | 业务表存字典值时，后端必须用 `DictApi.validate(type, value)` 校验值存在且启用（修改时如果值未变化则允许已停用的值） | `{字段名}的值「{value}」无效` |

## 6. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | /system/dict-types | `system:dict:query` | 类型分页 |
| POST / PUT / DELETE | /system/dict-types[/{id}] | create / update / delete | |
| GET | /system/dict-items?typeCode= | `system:dict:query` | 某类型全部项（含停用） |
| POST / PUT / DELETE | /system/dict-items[/{id}] | create / update / delete | |
| POST | /system/dict-items/{id}/enable、/disable | `system:dict:update` | |
| GET | /system/dicts/all | 登录即可 | 全部启用类型的启用项 + 停用项（停用项带标记，用于显示历史数据标签），以及版本号 `version`（字典任意变更时 +1）。前端登录后加载并缓存；每 10 分钟用 `GET /system/dicts/version` 比较版本，变化时重新加载 |
| GET | /system/dicts/version | 登录即可 | 当前字典版本号 |
| POST | /system/dicts/refresh-cache | `system:dict:update` | 清除缓存 |

## 8. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SYS-DIC-T01 | — | 新建类型 `crm_source` 客户来源，添加项“展会 EXPO”“官网 WEBSITE” | 客户表单中“客户来源”下拉出现这两项 |
| SYS-DIC-T02 | EXPO 已被客户使用 | 删除 EXPO | 提示“该字典项已被使用，只能停用” |
| SYS-DIC-T03 | EXPO 停用 | 新建客户 | 下拉中没有“展会”；已有客户详情仍显示“展会” |
| SYS-DIC-T04 | — | 把 WEBSITE 设为默认 | EXPO 的默认标记被自动取消；新建客户时来源默认“官网” |
| SYS-DIC-T05 | 内置字典项 | 编辑 | 值输入框不可编辑；没有删除、停用按钮 |
| SYS-DIC-T06 | 用户 A 已登录，管理员修改了某项标签 | 10 分钟内 | 用户 A 页面上的标签更新为新值（无需重新登录） |

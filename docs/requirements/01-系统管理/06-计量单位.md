# 01-06 计量单位

## 1. 功能说明

维护计量单位、单位精度和**通用换算**（与物料无关的换算，如 1 KG = 1000 G）。

与物料相关的换算（如某物料 1 箱 = 100 PCS、1 卷 = 3000 PCS）在物料上维护（见 05-研发工程 / 物料），不在本页面。

- 使用者：系统管理员
- 优先级：P0

**单位类别**（枚举，决定哪些单位之间可以做通用换算）：数量 COUNT、重量 WEIGHT、长度 LENGTH、面积 AREA、体积 VOLUME、时间 TIME。只有同类别的单位才能建立通用换算。

## 2. 数据表

### sys_uom 计量单位

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| code | str(16) | 是 | | 单位编码，唯一，大写，如 `PCS`、`KG` |
| name | str(16) | 是 | | 中文名称，如“个”“千克” |
| name_en | str(32) | 否 | | 英文名称（英文单据使用，为空时用编码），如 `pcs`、`kg` |
| category | enum(COUNT/WEIGHT/LENGTH/AREA/VOLUME/TIME) | 是 | | 类别 |
| precision | int | 是 | 0 | 数量小数位数 0～4（数据库统一存 4 位，显示和输入按此精度） |
| sort | int | 是 | 0 | |
| is_builtin | bool | 是 | 0 | 内置单位不可删除、不可改编码 |
| status | enum(ENABLED/DISABLED) | 是 | ENABLED | |

唯一：`uk_code(code)`。

### sys_uom_conversion 通用换算

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| from_uom | str(16) | 是 | 源单位 |
| to_uom | str(16) | 是 | 目标单位 |
| rate | rate | 是 | 1 源单位 = rate 目标单位，> 0 |

唯一：`uk_from_to(from_uom, to_uom)`。只需维护一个方向，反向自动按 1/rate 计算。

## 3. 页面

### 3.1 计量单位（T1，上下两个卡片）

路由 `/system/uom`，权限 `system:uom:query`。

**卡片一：计量单位**（不分页，按类别、排序）

- 查询条件：关键字（编码/名称）、类别、状态。
- 列：编码（100）、名称（100）、英文名称（120）、类别（90）、精度（70，右）、状态（70）、操作（编辑、停用/启用、删除）。
- 工具栏：[新建]（`system:uom:create`）。

**卡片二：通用换算**

- 列：源单位（显示“1 KG”）、= 、目标单位数量（显示“1000 G”）、操作（编辑、删除）。
- 工具栏：[新建换算]（`system:uom:update`）。

### 3.2 单位表单（T2 中弹窗）

| 字段 | 控件 | 必填 | 默认 | 可编辑 | 校验 |
|---|---|---|---|---|---|

| 名称 | 输入框 | 是 | | 始终 | ≤16；R02 |
| 英文名称 | 输入框 | 否 | | 始终 | ≤32 |
| 类别 | 下拉 | 是 | 数量 | 未被使用时 | R04 |
| 精度 | 数字框 0～4 | 是 | 0 | 始终 | R05 |
| 排序 | 数字框 | 是 | | 始终 | |

### 3.3 换算表单（T2 小弹窗）

| 字段 | 控件 | 必填 | 校验 |
|---|---|---|---|
| 源单位 | UomSelect | 是 | |
| 换算率 | 数字框（6 位小数） | 是 | > 0 |

表单下方实时显示“1 KG = 1000 G，1 G = 0.001 KG”。

## 4. 状态与流转

启用 ⇄ 停用。停用的单位不能在新的物料、单据中选择。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SYS-UOM-R01 | 保存 | 编码唯一 | `单位编码「{code}」已存在` |
| SYS-UOM-R02 | 保存 | 名称唯一 | `单位名称「{name}」已存在` |
| SYS-UOM-R03 | 删除 | 内置单位不能删除；被物料或换算引用的单位不能删除（通过 `UomReferenceChecker`，研发工程模块提供） | `该单位已被使用，只能停用` |
| SYS-UOM-R04 | 修改类别 | 已被物料引用的单位不能修改类别 | `该单位已被使用，不能修改类别` |
| SYS-UOM-R05 | 修改精度 | 精度只能调大；调小会导致已有数据被截断 | `单位精度只能调大` |
| SYS-UOM-R06 | 保存换算 | 源单位与目标单位类别相同；同一对单位（含反向）只能有一条 | `只能在同类别单位之间换算` / `该换算已存在` |
| SYS-UOM-R07 | 换算 | `UomApi.convert(qty, from, to)`：相同单位直接返回；有直接或反向换算按其计算；否则通过同类别的一个中间单位换算一次（最多一次中转）；都没有时报错 | `单位 {from} 与 {to} 之间没有换算关系` |
| SYS-UOM-R08 | 舍入 | 所有数量按单位精度 HALF_UP 舍入（`UomApi.round`），业务模块保存数量前必须调用 | — |

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SYS-UOM-T01 | 内置数据 | `convert(2.5, KG, G)` | 2500 |
| SYS-UOM-T02 | 内置数据 | `convert(500, G, KG)` | 0.5 |
| SYS-UOM-T03 | 内置数据 | `convert(1, T, G)` | 1000000（通过 KG 中转） |
| SYS-UOM-T04 | — | 新建换算 KG → M | 目标单位下拉中没有 M；接口提交返回“只能在同类别单位之间换算” |
| SYS-UOM-T05 | PCS 精度 0 | 采购订单数量输入 10.5 PCS | 输入框只能输入整数 |
| SYS-UOM-T06 | KG 精度 3 | 改为 2 | 提示“单位精度只能调大” |
| SYS-UOM-T07 | PCS 被物料使用 | 删除 PCS | 提示内置不能删除（内置单位不显示删除按钮） |

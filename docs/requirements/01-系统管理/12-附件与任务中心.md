# 01-12 附件、任务中心、定时任务

## 1. 附件

### 1.1 功能说明

所有单据和主数据的附件上传、下载、预览、删除，由系统管理统一提供，业务模块通过 `AttachmentPanel` 组件和 `FileApi` 使用。

- 优先级：P0（单据附件在一期即需要）
- 存储后端可配置：本地磁盘（默认，`erp.file.local-path`）/ MinIO / S3 兼容对象存储（`erp.file.storage=local|s3`）。

### 1.2 数据表：sys_file

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| biz_type | str(64) | 否 | 所属业务类型；上传后未绑定前为空 |
| biz_id | id | 否 | 所属业务 ID |
| category | str(32) | 否 | 附件分类（业务自定义，如 DRAWING 图纸、CERT 证书），空为普通附件 |
| file_name | str(255) | 是 | 原始文件名 |
| ext | str(16) | 是 | 扩展名（小写） |
| content_type | str(128) | 是 | |
| size | bigint | 是 | 字节 |
| sha256 | str(64) | 是 | 内容哈希 |
| storage | enum(LOCAL/S3) | 是 | |
| path | str(512) | 是 | 存储路径：`{yyyy}/{MM}/{uuid}.{ext}` |
| bound | bool | 是 | 是否已绑定业务 |

索引：`idx_biz(biz_type, biz_id)`。

### 1.3 交互（AttachmentPanel）

- 列表：文件名（链接，点击下载）、大小（KB/MB）、上传人、上传时间、操作（预览、下载、删除）。
- 上传：拖拽或点击，可多选；显示进度；图片和 PDF 支持在线预览（新窗口），其他类型直接下载。
- 可编辑性由业务页面传入（通常草稿状态可上传/删除，其他状态只读；各单据文档可另行规定，如“已审核单据允许追加附件”）。

### 1.4 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| SYS-FIL-R01 | 大小不超过参数 `sys.file.max-size-mb` | `文件大小不能超过 {n}MB` |
| SYS-FIL-R02 | 扩展名在 `sys.file.allowed-ext` 中；并校验文件头（魔数）与扩展名一致，防止伪装 | `不支持的文件类型：{ext}` |
| SYS-FIL-R03 | 新建单据时先上传（未绑定），保存单据时 `FileApi.bind(fileIds, bizType, bizId)` 绑定；超过 24 小时未绑定的文件由定时任务清理 | — |
| SYS-FIL-R04 | 下载、预览校验权限：调用方必须对 `biz_type` 对应单据有查看权限（通过 `FileAccessChecker` 扩展点，由业务模块提供；未提供的只允许上传人和管理员下载） | `没有权限访问该附件` |
| SYS-FIL-R05 | 删除为逻辑删除；物理文件保留 30 天后清理 | — |
| SYS-FIL-R06 | 下载文件名使用原始文件名（`Content-Disposition` 使用 RFC 5987 编码，中文不乱码） | — |

### 1.5 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /system/files | 上传（multipart），返回 id、文件名、大小 |
| GET | /system/files?bizType=&bizId= | 列表 |
| GET | /system/files/{id}/download | 下载 |
| GET | /system/files/{id}/preview | 预览（inline） |
| DELETE | /system/files/{id} | 删除（业务模块控制可编辑性，由 `FileAccessChecker.canEdit` 判断） |

## 2. 任务中心（异步任务）

### 2.1 功能说明

耗时操作（大批量导出、大批量导入、MRP 运算、成本计算等）以后台任务执行，用户在“任务中心”查看进度和下载结果。

- 路由 `/system/task`，所有登录用户可访问，只能看到自己提交的任务（管理员有 `system:task:all` 权限时可看全部）。
- 优先级：P1

### 2.2 数据表：sys_async_task

| 字段 | 类型 | 说明 |
|---|---|---|
| task_type | str(32) | EXPORT / IMPORT / MRP / COST_CALC / ... |
| name | str(128) | 如“导出物料列表” |
| module_code | str(32) | |
| status | enum(WAITING/RUNNING/SUCCESS/FAILED/CANCELED) | |
| progress | int | 0～100 |
| result_file_id | id | 结果文件（导出文件、导入错误报告） |
| result_message | str(1024) | 结果说明，如“成功导出 25,318 行” |
| error_message | str(1024) | 失败原因 |
| submitted_by | id | |
| started_at / finished_at | datetime | |

### 2.3 页面（T1）

- 查询条件：类型、状态、提交时间（默认近 7 天）。
- 列：任务名称、类型、状态（运行中显示进度条）、提交时间、完成时间、耗时、结果说明、操作（下载结果、取消（等待中）、查看错误）。
- 运行中的任务每 3 秒自动刷新状态。
- 任务完成时向提交人发送工作台消息“你的任务【导出物料列表】已完成”，点击跳转任务中心。

### 2.4 规则

| 编号 | 规则 |
|---|---|
| SYS-TSK-R01 | 同一用户同时运行的任务不超过 3 个，超出进入等待；全系统并发任务数由线程池大小控制（默认 4） |
| SYS-TSK-R02 | 应用重启时 RUNNING 状态的任务标记为 FAILED（原因“服务重启，任务中断，请重新提交”） |
| SYS-TSK-R03 | 结果文件保留 7 天，过期后删除，列表中“下载”按钮隐藏并显示“已过期” |

### 2.5 接口

`GET /system/tasks`、`GET /system/tasks/{id}`、`POST /system/tasks/{id}/cancel`。Java API：`AsyncTaskApi.submit(type, name, moduleCode, TaskRunner)`，`TaskRunner` 可通过回调更新进度。

## 3. 定时任务

### 3.1 功能说明

查看和管理由各模块声明的定时任务（`@ErpJob(code, name, defaultCron)`），如汇率提醒、日志清理、MRP 夜间运算、库存预警检查。

- 路由 `/system/job`，权限 `system:job:query`。
- 优先级：P1

### 3.2 数据表

**sys_job**：`code`（唯一）、`name`、`module_code`、`cron`、`default_cron`、`enabled`、`last_run_at`、`last_result`、`next_run_at`。

**sys_job_log**：`job_code`、`started_at`、`finished_at`、`result(SUCCESS/FAILED)`、`message`、`trigger(SCHEDULE/MANUAL)`、`operator_id`。保留 90 天。

### 3.3 页面（T1）

- 列：任务编码、名称、模块、Cron 表达式（悬停显示中文说明，如“每天 02:00”）、状态（启用/停用开关，`system:job:update`）、上次执行时间、上次结果、下次执行时间、操作（[立即执行]、[编辑 Cron]、[执行日志]）。
- 编辑 Cron：输入框 + 下方显示最近 5 次执行时间预览；[恢复默认]。

### 3.4 规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| SYS-JOB-R01 | Cron 表达式必须合法 | `Cron 表达式不正确` |
| SYS-JOB-R02 | 多实例部署时同一任务同一时刻只在一个实例执行（数据库锁：`UPDATE sys_job SET locked_until=? WHERE code=? AND locked_until < now()`） | — |
| SYS-JOB-R03 | 任务正在执行时“立即执行”提示 | `任务正在执行中` |

## 4. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SYS-FIL-T01 | — | 上传 60MB 文件（上限 50MB） | 提示“文件大小不能超过 50MB” |
| SYS-FIL-T02 | — | 把 exe 改名为 pdf 上传 | 提示“不支持的文件类型：pdf”（文件头不一致） |
| SYS-FIL-T03 | 新建采购订单时上传附件后未保存就关闭 | 24 小时后 | 该文件被清理 |
| SYS-FIL-T04 | 用户无采购订单查看权限 | 直接访问附件下载地址 | 提示“没有权限访问该附件” |
| SYS-TSK-T01 | 物料 3 万条 | 导出 | 提示已转后台导出；任务中心显示进度；完成后收到消息并可下载 |
| SYS-TSK-T02 | 任务运行中重启服务 | 重启后查看 | 任务状态“失败”，原因“服务重启，任务中断，请重新提交” |
| SYS-JOB-T01 | — | 把日志清理任务的 Cron 改为 `0 0 3 * * ?` | 预览显示最近 5 次执行时间均为 03:00 |

# 01-02 用户管理

## 1. 功能说明

维护系统用户账号：基本信息、所属部门、角色、直属上级、状态、密码。

- 使用者：系统管理员
- 优先级：P0
- 用户**不能删除**，只能停用（历史单据的经办人、审批人需要保留）。

## 3. 页面

### 3.1 用户列表（T1）

路由 `/system/user`，权限 `system:user:query`。页面左侧 240px 显示组织树（T6 风格），点击节点筛选该节点**及下级**的用户；右侧为用户列表。

**查询条件**

| 条件 | 控件 | 匹配方式 | 默认值 |
|---|---|---|---|
| 关键字 | 输入框（placeholder：用户名/姓名/工号/手机号） | 模糊 | 空 |
| 状态 | 下拉（全部/启用/停用） | 等于 | 启用 |
| 角色 | 下拉（角色列表） | 拥有该角色 | 空 |
| 岗位 | DictSelect(sys_position) | 等于 | 空（展开区） |
| 最近登录 | 日期范围 | 区间 | 空（展开区） |

**列表列**

| 列 | 字段 | 宽度 | 对齐/格式 | 说明 |
|---|---|---|---|---|
| 用户名 | username | 130 | 左 | 链接，打开编辑页 |
| 姓名 | real_name | 100 | 左 | |
| 工号 | employee_no | 100 | 左 | |

| 角色 | — | 200 | 左 | 角色名称逗号分隔，省略 + 提示 |
| 岗位 | position | 100 | 左 | 字典标签 |
| 手机号 | mobile | 120 | 左 | 中间 4 位脱敏显示 `138****1234`（有 `system:user:update` 权限的显示完整） |
| 状态 | status | 80 | 中 | StatusTag；锁定中额外显示橙色“已锁定”标签 |

## 4. 状态与流转

| 当前 | 动作 | 结果 | 副作用 |
|---|---|---|---|
| 启用 | 停用 | 停用 | token_version + 1（立即下线）；清除权限缓存；其审批待办按 08-审批流 R12 转交 |
| 停用 | 启用 | 启用 | 清除失败次数与锁定 |

“锁定”不是独立状态，由 `lock_until > 当前时间` 判断。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| SYS-USR-R01 | 保存 | 用户名唯一（不区分大小写） | `用户名「{username}」已存在` |
| SYS-USR-R02 | 保存 | 工号非空时唯一 | `工号「{no}」已被用户「{name}」使用` |
| SYS-USR-R03 | 保存 | 手机号非空时唯一 | `手机号已被用户「{name}」使用` |
| SYS-USR-R04 | 保存 | 直属上级不能是自己，也不能是自己的下属（沿上级链向上查找不能回到自己，最多查 20 层） | `直属上级不能是自己或自己的下属` |
| SYS-USR-R05 | 保存 | 至少分配一个启用的角色 | `请至少分配一个角色` |
| SYS-USR-R06 | 保存 | 只有超级管理员能分配或取消“超级管理员”角色 | `只有超级管理员可以分配超级管理员角色` |
| SYS-USR-R07 | 保存 | 主部门、兼职部门必须为启用状态 | `部门「{name}」已停用` |
| SYS-USR-R08 | 停用 | 不能停用自己；不能停用内置超级管理员 admin | `不能停用当前登录的账号` / `内置超级管理员不能停用` |
| SYS-USR-R09 | 修改角色 | 修改用户角色、部门后，清除该用户的登录用户缓存，使权限立即生效 | — |
| SYS-USR-R10 | 修改 | 修改了自己的角色导致失去 `system:user:update` 时允许，但需二次确认“修改后你将失去用户管理权限，确定吗？” | — |
| SYS-USR-R11 | 查询 | 部门主管角色（数据范围为本部门及下级）只能看到范围内的用户 | — |

## 6. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | /system/users | `system:user:query` | 分页查询，参数含 `deptId`（含下级）、`keyword`、`status`、`roleId` |
| GET | /system/users/{id} | `system:user:query` | 详情（含兼职部门、角色 ID 列表） |
| GET | /system/users/simple | 登录即可 | 用户远程搜索（UserSelect）：`keyword`，返回启用用户 id、姓名、部门，最多 20 条 |
| POST | /system/users | `system:user:create` | 新建，返回 id 和初始密码（仅此一次） |
| PUT | /system/users/{id} | `system:user:update` | 修改 |
| POST | /system/users/{id}/disable、/enable | `system:user:update` | 停用/启用 |
| POST | /system/users/batch-disable | `system:user:update` | 批量停用，返回每条结果 |
| POST | /system/users/{id}/unlock | `system:user:update` | 解锁 |
| POST | /system/users/{id}/kick | `system:user:update` | 强制下线 |
| POST | /system/users/{id}/reset-password | `system:user:reset-password` | 重置密码 |
| GET | /system/users/import-template | `system:user:import` | 下载模板 |
| POST | /system/users/import/check、/import | `system:user:import` | 校验、执行导入 |
| GET | /system/users/export | `system:user:export` | 导出 |

## 8. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| SYS-USR-T01 | — | 新建用户 zhangsan，角色“采购员”，初始密码随机 | 保存成功，弹窗显示初始密码；该用户首次登录后被要求修改密码 |
| SYS-USR-T02 | 已有 zhangsan | 新建 ZhangSan | 提示“用户名「zhangsan」已存在” |
| SYS-USR-T03 | A 的上级是 B | 编辑 B，上级选 A | 提示“直属上级不能是自己或自己的下属” |
| SYS-USR-T04 | zhangsan 已登录 | 管理员停用 zhangsan | zhangsan 的下一次请求返回 401 并跳转登录页；登录提示“账号已停用” |
| SYS-USR-T05 | zhangsan 已登录 | 管理员为其增加“仓管员”角色 | zhangsan 刷新页面后出现仓库菜单，无需重新登录 |
| SYS-USR-T06 | zhangsan 已登录 | 管理员重置其密码 | zhangsan 旧令牌失效；用新密码登录后被要求修改密码 |
| SYS-USR-T07 | admin 登录 | 停用自己 | 提示“不能停用当前登录的账号” |
| SYS-USR-T08 | 导入文件第 3 行主部门编码不存在 | 导入校验 | 预览中第 3 行标红，原因“部门编码 XXX 不存在”；不能执行导入 |
| SYS-USR-T09 | 普通管理员（无超级管理员角色） | 给用户勾选超级管理员 | 超级管理员选项不可见；直接调用接口返回“只有超级管理员可以分配超级管理员角色” |
| SYS-USR-T10 | 用户列表左侧选中“生产部” | 查询 | 显示生产部及其所有下级部门的用户 |

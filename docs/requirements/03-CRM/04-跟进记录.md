# 03-04 跟进记录

## 1. 功能说明

记录与客户的每次沟通（拜访、电话、邮件、展会、视频会议），并设置下次跟进提醒。

- 使用者：业务员、业务主管
- 优先级：P1

## 2. 数据表

### crm_followup

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| customer_id | id | 是 | | |
| contact_id | id | 否 | | 联系人 |
| opportunity_id | id | 否 | | 关联商机 |
| followup_type | dict(crm_followup_type) | 是 | PHONE | |
| followup_at | datetime | 是 | 当前时间 | 跟进时间，不能晚于当前时间 |
| subject | str(128) | 是 | | 主题 |
| content | str(4000) | 是 | | 内容 |
| next_followup_at | date | 否 | | 下次跟进日期，≥ 今天 |
| next_plan | str(512) | 否 | | 下次计划 |
| owner_id | id | 是 | 当前用户 | 记录人 |
| reminded | bool | 是 | 0 | 是否已提醒 |

附件使用 sys_file（biz_type = CRM_FOLLOWUP）。

## 3. 页面

### 3.1 跟进记录列表（T1）

路由 `/crm/followup`。查询：客户、记录人、方式、跟进时间（默认近 30 天）、商机、仅看待跟进（next_followup_at ≤ 今天 + 7 天且之后没有新跟进）。
列：跟进时间、客户简称（链接）、联系人、方式、主题、内容（省略）、商机、下次跟进（已到期红色）、记录人、操作（编辑、删除——仅记录人，24 小时内）。
工具栏：[新增跟进]。

### 3.2 跟进表单（T2 大弹窗）

字段：客户*（CustomerSelect，可选潜在客户）、联系人（该客户联系人）、关联商机（该客户未关闭商机）、方式*、跟进时间*、主题*、内容*（文本域，6 行）、下次跟进日期、下次计划、附件。

客户详情页“跟进记录”页签以时间线显示：时间、方式图标、主题、内容、联系人、记录人、附件；顶部 [新增跟进] 固定客户。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| CRM-FU-R01 | 跟进时间不能晚于当前时间；下次跟进日期不能早于今天 | `跟进时间不能晚于当前时间` |
| CRM-FU-R02 | 只有记录人本人在 24 小时内可以修改、删除；之后只读（保证记录真实） | `跟进记录超过 24 小时，不能修改` |
| CRM-FU-R03 | 每天按参数 `crm.followup.remind-time` 给记录人发送当天到期的跟进提醒（工作台待办，点击打开客户详情）；已针对同一客户新增了更晚的跟进时视为已跟进，不再提醒 | — |
| CRM-FU-R04 | 数据权限按客户：能看到客户就能看到其全部跟进记录 | — |

## 5. 接口

`/crm/followups`（GET 列表、POST、PUT、DELETE）、`GET /crm/followups?customerId=`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| CRM-FU-T01 | — | 新增电话跟进，下次跟进明天 | 明天 09:00 记录人工作台出现提醒 |
| CRM-FU-T02 | 昨天记录的跟进（超过 24 小时） | 编辑 | 没有编辑按钮；接口提示“跟进记录超过 24 小时，不能修改” |
| CRM-FU-T03 | 今天到期提醒前已新增跟进 | 到提醒时间 | 不再提醒 |

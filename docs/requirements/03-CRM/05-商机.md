# 03-05 商机

## 1. 功能说明

跟踪潜在订单机会从初步接触到赢单/输单的过程，统计商机漏斗和赢单率。

- 使用者：业务员、业务主管
- 优先级：P1

### 1.1 阶段

| 阶段 | 编码 | 默认赢率 |
|---|---|---|
| 初步接触 | CONTACT | 10% |
| 需求确认 | REQUIREMENT | 30% |
| 报价 | QUOTATION | 50% |
| 谈判 | NEGOTIATION | 70% |
| 赢单 | WON | 100% |
| 输单 | LOST | 0% |

结果状态：进行中（OPEN）/ 赢单（WON）/ 输单（LOST）/ 搁置（SHELVED）。

## 3. 页面

### 3.1 商机列表（T1）

路由 `/crm/opportunity`。页面顶部显示漏斗统计卡片：各阶段（进行中商机）数量、金额（折算本位币）、加权金额（金额 × 赢率）。
查询：关键字、客户、负责人、阶段、状态（默认进行中）、预计成交日期（范围）。
列：编码、名称（链接打开详情抽屉）、客户、阶段（步骤小标签）、金额（币别 + 金额）、赢率、预计成交日期（已过期未结束红色）、负责人、最近跟进时间、状态、操作（编辑、推进阶段、赢单、输单、搁置/恢复）。

### 3.2 商机表单（T2 大弹窗）

字段：名称*、客户*、联系人、阶段*、金额*、币别*、赢率（随阶段带出，可改）、预计成交日期*、意向产品、竞争对手、负责人、备注。

### 3.3 商机详情（抽屉 720px）

基本信息 + 阶段步骤条 + 关联报价单（销售模块按 opportunity_id 查询）+ 跟进记录时间线 + [新增跟进]。

### 3.4 结束商机

- 赢单：选择关联的销售订单（可选），状态 WON、阶段 WON。
- 输单：原因*、说明，状态 LOST。
- 搁置：说明，状态 SHELVED；恢复后回到 OPEN（阶段不变）。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| CRM-OPP-R01 | 输单必须选择原因 | `请选择输单原因` |
| CRM-OPP-R02 | 已结束（赢单/输单）的商机不能修改，只能查看 | `商机已结束，不能修改` |
| CRM-OPP-R03 | 监听 `QuotationCreatedEvent`：报价单关联了商机且商机阶段在“报价”之前时，自动推进到“报价” | — |
| CRM-OPP-R04 | 监听 `SalesOrderApprovedEvent`：订单来源报价关联了商机时，商机自动赢单并记录订单号 | — |
| CRM-OPP-R05 | 漏斗金额按当日汇率折算本位币 | — |

## 5. 接口

`/crm/opportunities`（CRUD）、`/{id}/stage`、`/{id}/win`、`/{id}/lose`、`/{id}/shelve`、`/{id}/resume`、`GET /crm/opportunities/funnel`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| CRM-OPP-T01 | 商机在需求确认阶段 | 为其创建报价单 | 商机自动推进到报价阶段 |
| CRM-OPP-T02 | 报价转订单并审核 | — | 商机自动赢单，记录订单号 |
| CRM-OPP-T03 | — | 输单不选原因 | 提示“请选择输单原因” |
| CRM-OPP-T04 | 3 个进行中商机 | 查看漏斗 | 各阶段数量、金额、加权金额正确 |

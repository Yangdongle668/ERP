# 03-02 客户料号对照

## 1. 功能说明

维护“客户料号 ↔ 本厂物料”的对照。客户下单、RFQ 时用的是客户自己的料号；系统通过对照自动转换为本厂物料，并在对外单据（PI、Packing List、Invoice、出货标签）上打印客户料号。

- 使用者：业务员、业务助理
- 优先级：P1

## 2. 数据表

### crm_customer_part

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| customer_id | id | 是 | | |
| customer_part_no | str(64) | 是 | | 客户料号 |
| customer_part_name | str(256) | 否 | | 客户品名（对外单据优先使用） |
| customer_part_spec | str(512) | 否 | | 客户规格描述 |
| material_id | id | 是 | | 本厂物料（半成品/成品） |
| customer_revision | str(16) | 否 | | 客户图纸版本 |
| status | enum(ENABLED/DISABLED) | 是 | ENABLED | |
| remark | str(256) | 否 | | |

唯一：`uk_customer_part(customer_id, customer_part_no)`。同一客户下一个物料可以对应多个客户料号（客户不同项目用不同料号）。

## 3. 页面（T1 + T2）

路由 `/crm/customer-part`。

- 查询：客户（CustomerSelect）、客户料号（前缀）、本厂物料（MaterialSelect）、状态。
- 列：客户简称、客户料号、客户品名、客户版本、本厂物料编码、名称、规格、状态、更新时间、操作（编辑、停用/启用、删除）。
- 表单（中弹窗）：客户*、客户料号*、客户品名、客户规格、客户版本、本厂物料*（MaterialSelect，半成品/成品，启用）、备注。
- 导入：客户编码*、客户料号*、客户品名、客户规格、客户版本、本厂物料编码*。
- 客户详情页“客户料号”页签复用本列表（固定客户）。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| CRM-CP-R01 | 同一客户下客户料号唯一 | `客户料号「{no}」已存在，对应物料 {code}` |
| CRM-CP-R02 | `CustomerPartApi.toMaterial` 只匹配启用的对照；找不到返回空，由调用方提示“客户料号「{no}」没有对照的物料，请先维护客户料号对照” | — |
| CRM-CP-R03 | `toCustomerPart(customerId, materialId)` 有多个时取最近更新的启用记录 | — |
| CRM-CP-R04 | 已被订单引用的对照不能删除，只能停用（`CustomerPartReferenceChecker` 由销售模块提供） | `该客户料号已被订单使用，只能停用` |

## 5. 接口

`/crm/customer-parts`（CRUD、enable/disable、导入导出）；`GET /crm/customer-parts/lookup?customerId=&partNo=`（登录即可）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| CRM-CP-T01 | ABC 客户料号 X-100 → FG00001 | 销售订单行输入客户料号 X-100 | 自动带出物料 FG00001 |
| CRM-CP-T02 | 未对照的 X-200 | 销售订单行输入 | 提示“客户料号「X-200」没有对照的物料，请先维护客户料号对照”，提供 [去维护] 链接 |
| CRM-CP-T03 | 对照已被订单使用 | 删除 | 提示“该客户料号已被订单使用，只能停用” |

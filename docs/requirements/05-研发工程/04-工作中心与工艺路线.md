# 05-04 工作中心与工艺路线

## 1. 功能说明

- **工作中心**：完成某类工序的生产资源（产线、机台组、手工组、委外厂），有产能和费率。用于排产、产能负荷分析、成本分摊。
- **工艺路线**：一个自制件的加工工序序列，每道工序指定工作中心和标准工时。用于生产订单工序、报工、排产、标准成本。
- 优先级：P1（没有工艺路线的物料，生产订单按“单工序”处理：只有一道“完工”工序）。

## 3. 页面

### 3.1 工作中心（T1 + T2）

路由 `/engineering/work-center`，权限 `eng:work-center:query`。

- 查询：关键字（编码/名称）、车间（OrgTreeSelect）、类型、状态。
- 列：编码（110）、名称（150）、车间（140）、类型（80）、每班小时（90，右）、班次（60，右）、效率（70，百分比）、日产能(h)（90，右）、人工费率（90，字段权限）、制费费率（90，字段权限）、状态（70）、操作（编辑、停用/启用、删除）。
- 表单字段即数据表字段（日产能只读实时计算）；校验：编码唯一（`工作中心编码「{code}」已存在`）、每班小时 0～24、班次 1～4、效率 1%～200%、费率 ≥0。
- 删除：被工艺路线或生产订单引用时不能删除（`该工作中心已被使用，只能停用`）。

### 3.2 工艺路线列表（T1）

路由 `/engineering/routing`。查询：物料、状态、仅默认版本（默认开）、工作中心（包含该工作中心的路线）。列：物料编码（链接）、名称、版本（带默认标签）、工序数、总标准工时（秒/件）、状态、更新时间、操作（编辑、审核、设为默认、新建版本、停用、删除——按状态显示，规则同 BOM）。

### 3.3 工艺路线编辑（T4）

单头：物料（MaterialSelect，类型半成品/成品，取得方式自制或委外）、版本（只读）、说明。

明细（LinesEditor）：工序号（数字，默认上一行 + 10）、工序（DictSelect）、工作中心（下拉）、准备时间（分钟）、标准工时（秒/件）、报工点（复选，默认是）、检验点、委外、备注。

底部汇总：总准备时间、总标准工时、按工作中心汇总的工时。

### 3.4 工艺路线详情（T5）

按钮：编辑（草稿）、审核（草稿，`eng:routing:approve`）、反审核（已审核且非默认、未被生产订单使用）、设为默认、新建版本、停用、删除（草稿）。页签：工序明细、操作日志。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| ENG-RTG-R01 | 保存 | 工序号在路线内唯一且为正整数 | `工序号 {seq} 重复` |
| ENG-RTG-R02 | 审核 | 至少一道工序；最后一道必须是报工点；工作中心均为启用 | `最后一道工序必须是报工点` |
| ENG-RTG-R03 | 保存 | 委外工序的工作中心类型必须为委外 | `委外工序必须选择委外类型的工作中心` |
| ENG-RTG-R04 | 设为默认 | 同一物料一个默认版本；首个审核版本自动为默认 | — |
| ENG-RTG-R05 | 反审核 | 被生产订单使用的版本不能反审核 | `该工艺路线已被生产订单使用，不能反审核` |
| ENG-RTG-R06 | 引用 | BOM 行的“工序”必须是父件默认工艺路线中的工序号；工艺路线新版本删除了某工序时，提示检查 BOM | `BOM 中引用了工序 {seq}，新版本中不存在` （警告） |

# 05-06 研发项目

## 1. 功能说明

管理新产品开发（NPI）和改进项目：项目基本信息、成员、阶段、任务与交付物、进度。

- 使用者：项目经理、研发工程师、工程主管
- 优先级：P1
- 范围说明：本功能是轻量项目管理（任务清单 + 进度），不做甘特图拖拽排程和项目费用核算（P2）。

## 2. 数据表

### eng_project 项目（编码规则 ENG_PROJECT，doc_no 即项目编号；使用 BaseDocDO，状态为项目自有状态）

| 字段 | 类型 | 必填 | 默认 | 说明 |

| customer_id | id | 否 | | 客户 |
| product_material_id | id | 否 | | 产品物料（立项时可为空，建料后关联） |

| priority | enum(HIGH/MEDIUM/LOW) | 是 | MEDIUM | |

### eng_project_member 成员

## 3. 页面

### 3.1 项目列表（T1）

查询：项目编号、名称、客户、项目经理、阶段、状态（默认非完成、非取消）、计划结束（日期范围）。
列：项目编号（链接）、名称、类型、客户、产品、项目经理、阶段（标签）、进度（进度条）、计划结束（逾期未完成红色）、状态、操作（编辑、更多：暂停/恢复/取消/完成）。

### 3.2 新建/编辑项目（T3）

分组：基本信息（名称*、类型*、客户、产品物料、项目经理*、优先级、计划开始*、计划结束*、说明）；成员（可编辑表格：成员*（UserSelect）、角色）。

### 3.3 项目详情（T5 变体）

页头：项目编号 + 名称 + 状态；按钮：编辑、推进阶段（下拉选择下一阶段，需确认）、暂停/恢复、完成、取消（原因）。
单头：基本信息 + 进度条 + 当前阶段步骤条（概念 → 设计 → EVT → DVT → PVT → 量产）。
页签：
- **任务**：按阶段分组的任务表格（阶段、任务、负责人、计划开始、计划结束、实际完成、状态、交付物、附件数）；[新建任务]（项目经理）；负责人可在行上更新状态、上传交付物；逾期任务红色。
- **成员**、**关联**（样品单、BOM、ECN、认证——按项目或产品物料关联查询）、**操作日志**。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| ENG-PRJ-R01 | 保存 | 计划结束 ≥ 计划开始 | `计划结束日期不能早于开始日期` |
| ENG-PRJ-R02 | 任务 | 负责人必须是项目成员；项目经理自动成为成员 | `任务负责人必须是项目成员` |
| ENG-PRJ-R03 | 进度 | 进度 = 已完成任务权重之和 ÷ 未取消任务权重之和；任务变化时自动重算 | — |
| ENG-PRJ-R04 | 推进阶段 | 当前阶段存在未完成（非 DONE/CANCELED）任务时提示确认（不阻止） | `当前阶段还有 {n} 个未完成任务，确定进入下一阶段吗？` |
| ENG-PRJ-R05 | 完成 | 所有任务完成或取消 | `还有 {n} 个未完成任务` |
| ENG-PRJ-R06 | 权限 | 编辑项目、新建任务：项目经理或有 `eng:project:update` 的人；更新任务状态：任务负责人或项目经理 | `只有项目经理或任务负责人可以操作` |
| ENG-PRJ-R07 | 提醒 | 每天 09:00 给任务负责人推送“明天到期”和“已逾期”的任务提醒 | — |
| ENG-PRJ-R08 | 状态 | 首个任务变为 DOING 时，项目状态由 PLANNING 自动变为 IN_PROGRESS 并记录实际开始 | — |

## 5. 接口

`/engineering/projects`（CRUD、`/{id}/stage`、`/{id}/hold`、`/{id}/resume`、`/{id}/complete`、`/{id}/cancel`）；`/engineering/projects/{id}/tasks`（CRUD、`/{taskId}/status`）。权限 `eng:project:*`，任务状态更新按 R06。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| ENG-PRJ-T01 | — | 新建项目，成员 3 人，建 4 个任务（权重各 1） | 进度 0% |
| ENG-PRJ-T02 | 完成 1 个任务 | — | 进度 25%，项目状态自动变为进行中 |
| ENG-PRJ-T03 | 设计阶段还有 2 个任务未完成 | 推进到 EVT | 确认框提示 2 个未完成任务，确认后阶段变为 EVT |
| ENG-PRJ-T04 | 非成员 | 被指定为任务负责人 | 提示“任务负责人必须是项目成员” |
| ENG-PRJ-T05 | 任务明天到期 | 次日 09:00 前 | 负责人工作台收到提醒 |

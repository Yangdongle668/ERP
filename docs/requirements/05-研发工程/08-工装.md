# 05-08 工装

## 1. 功能说明

模具、治具、夹具、检具、钢网的台账：归属、适用产品、寿命与使用次数、保养、借用归还、维修、报废。

- 使用者：工艺工程师、工装管理员、生产
- 优先级：P1
- 工装不作为库存物料管理（不进仓库库存），用独立台账管理；如需核算价值，由财务按固定资产处理。

## 3. 页面

### 3.1 工装台账（T1）

查询：编号、名称、类型、归属、状态、适用物料（MaterialSelect）、寿命预警（仅显示使用率 ≥ 预警比例）。
列：编号（链接）、名称、类型、归属（客户资产显示客户名）、模穴数、使用次数 / 设计寿命（显示“45,000 / 50,000”，下方进度条，≥90% 橙、≥100% 红）、距下次保养（次）、存放位置、状态、持有人、操作。
工具栏：[新建]、[导入]、[导出]。
行操作（`eng:tooling:record`，按状态显示）：借出（在库）、归还（借出/使用中）、保养（非报废）、送修（在库/借出）、修复（维修中）、报废（非报废，原因必填，确认）、编辑。

### 3.2 工装表单（T2 大弹窗双列）

字段即台账字段（除 used_count、last_maintain_count、tooling_status、holder_id 外）；另有“适用物料”多选（MaterialSelect 多选）。新建时可填“初始使用次数”（用于旧模具建档）。

### 3.3 登记弹窗

| 操作 | 字段 |
|---|---|
| 借出 | 借用人*（UserSelect）、用途、预计归还日期 |
| 归还 | 归还人、状态检查说明 |
| 保养 | 保养内容*、费用、保养日期*（默认今天） |
| 送修 / 修复 | 维修内容*、维修厂商、费用 |
| 报废 | 报废原因*、报废日期* |
| 次数调整 | 调整后次数*、原因*（需要 `eng:tooling:update`） |

### 3.4 工装详情（T5 变体）

基本信息 + 适用物料 + 记录时间线（全部 record 按时间倒序）+ 附件（模具图纸、验收报告）。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| ENG-TL-R01 | 保存 | 编号唯一；客户资产必须选择客户 | `工装编号「{code}」已存在` |
| ENG-TL-R02 | 报工 | 生产报工单关联工装时，`ToolingApi.addUsage(toolingId, ceil(合格数+不良数 ÷ 模穴数))`，写 USAGE 记录（事件 `WorkReportApprovedEvent` 触发）；报工反审核时扣回 | — |
| ENG-TL-R03 | 寿命 | 使用次数 ≥ 设计寿命 × 预警比例时发布 `ToolingLifeWarningEvent`（工作台预警，每个工装每个阈值只提醒一次）；≥ 设计寿命时 `validateUsable` 返回不可用，生产报工/派工选择该工装时阻止，除非有 `eng:tooling:update` 权限的人在工装上勾选“超寿命继续使用”（记录原因） | `工装「{code}」已达到设计寿命，不能继续使用` |
| ENG-TL-R04 | 保养 | 使用次数 − 上次保养次数 ≥ 保养周期时，工作台提醒工装管理员；登记保养后 last_maintain_count = used_count | — |
| ENG-TL-R05 | 状态 | 报废后不可恢复，不能再借出/使用；维修中不能借出、不能报工使用 | `工装「{code}」当前状态为{状态}，不能{操作}` |
| ENG-TL-R06 | 删除 | 有 USAGE 记录的工装不能删除，只能报废 | `工装已有使用记录，不能删除` |

## 5. 接口

`/engineering/toolings`（CRUD、导入导出）、`/{id}/lend`、`/{id}/return`、`/{id}/maintain`、`/{id}/repair-start`、`/{id}/repair-end`、`/{id}/scrap`、`/{id}/adjust`、`/{id}/records`；`/engineering/toolings/simple?materialId=`（生产报工选择，只返回可用工装）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| ENG-TL-T01 | 模具 4 穴，已用 1000 次 | 报工合格 398、不良 2 并关联该模具 | 使用次数 1100 |
| ENG-TL-T02 | 设计寿命 50,000，预警 90% | 使用次数达到 45,000 | 工作台出现寿命预警，只提醒一次 |
| ENG-TL-T03 | 使用次数 50,000 | 报工选择该模具 | 提示“工装「…」已达到设计寿命，不能继续使用” |
| ENG-TL-T04 | 保养周期 10,000，上次保养 30,000 | 使用次数到 40,000 | 提醒保养；登记保养后提醒消失 |
| ENG-TL-T05 | 维修中 | 借出 | 提示“工装「…」当前状态为维修中，不能借出” |

# 05-09 认证

## 1. 功能说明

维护产品认证证书（CE、UL、FCC、CCC、RoHS、REACH 等）和体系证书：证书信息、适用产品、适用国家、证书文件、有效期，并在到期前提醒。

- 使用者：认证工程师；业务员、船务查询
- 优先级：P1

## 2. 数据表

### eng_certification 证书

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| cert_type | dict(eng_cert_type) | 是 | | 认证类型 |
| cert_no | str(64) | 是 | | 证书编号 |
| name | str(128) | 是 | | 证书名称 |
| issuing_body | str(128) | 是 | | 发证机构 |
| holder | str(128) | 否 | | 证书持有人（默认本公司名称） |
| issue_date | date | 是 | | 发证日期 |
| expire_date | date | 否 | | 到期日期（为空表示长期有效，如部分 RoHS 报告） |
| countries | str(256) | 否 | | 适用国家/地区（ISO 代码逗号分隔，如 `EU,US`） |
| scope | str(1000) | 否 | | 认证范围说明（型号、标准） |
| cert_status | enum(VALID/REVOKED) | 是 | VALID | 有效 / 已撤销（手工）；“即将到期”“已过期”由到期日计算，不存储 |
| remark | str(512) | 否 | | |

唯一：`uk_type_no(cert_type, cert_no)`。证书文件使用 sys_file（biz_type = ENG_CERT，category = CERT），至少 1 个。

### eng_certification_material 适用物料

`certification_id`、`material_id`，唯一。

## 3. 页面

### 3.1 认证证书（T1 + T2）

查询：证书编号、类型、适用物料（MaterialSelect）、有效性（全部 / 有效 / 90 天内到期 / 已过期 / 已撤销）、到期日期（范围）。
列：类型（80）、证书编号（160）、名称（200）、发证机构（140）、适用物料（显示前 3 个 + “等 n 个”，悬停显示全部）、适用国家（100）、发证日期（110）、到期日期（110）、有效性标签（有效绿 / 即将到期橙（≤90 天）/ 已过期红 / 已撤销灰 / 长期有效绿）、附件（数量，点击预览）、操作（编辑、撤销、删除）。
工具栏：[新建]、[导出]。

**表单（大弹窗）**：类型*、证书编号*、名称*、发证机构*、持有人、发证日期*、到期日期（≥ 发证日期）、适用国家（多选，常用：EU、US、CN、KR、JP、UK、IN）、认证范围、适用物料（MaterialSelect 多选）、证书文件*（上传，PDF/图片）、备注。

### 3.2 物料详情“认证”页签

物料详情页（02-物料）增加“认证”页签，列出该物料适用的全部证书及有效性。

## 4. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| ENG-CRT-R01 | 保存 | 同类型证书编号唯一；到期日期 ≥ 发证日期；至少上传一个证书文件 | `该证书已存在` / `到期日期不能早于发证日期` / `请上传证书文件` |
| ENG-CRT-R02 | 提醒 | 每天 08:00 检查：到期前 N 天（参数 `eng.cert.remind-days`，默认 90/30/7）发布 `CertificationExpiringEvent`，工作台预警给拥有 `eng:cert:update` 的用户；已过期当天再提醒一次 | — |
| ENG-CRT-R03 | 查询 | `CertificationApi.listValid(materialId)` 只返回未撤销且未过期的证书 | — |
| ENG-CRT-R04 | 删除 | 删除为逻辑删除，需二次确认；已撤销的证书保留供追溯 | — |

## 5. 接口

`/engineering/certifications`（CRUD、`/{id}/revoke`、`/export`）；`/engineering/certifications/by-material/{materialId}`（登录即可）。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| ENG-CRT-T01 | — | 新建 CE 证书，适用 FG1、FG2，到期 2026-12-01 | 保存成功；FG1 物料详情“认证”页签显示该证书 |
| ENG-CRT-T02 | 今天 2026-09-02 | 定时任务执行 | 工作台出现“CE 证书 xxx 将在 90 天后到期” |

| ENG-CRT-T04 | 未上传文件 | 保存 | 提示“请上传证书文件” |

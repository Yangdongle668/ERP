# 05-02 物料

## 1. 功能说明

物料是系统中所有“物”的主数据：原材料、FPC、电子料、包材、辅料、半成品、成品。物料档案按用途分为 6 组属性，分别被不同模块使用：

| 属性组 | 使用方 |
|---|---|
| 基本信息 | 全部模块 |
| 单位换算 | 采购、销售、仓库 |
| 计划属性 | PMC（MRP） |
| 采购属性 | 资材 |
| 库存属性 | 仓库 |
| 质量属性 | 品质 |
| 财务属性 | 财务、销售报价 |

- 使用者：研发工程师（建档）、数据管理员（审核启用）、采购/计划/仓库/品质人员（维护各自属性，需对应权限）
- 优先级：P0
- 已有实现：基本信息的增删改查、启用/停用、自动编码。本文档补充其余属性组、查重、导入导出、详情页。

### 3.3 物料详情（T5，无审批）

路由 `/engineering/material/:id`。页头：编码 + 名称 + 状态；按钮：[编辑] [启用]/[停用] [复制新建]。

单头区显示基本信息；页签：

| 页签 | 内容 |
|---|---|
| 属性 | 其余属性组的只读展示（分组） |
| 单位换算 | 列表 |

### 3.4 查重提示

名称、规格、制造商料号失焦时调用查重接口；有疑似重复时在表单顶部显示黄色提示条：“发现 2 个疑似重复物料：FPC00012 FPC 排线 20P（启用）…”，每条可点击在新页签查看。参数为 BLOCK 时保存被拒绝。

### 3.5 导入

模板列：物料类别编码*、编码（留空自动生成）、名称*、英文名称、规格型号、物料类型*（中文）、基本单位*（编码）、图号、版本、品牌、制造商、制造商料号、海关编码、单位净重、单位毛重、取得方式（中文）、提前期、安全库存、MOQ、MPQ、采购员用户名、计划员用户名、库存管理（中文）、保质期、来料检验（是/否）、完工检验、出货检验、标准成本（需字段权限，否则忽略该列）、进项税率（%）、销项税率（%）、备注。

- 导入的物料状态为草稿；导入选项“导入后直接启用”（需要 `eng:material:enable`，且参数不要求审批）。
- 编码已存在的行：选项“跳过”或“更新”（更新时只更新文件中非空的列，已启用物料的锁定字段不更新并在结果中提示）。
- 查重按参数执行：BLOCK 时疑似重复行报错。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| ENG-MAT-R01 | 保存 | 编码唯一（不区分大小写） | `物料编码「{code}」已存在` |
| ENG-MAT-R02 | 新建 | 编码为空时按 `ENG_MATERIAL` 规则生成，变量 `categoryPrefix` 取类别的编码前缀 | — |
| ENG-MAT-R03 | 保存 | 查重：同一类别下“名称 + 规格”相同，或制造商料号相同（不区分大小写、忽略空格） | `发现疑似重复物料：{codes}`（BLOCK 时阻止） |
| ENG-MAT-R04 | 保存 | 类别必须是启用的末级类别 | `请选择末级物料类别` |
| ENG-MAT-R05 | 保存 | 计划属性条件必填：固定批量规则需填固定批量；按周期需填周期天数 | `批量规则为“固定批量”时必须填写固定批量` |
| ENG-MAT-R06 | 启用 | 必填属性完整：类别、名称、类型、基本单位、取得方式；采购件需填采购提前期（可为 0）；FEFO 需保质期 | `物料「{code}」缺少{字段}，不能启用` |
| ENG-MAT-R07 | 修改 | 启用后编码、物料类型、基本单位不可修改（已实现）；已被使用的单位换算不可修改或删除 | `物料「{code}」已启用，只能修改名称、规格等描述信息` / `单位换算已被单据使用，不能修改` |
| ENG-MAT-R08 | 停用 | 停用前查询引用情况并在确认框中提示（不阻止）：有库存、有未完成采购/销售/生产单据、被启用 BOM 引用 | `该物料当前有库存 {qty}，未完成单据 {n} 张，被 {m} 个 BOM 使用。停用后不能在新单据中使用，确定停用吗？` |
| ENG-MAT-R09 | 删除 | 只有草稿且从未被任何单据、BOM 引用（`MaterialReferenceChecker` 由各模块提供）才能删除 | `只有草稿状态的物料可以删除，已启用的物料请停用` / `该物料已被使用，不能删除` |
| ENG-MAT-R10 | 修改库存管理 | 该物料在任何仓库有库存或有未完成出入库单据时不能修改库存管理方式 | `物料有库存或未完成单据，不能修改库存管理方式` |
| ENG-MAT-R11 | 保存 | 采购单位、销售单位必须是基本单位或已配置换算的辅助单位 | `采购单位 {uom} 没有与基本单位的换算关系` |
| ENG-MAT-R12 | 修改计划/采购/库存属性 | 发布 `MaterialChangedEvent(materialId, changedGroups)` | — |
| ENG-MAT-R13 | 字段权限 | 无 `eng:material:cost` 时接口不返回标准成本（null），保存时忽略该字段 | — |

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| ENG-MAT-T01 | 类别 FPC（前缀 FPC） | 新建物料，编码留空 | 编码 FPC00001；类型、单位、批次管理、来料检验取类别默认值 |
| ENG-MAT-T02 | 已有 FPC00001 名称“FPC 排线 20P”规格“0.5mm” | 在 FPC 类别新建同名同规格物料（参数 WARN） | 显示疑似重复提示，仍可保存 |

| ENG-MAT-T05 | 已启用物料 | 修改基本单位 | 基本单位不可编辑；接口提交返回“已启用，只能修改名称、规格等描述信息” |

# 05-01 物料类别

## 1. 功能说明

物料的多级分类，如“电子料 / IC”“FPC”“包材 / 纸箱”。类别用于：

1. 物料编码前缀（编码规则变量 `{categoryPrefix}`）；
2. 新建物料时带出默认属性（物料类型、单位、批次管理、是否来料检验等）；
3. 仓库模块按类别确定默认仓（类别 → 默认仓的映射在仓库模块维护）；
4. 查询、统计、报表分组。

- 使用者：数据管理员
- 优先级：P0
- 物料只能挂在**末级类别**上。

## 4. 状态与流转

启用 ⇄ 停用。停用的类别不能在新建物料时选择，其下已有物料不受影响。

## 5. 业务规则

| 编号 | 触发 | 规则 | 提示原文 |
|---|---|---|---|
| ENG-CAT-R01 | 保存 | 编码唯一 | `类别编码「{code}」已存在` |
| ENG-CAT-R02 | 保存 | 上级不能是自己或下级 | `上级类别不能是自己或自己的下级` |
| ENG-CAT-R03 | 保存 | 最多 5 级 | `物料类别不能超过 5 级` |
| ENG-CAT-R04 | 新增下级 | 已挂有物料的类别不能再新增下级（物料只能挂在末级） | `该类别下已有物料，不能新增下级类别` |
| ENG-CAT-R05 | 删除 | 有下级或有物料（含停用）时不能删除 | `该类别下有下级类别或物料，不能删除` |
| ENG-CAT-R06 | 停用 | 有启用的下级类别时不能停用 | `请先停用下级类别` |
| ENG-CAT-R07 | 修改编码 | 已被物料使用的类别编码不能修改 | `该类别已被物料使用，不能修改编码` |
| ENG-CAT-R08 | 编码段 | 只能设置在末级类别上；已设置编码段的类别不能新增下级 | `编码段只能设置在末级类别上` |
| ENG-CAT-R09 | 编码段 | 类别已有物料后：编码段的个数、顺序、位数和已有特征值的代码不能修改，特征值不能删除（只能停用）；名称、说明可改，可新增特征值 | `类别「{name}」已有物料，编码段的名称以外不能修改，特征值只能新增或停用` |
| ENG-CAT-R10 | 编码段 | 特征值位数必须等于编码段位数；同一编码段内特征值不重复，同一类别内编码段名称不重复 | `编码段「{name}」为 {n} 位，特征值「{code}」位数不对` |

## 8. 编码段（《物料编码手册》20260618 A02）

物料编码 = **类别前缀** + **各编码段的特征值**（从左到右）+ **流水号**。流水号按「前缀 + 特征值」组合独立计数，相同特征的物料依次编号，作废编码不复用。

- 类别字段：编码前缀可含 `-`（如 `12-`）；流水号位数 `code_seq_length`（空则按编码规则 `ENG_MATERIAL`，默认 5 位）。
- 编码段 `eng_code_segment`（category_id、name、seg_length 1～4、sort）；特征值 `eng_code_segment_value`（segment_id、value_code、value_name、sort、status）。
- 页面：类别列表「编码段」列（末级类别显示段数或“设置”），点击打开编码段弹窗：上方显示编码构成与示例；每段可改名称、位数、顺序，维护特征值（代码、说明、启用）。
- 新建物料：类别有编码段时，基本信息页签显示每段的下拉框和编码预览；规格型号按所选特征值说明带出（如 `UL3302/红色/`，未手工修改时跟随）。保存后物料记录「编码构成」（如 `线材型号 02 UL3302；颜色 1 红色`），详情页显示。
- 手工输入编码（编码规则允许时）不受编码段约束。

## 9. 导入与回滚

- 类别列表右上角「导入」：模板列 类别编码*、名称*、上级类别编码、编码前缀*、流水号位数、默认物料类型*、默认基本单位、默认库存管理、默认来料检验、排序、备注。
  按文件顺序新建，上级须已存在或在文件中排在前面；编码已存在的行跳过。权限 `eng:category:create`。
- 每次导入为一个**导入批次**（`eng_import_batch` / `eng_import_item`），导入对话框「导入记录（回滚）」可整批回滚：物理删除本批新增的类别（编码可重新导入）。
  类别下已有物料或有不属于本批的下级类别时不能回滚。

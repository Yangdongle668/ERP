# 06-06 缺料分析

## 1. 功能说明

对生产订单（已下达/已计划）按开工先后分配可用库存，计算每张订单的齐套率和缺料清单，并关联在途采购的预计到货，推送催料。

- 使用者：物控员、计划员、采购员（被推送）
- 优先级：P0

## 2. 分配逻辑

1. 选择分析范围：生产订单（状态、车间、计划开工范围，或手工勾选）。
2. 排序：优先级 → 计划开工 → 单号。
3. 对每张订单每个用料行的**未领数量**，依次从“剩余可用库存”中分配（可用口径同仓库模块：可用仓合格未冻结 − 预留）；不足部分 = 缺料数量。
4. 缺料数量再依次匹配在途供应（在途采购、待检仓数量、委外），得到“预计齐套日期”（最后一笔覆盖缺料的供应日期）；在途也不足的部分标记“无供应”（需要采购）。
5. 订单齐套率 = 已分配可满足的用料行数 ÷ 用料行数（行级）；数量齐套率 = Σ min(可分配, 未领) ÷ Σ 未领。
6. 可开工数量（可齐套套数）= min over 用料行 (（已领 − 已退 + 可分配）÷ 单位用量 ÷ (1+损耗))，向下取整。

分析结果保存为快照（`pmc_shortage_snapshot`），便于对比和推送。

## 4. 页面（专用）

路由 `/pmc/shortage`。

**上部：分析条件** 车间、状态（已下达、已计划）、计划开工（默认今天起 14 天）、生产订单（多选）→ [开始分析]。

**中部：订单视图**（默认）

| 列 | 说明 |
|---|---|
| 优先级 / 生产订单 / 产品 / 数量 | |
| 计划开工 | |
| 行齐套率 | 进度条（100% 绿、≥80% 橙、<80% 红） |
| 可开工数量 | |
| 缺料行数 | 点击展开缺料明细 |
| 预计齐套日期 | 晚于计划开工时红色 |
| 销售订单 / 要求交期 | |

展开缺料明细：子件、未领、可分配、缺料、在途明细（PO 号、确认交期、数量，悬停）、预计齐套日期、无供应数量（红色）、采购员。

**切换：物料视图** 以物料汇总缺料：物料、总缺料、影响订单数、最早需要日期、在途（单号/日期）、无供应数量、采购员；用于采购统一催料。

**按钮**：[推送催料]（`pmc:shortage:push`，勾选物料 → 给采购员发送待办：物料、缺料数量、需要日期、影响的生产订单）、[导出]、[历史快照]（选择以前的分析结果查看）。

## 5. 业务规则

| 编号 | 规则 |
|---|---|
| PMC-SHT-R01 | 分析只读取数据不占用库存（与“预留”无关）；结果仅代表分析时点 |
| PMC-SHT-R02 | 倒冲物料同样参与分析（未领 = 应领 − 已倒冲） |
| PMC-SHT-R03 | 同一物料一天内推送催料只发送一次（重复推送合并） |
| PMC-SHT-R04 | 快照保留 30 天 |

## 6. 接口

`POST /pmc/shortages/analyze`、`GET /pmc/shortages?snapshotNo=&view=ORDER|MATERIAL`、`POST /pmc/shortages/push`、`GET /pmc/shortages/snapshots`；`PmcQueryApi.getShortage(prodOrderId)`（生产订单下达齐套检查复用）。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PMC-SHT-T01 | 螺丝可用 500；MO-1（优先级 1）需 408、MO-2 需 408 | 分析 | MO-1 齐套；MO-2 缺 316 |
| PMC-SHT-T02 | 螺丝在途 PO 1000 交期 10-05 | 分析 | MO-2 预计齐套 10-05 |
| PMC-SHT-T03 | MO-2 PCBA 可分配 60/100（单位用量 1） | 分析 | MO-2 可开工数量 60（假设其他料齐） |
| PMC-SHT-T04 | — | 推送催料 | 采购员收到待办，含影响的生产订单 |

# 06-05 排产与产能

## 1. 功能说明

- **产能日历**：每个工作中心每天的可用工时（默认取工作中心设置，可按日期调整：节假日、加班、停机）。
- **负荷分析**：已下达和已计划生产订单的工序负荷与产能对比。
- **排产**：按优先级和交期把生产订单工序排到工作中心的具体日期，输出计划开工/完工；支持甘特图查看和拖拽调整、插单模拟。

- 使用者：计划员、生产主管
- 优先级：P1（未使用排产时，生产订单按“计划开工/完工 = 需求日期倒推提前期”运作）

## 2. 数据表

### pmc_capacity_calendar 产能日历（例外日）

| 字段 | 类型 | 说明 |
|---|---|---|
| work_center_id | id | 为空表示全厂（节假日） |
| cal_date | date | |
| available_hours | rate | 当天可用工时（0 表示停工/休息） |
| reason | str(64) | 节假日 / 加班 / 设备保养 / 停电 |

未设置例外的日期：周一至周六取工作中心日产能，周日为 0（工作日模式参数化，P2）。

### pmc_schedule 排产结果

| 字段 | 类型 | 说明 |
|---|---|---|
| prod_order_id | id | |
| operation_seq | int | |
| work_center_id | id | |
| sched_start / sched_end | datetime | 排产开始/结束 |
| load_hours | rate | 工序负荷 = 准备 + 剩余数量 × 标准工时 |
| locked | bool | 锁定（自动排产不移动） |
| applied | bool | 已回写生产订单计划日期 |

## 3. 排产算法（有限产能模式）

1. 取待排订单：已计划和已下达、未完工的生产订单；排序：锁定的先占用 → 优先级（1 高）→ 需求日期（关联销售订单承诺交期/要求交期）→ 计划开工。
2. 对每张订单按工序顺序：从 max(今天, 物料齐套日期, 上道工序结束) 开始，在该工作中心逐日占用剩余产能直到负荷排完（支持跨天拆分）。
3. 订单完工 = 末道工序结束；晚于需求日期的订单标记“延期”（进入交期预警）。
4. 无限产能模式：不考虑已占用负荷，按提前期从需求日期倒排，只输出负荷分析。

## 4. 页面

### 4.1 产能日历（专用）

路由 `/pmc/capacity`。上方选择工作中心（或“全厂”）和月份；月历视图：每天显示可用工时（例外日橙色）、已排负荷、负荷率（>100% 红色）。点击日期编辑可用工时和原因；[批量设置]（日期范围、工时、原因，如“国庆 10-01～10-07 停工”）。

### 4.2 负荷分析（产能页第二个页签，T7）

选择日期范围、车间：表格（行 = 工作中心，列 = 日期或周）显示负荷 / 产能 / 负荷率，超载红色；点击单元格列出该工作中心当天的工序负荷明细（订单、产品、工序、工时）。

### 4.3 排产（甘特图）

路由 `/pmc/schedule`。

```
┌ [运行排产] [应用到生产订单] [插单模拟]   车间[SMT▾]  2026-09-25 ~ 10-10   (●)按工作中心 ( )按订单 ┐
├──────────┬──────────────────────────────────────────────────────────────────────┤
│ SMT1     │ ███MO-12(10)███ ░░MO-15(10)░░  ██MO-18██                              │
│ SMT2     │     ██MO-13(10)██████                                                │
│ DIP1     │           ███MO-12(20)███   ███MO-13(20)███                           │
└──────────┴──────────────────────────────────────────────────────────────────────┘
  图例：█ 按期  ▓ 延期  🔒 锁定   悬停显示：订单、产品、工序、数量、开始/结束、负荷、需求日期
```

- 使用 ECharts 自定义系列或轻量甘特组件实现；按天刻度，可缩放到周。
- 拖拽工序块到其他日期/同类工作中心 → 重新计算后续工序（不移动锁定的块）→ 标记为手工调整；右键：锁定/解锁、查看订单。
- [插单模拟]：选择一张（新）订单并设置优先级 → 在不保存的情况下重算 → 列出因此延期的其他订单（对比表：原完工、新完工、延期天数）→ [确认插单] 或 [取消]。
- [应用到生产订单]：把排产结果的订单开工/完工写回生产订单计划日期（只对未锁定且有变化的订单，确认列表后应用；`pmc:schedule:apply`）。

## 5. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| PMC-SCH-R01 | 同时只能有一个排产运算 | `排产正在运行中` |
| PMC-SCH-R02 | 拖拽不能放到比上道工序结束更早的时间；不能放到其他类型的工作中心（只允许同车间、同工序可用的工作中心） | `不能早于上道工序结束时间` |
| PMC-SCH-R03 | 应用到生产订单时，已下达订单的计划日期修改记录操作日志 | — |
| PMC-SCH-R04 | 没有工艺路线的订单按单一工序“完工”占用其车间默认工作中心（负荷 = 数量 × 产品标准工时，无标准工时时不占产能） | — |

## 6. 接口

`GET/PUT /pmc/capacity-calendars`、`POST /pmc/capacity-calendars/batch`、`GET /pmc/capacity/load?from=&to=&deptId=`、`POST /pmc/schedules/run`、`GET /pmc/schedules?from=&to=&deptId=`、`PUT /pmc/schedules/{id}`（拖拽）、`POST /pmc/schedules/{id}/lock`、`POST /pmc/schedules/simulate`、`POST /pmc/schedules/apply`。

## 7. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PMC-SCH-T01 | SMT1 日产能 17h；MO-12 工序 10 负荷 30h | 排产 | 占用第 1 天 17h、第 2 天 13h |
| PMC-SCH-T02 | 国庆停工 | 批量设置 10-01～10-07 为 0 | 排产跳过这些日期 |
| PMC-SCH-T03 | 插单优先级 1 | 插单模拟 | 列出被推迟的订单及延期天数；取消后排产不变 |
| PMC-SCH-T04 | 拖拽工序 20 到工序 10 结束之前 | — | 提示“不能早于上道工序结束时间” |

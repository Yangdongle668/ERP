# 06-04 MRP 建议处理

## 1. 功能说明

计划员/采购员查看最近一次成功运算的建议，调整数量和日期后确认转单：采购建议 → 采购申请；生产建议 → 生产订单（已计划）；委外建议 → 委外单（草稿）。例外信息推送给采购员/生产主管处理。

- 使用者：计划员、采购员
- 优先级：P0

## 2. 页面

### 2.1 建议列表（T1，四个页签：采购 / 生产 / 委外 / 例外）

路由 `/pmc/mrp/suggestions`。默认显示最近一次成功运算的“待处理”建议。

**查询条件**：运算号（默认最新）、物料、物料类别、计划员（默认当前用户）、采购员（采购页签）、默认供应商、下达日期（范围）、仅已延迟（开关）、状态（默认待处理）。

**采购 / 委外建议列**

| 列 | 说明 |
|---|---|
| 物料编码 / 名称 / 规格 / 单位 | |
| 建议数量 | 可编辑（QtyInput），修改后显示原值 |
| 净需求 | 只读 |
| 需求日期 | 可编辑 |
| 建议下达日期 | 已延迟时红色“延迟 N 天” |
| 供应商 | 可编辑（该物料可供供应商下拉） |
| 参考单价 / 金额 | 字段权限 `pur:price:view` |
| 可用库存 / 在途 | 只读 |
| 需求来源 | 链接：打开需求追溯抽屉（pegging） |
| 采购员 / 计划员 | |
| 状态 | |

**生产建议列**：物料、建议数量（可改）、需求日期、建议开工（= 下达日期）、建议完工、BOM 版本（下拉）、车间（默认）、齐套情况（[检查]：按子件可用 + 在途计算齐套率）、需求来源、状态。

**例外列**：类型（提前红 / 推迟蓝 / 取消灰 / 已逾期红）、物料、单据号（链接）、当前日期、建议日期、数量、说明、负责人（采购员/生产主管）、已处理（复选框）。

**按钮**

| 按钮 | 页签 | 权限 | 行为 |
|---|---|---|---|
| 转采购申请 | 采购 | `pmc:mrp:convert` | 勾选 → 调用 `PurchaseRequisitionApi.createFromMrp`（按计划员合并为一张或多张申请）→ 建议状态“已转单”，显示申请单号 |
| 转生产订单 | 生产 | `pmc:mrp:convert` | 勾选 → 调用 `ProductionOrderApi.createFromMrp` → 每条建议一张“已计划”生产订单；可选“同时下达” |
| 转委外单 | 委外 | `pmc:mrp:convert` | 勾选 → 按供应商生成委外单草稿 |
| 忽略 | 全部 | `pmc:mrp:ignore` | 原因必填 |
| 推送处理 | 例外 | `pmc:mrp:convert` | 给负责人发送工作台待办（附例外说明与单据链接） |
| 导出 | 全部 | — | |

### 2.2 需求追溯抽屉

显示该建议覆盖的需求：需求类型、来源单号（销售订单/预测/上层建议）、父件、数量、需求日期；上层为计划订单时可继续展开到顶层销售订单。

## 3. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| PMC-SUG-R01 | 只能转换最近一次成功运算的建议；旧运算的建议（SUPERSEDED）只读 | `该建议已过期，请使用最新的运算结果` |
| PMC-SUG-R02 | 转单前再次校验：物料启用；采购建议的供应商为合格/潜在；生产建议 BOM 已审核 | `物料「{code}」已停用` 等 |
| PMC-SUG-R03 | 修改建议数量时提示是否低于 MOQ / 不是 MPQ 倍数（警告） | — |
| PMC-SUG-R04 | 转单成功与否逐条返回，部分失败时列出原因，成功的仍然转换 | — |
| PMC-SUG-R05 | 转单后发布事件，在途/在制随之变化；下一次运算会计入这些新单据 | — |

## 4. 接口

`GET /pmc/mrp/suggestions?type=&runId=`、`PUT /pmc/mrp/suggestions/{id}`（调整数量、日期、供应商、BOM）、`POST /pmc/mrp/suggestions/convert`（ids、type、options）、`POST /pmc/mrp/suggestions/ignore`、`GET /pmc/mrp/suggestions/{id}/pegging`、`GET /pmc/mrp/exceptions`、`POST /pmc/mrp/exceptions/push`、`POST /pmc/mrp/exceptions/{id}/handled`。

## 5. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PMC-SUG-T01 | 3 条采购建议（同一计划员） | 转采购申请 | 生成 1 张 MRP 类型采购申请，3 行；建议显示申请单号 |
| PMC-SUG-T02 | 生产建议 | 转生产订单并同时下达 | 生产订单状态已下达 |
| PMC-SUG-T03 | 旧运算建议 | 转单 | 提示该建议已过期 |
| PMC-SUG-T04 | 提前例外 | 推送处理 | 采购员工作台出现待办“PO-… 建议提前到 10-27” |

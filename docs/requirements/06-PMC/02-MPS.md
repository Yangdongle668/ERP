# 06-02 MPS（主生产计划）

## 1. 功能说明

对成品（和关键半成品）按周编制生产计划：参考需求池（订单 + 预测）、库存和产能，平滑生产节奏。MPS 发布后，MRP 对 MPS 物料使用 MPS 计划数量作为需求（参数 `pmc.mrp.use-mps` 为是时）。

- 使用者：计划员、PMC 主管
- 优先级：P1（未启用 MPS 时 MRP 直接使用需求池）

## 2. 数据表

### pmc_mps MPS 单（BaseDocDO，编码规则 PMC_MPS）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | str(128) | 是 | |
| start_week / end_week | str(8) | 是 | ISO 周，如 `2026-W40`，最多 26 周 |
| mps_status | enum(DRAFT/PUBLISHED/CLOSED) | 是 | 每个周期只能有一张已发布的 MPS，新发布自动关闭旧的 |

### pmc_mps_line

| 字段 | 类型 | 说明 |
|---|---|---|
| material_id | id | 成品/半成品 |
| week | str(8) | |
| demand_qty | qty | 需求（系统计算：需求池该周未满足需求） |
| planned_qty | qty | 计划生产数量（计划员填写） |
| projected_on_hand | qty | 预计结存 = 上周结存 + 计划 + 在制到期 − 需求（系统计算） |
| remark | str(128) | |

## 3. 页面：MPS 编制（矩阵）

```
物料 \ 周            W40    W41    W42    W43    合计
FG1  需求           1000    500      0   1200
     在制完工          600      0      0      0
     计划生产 [   ]  [400]  [500]  [600]  [600]
     预计结存 (期初 200) 200   200    800    200
FG2  ...
```

- 行分组为每个物料 4 行：需求（只读）、在制完工（只读，生产订单计划完工在该周的剩余数量）、计划生产（可编辑）、预计结存（只读，< 安全库存橙色，< 0 红色）。
- 工具栏：[按需求生成]（计划 = max(0, 需求 + 安全库存 − 上周结存 − 在制)，按 MPQ 取整）、[添加物料]、[产能检查]（按产品工艺路线换算各工作中心每周负荷，超出产能的周标红）、[保存]、[发布]。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| PMC-MPS-R01 | 只能对有已审核 BOM 的自制件编制 | `物料「{code}」不是自制件或没有 BOM` |
| PMC-MPS-R02 | 发布后 MRP 运算时：MPS 物料的独立需求 = MPS 计划数量（落在该周周一），不再直接使用需求池中该物料的订单/预测需求 | — |
| PMC-MPS-R03 | 已发布 MPS 需要调整时复制为新草稿，发布时替换 | — |
| PMC-MPS-R04 | 过去的周自动锁定不可编辑 | — |

## 5. 接口

`/pmc/mps`（CRUD、publish、close、copy）、`GET /pmc/mps/{id}/matrix`、`PUT /pmc/mps/{id}/matrix`、`POST /pmc/mps/{id}/generate`、`POST /pmc/mps/{id}/capacity-check`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| PMC-MPS-T01 | FG1 W40 需求 1000，期初 200，在制 600，安全库存 0 | 按需求生成 | W40 计划 200 |
| PMC-MPS-T02 | W41 计划 500 超出 SMT1 产能 | 产能检查 | W41 标红 |
| PMC-MPS-T03 | 发布 MPS，启用 use-mps | 运行 MRP | FG1 需求取 MPS 计划数量 |

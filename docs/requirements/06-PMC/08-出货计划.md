# 06-08 出货计划

## 1. 功能说明

计划员按周（或日）编制出货计划：根据订单承诺交期和成品可用库存，确定本周要出哪些订单、多少数量，发布后出货模块据此生成出货通知。

- 使用者：计划员、船务
- 优先级：P1（未使用出货计划时，船务可直接从销售订单生成出货通知）

## 2. 数据表

| 字段 | 类型 | 说明 |

| plan_status | enum(DRAFT/PUBLISHED/CLOSED) | |

### pmc_shipping_plan_line

| 字段 | 类型 | 说明 |
|---|---|---|
| order_line_id | id | 销售订单行 |

| line_status | enum(PLANNED/NOTICED/CANCELED) | |
| remark | str(256) | |

## 3. 页面

### 3.1 出货计划列表（T1）

查询：周、状态。列：单号、周、行数、计划数量、已通知行数、状态、操作（编辑、发布、关闭）。

### 3.2 编辑页（T4）

单头：计划周*。工具栏 [生成计划]：取承诺交期（无则要求交期）在该周及之前、未出货数量 > 0 的订单行，计划数量 = min(未出货, 可用库存按交期先后分配)，计划日期 = max(承诺交期, 周一)。
明细：订单号、客户、物料、承诺交期、未出货、可用、计划数量（可改）、计划日期（可改）、运输方式、备注；可用不足的行橙色。

发布后发布 `ShippingPlanPublishedEvent`，出货模块在“出货通知”中提供“从出货计划生成”。

## 4. 业务规则

| 编号 | 规则 | 提示原文 |
|---|---|---|
| PMC-SP-R01 | 计划数量 ≤ 订单未出货数量 | `计划数量不能超过未出货数量 {qty}` |
| PMC-SP-R02 | 同一订单行在同一周只能有一条计划 | — |
| PMC-SP-R03 | 出货通知生成后回写 noticed_qty；发布后仍可修改未通知的行 | — |

## 5. 接口

`/pmc/shipping-plans`（CRUD、generate、publish、close）；`ShippingPlanApi.getPlanLines(week)`。

## 6. 验收用例

| 编号 | 前置条件 | 操作 | 预期结果 |

| PMC-SP-T02 | 发布 | — | 出货模块可从该计划生成出货通知 |

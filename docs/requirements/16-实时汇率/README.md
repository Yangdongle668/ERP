# 16 实时汇率（总览）

## 1. 模块定位

后台服务模块：自动获取**中国银行外汇牌价的现汇买入价**，计算日平均、月平均汇率，并推送给其他模块使用，**不需要人工维护汇率**。

| 汇率对 | 来源 | 推送 |
|---|---|---|
| USD_CNY（1 美元 = x 人民币） | 中国银行「美元」现汇买入价 ÷ 100 | 系统汇率表 USD（日汇率、月末汇率） |
| EUR_CNY（1 欧元 = x 人民币） | 中国银行「欧元」现汇买入价 ÷ 100 | 系统汇率表 EUR（日汇率、月末汇率） |
| EUR_USD（1 欧元 = x 美元） | 交叉汇率 EUR_CNY ÷ USD_CNY（中国银行不直接报价） | 仅本模块（`FxRateApi`、事件） |

汇率均保留 6 位小数。只有本位币为人民币时才写入系统汇率表；本位币不是人民币时只在本模块保存。

## 2. 功能与页面

| 功能 | 页面 | 路由 | 菜单权限 |
|---|---|---|---|
| 汇率看板 | 最新报价卡片、获取状态、日平均、月平均 | `/fx/rates` | `fx:rate:query` |

「立即获取」按钮需要 `fx:rate:refresh`（忽略 15 分钟缓存）。

## 3. 业务规则

| 编号 | 规则 |
|---|---|
| FX-R01 | 数据源：`https://www.boc.cn/sourcedb/whpj/`（配置 `erp.fx.boc-url`），按表头识别「现汇买入价」列，页面单位为每 100 外币；发布日期、时间取页面上的值。同一汇率对、同一发布时间的报价只记录一次。 |
| FX-R02 | 轮询：每 15 分钟一次，结果在内存缓存 15 分钟（`FxRateApi.latest` 直接返回缓存，超过 15 分钟未成功刷新时标记 stale 并返回最后一次成功的值）。失败时指数退避：1、2、4、8、16、32、60、60…分钟，成功后恢复 15 分钟。系统参数 `fx.enabled` 关闭、备份恢复的维护期间暂停。 |
| FX-R03 | 日平均汇率 = 当天全部报价的算术平均。当天进行中时每次取得新报价即更新（“当日进行中”），并以此作为当天的系统日汇率；当天结束后由定时任务 `FX_SETTLE`（每天 00:05）结算（“已结算”）。服务器停机漏掉的日期在下次结算时补算（回看到上上月 1 日）。 |
| FX-R04 | 月平均汇率 = 当月各日平均汇率的算术平均，月份结束后由 `FX_SETTLE` 结算（月初 00:05；漏掉时补算上上月），写入系统汇率表的**月末汇率**（生效日期为当月最后一天）。 |
| FX-R05 | 推送：USD、EUR 的日平均写入系统日汇率、月平均写入系统月末汇率，来源为“自动”；同一币别、类型、日期已有**手工或导入**的汇率时以人工为准、不覆盖。每次取得报价、日 / 月平均更新时发布 `FxRateUpdatedEvent`（QUOTE / DAILY / MONTHLY），其他模块可监听或通过 `FxRateApi` 查询。 |
| FX-R06 | 保存期限：报价、日平均、月平均保存 3 年，`FX_SETTLE` 每天删除 3 年前的数据。 |

## 4. 数据表

fx_quote（报价）、fx_daily_rate（日平均：avg / min / max / sample_count / finalized）、fx_monthly_rate（月平均：rate_month、day_count）。

## 5. 接口

| 方法 | 路径 | 权限 |
|---|---|---|
| GET | /fx/status | `fx:rate:query`：最新报价、今日平均、上次成功 / 尝试、连续失败次数、下次获取时间、错误信息 |
| POST | /fx/refresh | `fx:rate:refresh`：立即获取 |
| GET | /fx/daily?pair=&from=&to= | `fx:rate:query`：默认近 30 天，最多 1 年 |
| GET | /fx/monthly?limit=36 | `fx:rate:query` |

跨模块：`FxRateApi.latest(pair)`、`dailyAverage(pair, date)`、`monthlyAverage(pair, month)`；事件 `FxRateUpdatedEvent`。业务单据仍通过 `CurrencyApi.getRate` 取系统汇率表中的汇率（已由本模块自动维护）。

## 6. 配置

| 配置 | 默认 | 说明 |
|---|---|---|
| 系统参数 `fx.enabled` | 是 | 自动获取汇率 |
| `erp.fx.poll-enabled` | true | 是否启动轮询（测试环境为 false） |
| `erp.fx.boc-url` | 中国银行外汇牌价页 | 数据源地址 |
| `erp.fx.first-delay-seconds` | 30 | 启动后首次获取的延迟 |

服务器需要能访问 www.boc.cn（HTTPS 443）。

## 7. 验收用例

| 编号 | 场景 | 预期 |
|---|---|---|
| FX-T01 | 同一天取得 7.10、7.20 两笔美元报价 | 日平均 7.15（当日进行中），系统 USD 日汇率 7.15、来源自动；EUR_USD = EUR ÷ USD |
| FX-T02 | 数据源连接超时 | 提示“获取中国银行汇率失败：连接超时”，连续失败次数 +1，按退避重试；恢复后清零 |
| FX-T03 | 当天已有手工维护的 EUR 日汇率 | 自动汇率不覆盖 |
| FX-T04 | 1 月两天日平均 6.0、6.2，2 月 2 日结算 | 1 月日平均已结算；月平均 6.1，系统 USD 1 月月末汇率 6.1 |
| FX-T05 | 3 年前的报价 | 结算时删除 |

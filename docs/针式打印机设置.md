# 针式打印机设置（多联单据）

ERP 的入库单、出库单、领料单、退料单、送货单等内置“针式二等分”模板，按 **241 × 140mm（9.5 × 5.5 英寸，二等分）** 连续纸设计，一次打印由复写纸出全部联次。每台打单电脑按下面设置一次即可。

## 1. Windows 新建纸张（只需一次）

1. 控制面板 → 设备和打印机 → 选中针式打印机（如 Epson LQ-630K / LQ-735K）→ 顶部「打印服务器属性」。
2. 勾选「创建新纸张规格」，名称填 `ERP二等分`，宽度 `24.13cm`，高度 `13.97cm`，边距全部 `0`，点「保存纸张规格」。
   - 三等分纸：宽 `24.13cm`、高 `9.31cm`；整张：宽 `24.13cm`、高 `27.94cm`。
3. 打印机右键「打印首选项」→ 纸张/质量 → 高级 → 纸张规格选 `ERP二等分`，纸张来源选「连续纸 / 拖纸器」。

## 2. 浏览器打印（Chrome / Edge）

在 ERP 中点 [打印]，弹出的预览窗口点 [打印]，打印对话框里：

| 设置 | 选择 |
|---|---|
| 目标打印机 | 针式打印机 |
| 纸张尺寸 | ERP二等分 |
| 边距 | 无 |
| 缩放 | 100%（默认） |
| 页眉和页脚 | 不勾选 |
| 背景图形 | 不需要 |

浏览器会记住上次的设置，之后直接打印即可。

## 3. 对齐与常见问题

- **第一张对齐撕纸线**：进纸后让打印头对准纸张上边缘（可用打印机的“微调/撕纸”键），之后每张自动对齐。
- **越打越偏**：二等分纸高度必须是 13.97cm（5.5 英寸），不要填 14cm。
- **内容被裁掉 / 缩小**：检查缩放是否为 100%、边距是否为「无」。
- **一张单据打成多页**：明细超过每页行数（二等分 16 行，采购订单 15 行）时自动分页，每页都有单头和签名栏，合计在最后一页。
- **字迹太淡**：针式打印机色带需要定期更换；模板已用纯黑细线、宋体 8.5pt，不使用灰色和底色。字太小看不清时，可复制模板把 `font-size: 8.5pt` 改为 9pt，并把每页行数减 1。
- **扫不出条码**：条码已按针式打印加宽到 55mm；打印头老化、色带太淡时会影响扫描。
- **需要激光打印机打印**：在「系统管理 / 打印模板」复制针式模板，把打印方式改为「普通纸逐联打印」，每联会单独打印一页并标出联次。

## 4. 修改版式

「系统管理 / 打印模板」中复制内置模板后可改：每页行数、联次说明、签名栏文字、列宽等。公司 Logo、中英文名称取「系统管理 / 组织架构」中公司的设置。

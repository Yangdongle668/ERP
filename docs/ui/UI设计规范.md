# UI 设计规范

> 本规范是所有前端页面的强制约定。各模块需求文档中的页面定义只写“用哪个模板 + 具体字段/按钮”，模板的通用行为以本文为准。
> 技术基础：Vue 3 + Element Plus 2.x（中文语言包），不引入其他 UI 库。

## 1. 设计原则

1. **效率优先**：ERP 用户每天长时间录单。支持键盘操作、批量操作，尽量减少页面跳转和弹窗层级（弹窗最多两层）。
2. **一致**：同类页面结构、按钮位置、文案、颜色完全一致。用户学会一个模块，其他模块就会用。
3. **防错**：能选择的不让输入，能带出的不让重复填，危险操作二次确认，未保存离开提醒。
4. **信息密度适中**：列表一屏显示 15～20 行数据；表单尽量一屏显示完单头。

## 2. 基础规范

### 2.1 分辨率与适配

| 项 | 规范 |
|---|---|
| 设计基准 | 1920 × 1080 |
| 最小支持 | 1366 × 768，此时不得出现页面级横向滚动条（表格内部可横向滚动） |
| 浏览器 | Chrome / Edge 最新两个版本 |
| 移动端 | 不适配（工作台审批的 H5 页面另行设计，P2） |

### 2.2 颜色

使用 Element Plus 默认主题色，不自定义品牌色，降低维护成本。

| 用途 | 颜色变量 | 色值 |
|---|---|---|
| 主色（主按钮、链接、选中） | `--el-color-primary` | #409EFF |
| 成功 | `--el-color-success` | #67C23A |
| 警告 | `--el-color-warning` | #E6A23C |
| 危险 / 错误 / 负数 | `--el-color-danger` | #F56C6C |
| 信息 / 次要 | `--el-color-info` | #909399 |
| 主文字 | `--el-text-color-primary` | #303133 |
| 次要文字 | `--el-text-color-secondary` | #909399 |
| 页面背景 | `--el-bg-color-page` | #F2F3F5 |
| 卡片背景 | `--el-bg-color` | #FFFFFF |

### 2.3 字体与字号

- 字体：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`
- 数字列（数量、金额、单号）使用等宽数字：`font-variant-numeric: tabular-nums`

| 用途 | 字号 | 字重 |
|---|---|---|
| 页面标题（单据页头） | 18px | 600 |
| 卡片/分组标题 | 15px | 600 |
| 正文、表单、表格 | 14px | 400 |
| 辅助说明、表单提示 | 12px | 400 |
| 工作台指标数字 | 28px | 600 |

### 2.4 间距

以 4px 为单位：4 / 8 / 12 / 16 / 24。

| 位置 | 间距 |
|---|---|
| 内容区与页面边缘 | 16px |
| 卡片内边距 | 16px（Element 默认 20px 改为 16px） |
| 卡片之间 | 12px |
| 按钮之间 | 8px |
| 表单项垂直间距 | 18px（Element 默认） |

### 2.5 组件尺寸

| 组件 | 尺寸 |
|---|---|
| 全局（`el-config-provider size`） | `default` |
| 表格 | `default`，行高约 40px；单据明细可编辑表格也用 `default` |
| 查询区表单 | `default` |
| 弹窗宽度 | 小 480px（确认、原因）/ 中 640px（单列表单）/ 大 960px（双列表单、选择器）/ 超大 1200px（选单） |
| 抽屉宽度 | 720px（详情预览） |

```

│          ├────────────────────────────────────────────────────────────────┤
│ 工作台    │ [工作台] [物料 ×] [销售订单 ×] [SO-202609-0001 ×]                 │ ← 页签栏 36px
│ CRM   ▸  ├────────────────────────────────────────────────────────────────┤
│ 销售   ▸  │                                                                │
│ 研发工程 ▾│                     内容区（padding 16px）                       │
│   项目    │                                                                │
```

### 3.1 侧边栏

- 两级菜单：模块 → 页面。只显示有权限的菜单；模块下没有任何有权限的页面时整个模块隐藏。
- 手风琴模式（同时只展开一个模块）。
- 当前页面高亮，且自动展开所属模块。
- 折叠状态记住在本地（localStorage），折叠后鼠标悬停显示二级菜单。

### 3.2 头部

| 元素 | 行为 |
|---|---|
| 折叠按钮 | 展开/折叠侧边栏 |
| 面包屑 | `模块 / 页面`；单据详情页为 `模块 / 页面 / 单号` |
| 菜单搜索 | 输入拼音首字母或中文，下拉匹配菜单，回车跳转。快捷键 `Ctrl + K` 聚焦 |
| 待办铃铛 | 显示待办数量角标（>99 显示 99+），每 60 秒刷新；点击下拉显示最近 10 条待办，底部“查看全部”跳转工作台待办 |
| 用户菜单 | 个人中心、修改密码、切换语言（中文/English）、退出登录 |

### 3.3 多页签栏

- 每打开一个页面新增一个页签；已打开的页面再次点击菜单时切换到该页签而不是新开。
- 单据详情/编辑页按单号或“新建销售订单”作为页签标题，同一单据只开一个页签。
- 页签缓存页面状态（`keep-alive`）：切换回列表时保留查询条件、页码、滚动位置。
- 右键菜单：刷新、关闭、关闭其他、关闭右侧、关闭全部。“工作台”页签固定不可关闭。
- 最多 20 个页签，超出时自动关闭最早打开的未修改页签。
- 页签内有未保存修改时标题前显示 `●`，关闭时提示“有未保存的修改，确定关闭吗？”。

## 4. 页面模板

所有业务页面必须从以下模板中选用。模块需求文档中用模板代号（如 **T1**）说明页面类型。

### T1 列表页

```
┌───────────────────────────────────────────────────────────────────────┐
│ 单号 [__________]  客户 [______▾]  状态 [全部▾]  日期 [____ ~ ____]      │ 查询区
│                                            [查询] [重置] 展开 ⌄         │
├───────────────────────────────────────────────────────────────────────┤
│ [+ 新建] [批量审核] [批量删除]                    [导入] [导出] ⚙ ⟳     │ 工具栏
├───────────────────────────────────────────────────────────────────────┤
│ ☐ │ 单号 ▲       │ 客户      │ 日期       │ 金额       │ 状态   │ 操作        │
│ ☐ │ SO-2609-0001 │ ABC Ltd  │ 2026-09-24 │ 12,500.00 │ 已审核 │ 编辑 更多▾   │ 表格
│ ...                                                                  │
├───────────────────────────────────────────────────────────────────────┤
│                              共 128 条  [20条/页▾] ‹ 1 2 3 … 7 ›        │ 分页
└───────────────────────────────────────────────────────────────────────┘
```

**查询区**
- 默认显示一行（1920 宽度最多 4 个条件，1366 宽度 3 个），其余条件点击“展开”显示。
- 条件控件宽度统一 200px；日期范围 260px。
- 输入框回车即查询；下拉、日期变更不自动查询，需点“查询”。
- “重置”恢复默认条件并查询。
- 文本条件默认模糊匹配；单号、编码条件为前缀匹配（需求文档另有说明的除外）。
- 列表的默认条件（如“近 3 个月”）在各页面定义中说明。

**工具栏**
- 左侧：主操作（新建，`type=primary`，带 `Plus` 图标），然后是批量操作（勾选后才可用，未勾选时置灰并提示“请先勾选数据”）。
- 右侧（图标按钮 + tooltip）：导入、导出、列设置、刷新。
- 批量操作结果：全部成功提示“操作成功 N 条”；部分失败弹窗列出失败的单号和原因。

**表格**
- 第一列勾选框（有批量操作时才显示）。
- 单号/编码列：蓝色链接，点击打开详情页（单据）或编辑弹窗（主数据）。
- 状态列：`StatusTag`（颜色见 7.3）。
- 数量、金额、单价列右对齐；文本左对齐；状态、日期、是否类列居中。
- 超长文本单行省略 + 悬停提示（`show-overflow-tooltip`）。
- 操作列固定在右侧，最多直接显示 3 个文字按钮，其余放入“更多 ▾”下拉。按钮按单据状态和权限显示，不可用时**隐藏**而不是置灰。
- 支持列排序的列在需求文档中标注“可排序”，排序由后端执行。
- 列设置：可调整显示/隐藏、顺序，按用户 + 页面保存在本地；提供“恢复默认”。
- 需要合计的列表（如订单明细查询）在底部显示当前页合计和查询结果总计。
- 空数据显示 `el-empty`：“暂无数据”。

**分页**：每页 20 / 50 / 100 / 200，默认 20；显示总条数；翻页后表格滚动回顶部。

### T2 弹窗表单（主数据新建/编辑）

- 用于字段不超过 12 个的主数据（如计量单位、币别、字典项）。
- 标题：“新建XXX” / “编辑XXX”。
- 单列布局用中弹窗（640px），label 宽 100px；字段 7～12 个用双列布局 + 大弹窗（960px）。
- 底部按钮：右对齐 [取消] [保存]；新建时可额外提供 [保存并新建]。
- 点击遮罩不关闭；有修改时关闭提示“有未保存的修改，确定关闭吗？”。
- 保存成功：关闭弹窗、提示“保存成功”、刷新列表并保持当前页。

### T3 独立表单页（复杂主数据）

- 用于字段多、有分组或子表的主数据（如用户、物料、客户、供应商）。
- 路由：`/<模块>/<资源>/new`、`/<模块>/<资源>/:id/edit`。
- 结构：页头（返回、标题、[取消] [保存]）+ 若干分组卡片（或 Tabs）。
- 表单栅格：1920 下每行 3 列，1366 下每行 2 列；文本域、地址类占整行。

### T4 单据编辑页（单头 + 明细）

```
┌───────────────────────────────────────────────────────────────────────┐
│ ← 新建销售订单                                  [取消] [保存草稿] [提交]  │ 页头（吸顶）
├───────────────────────────────────────────────────────────────────────┤
│ 基本信息                                                               │
│ 单号 [自动生成]      单据日期 [2026-09-24]   客户* [ABC Ltd      ▾]     │
│ 客户PO号 [______]   币别* [USD▾]            汇率* [7.1000]            │
│ 交易信息 ▸（可折叠）                                                    │
├───────────────────────────────────────────────────────────────────────┤
│ 明细  [+ 添加行] [批量添加物料] [从报价选单] [导入] [删除选中]             │
│ ☐ 行 │ 物料编码*   │ 名称    │ 规格  │ 单位 │ 数量*  │ 单价*  │ 金额   │ 交期*  │ ⋯ │
│ ☐ 1  │ M000001  🔍 │ FPC排线 │ 20P  │ PCS │ 1,000 │ 0.50  │ 500.00 │ 10-30 │ 🗑 │
│ ☐ 2  │ [       ] 🔍│         │      │     │       │       │        │       │   │
│                                                    合计 │ 1,000 │        │ 500.00 │
├───────────────────────────────────────────────────────────────────────┤
│ 备注 [___________________________]      附件 [上传]                      │
└───────────────────────────────────────────────────────────────────────┘
```

**页头**：左侧返回箭头 + 标题（新建时“新建XXX”，编辑时“编辑XXX SO-…”）；右侧按钮从左到右：[取消] [保存草稿] [提交]（提交为主按钮）。页头滚动时吸顶。

**单头**：按分组卡片展示（基本信息 / 交易信息 / 其他），次要分组可折叠。选择客户/供应商等主数据后自动带出默认值（币别、付款条件、业务员等），带出的值可修改。

**明细行（可编辑表格，`LinesEditor` 组件）**
- 行号自动生成（10、20、30…，便于插行；显示为 1、2、3 亦可，各单据统一用 1、2、3）。
- 物料单元格：输入编码或名称后回车/失焦 → 精确匹配编码则直接带出；否则弹出物料选择器。带出名称、规格、单位、默认单价等只读字段。
- 键盘：`Enter` / `Tab` 移到下一个可编辑单元格；在最后一行最后一个单元格回车自动新增一行；`↑` `↓` 在同一列上下移动；`Ctrl + Delete` 删除当前行。
- 自动计算：数量 × 单价 = 金额；修改后实时刷新底部合计。
- 行校验：保存时校验所有行，有错误的单元格标红，鼠标悬停显示原因，并滚动到第一处错误。
- 空行（物料为空）保存时自动忽略；至少需要一行有效明细，否则提示“请至少添加一行明细”。
- 行操作：删除、复制行、插入行（在当前行上方）。
- 从上游选单：打开 `SourceDocPicker`，勾选上游单据行后带入，数量默认为上游剩余可执行数量。
- 超过 200 行时启用虚拟滚动。

**保存与提交**
- 保存草稿：只做必填和格式校验，状态为草稿。
- 提交：做全部校验 → 保存 → 提交审批（或直接审核）。成功后跳转到详情页，并关闭当前编辑页签。
- 快捷键：`Ctrl + S` 保存草稿，`Ctrl + Enter` 提交。
- 离开页面（关闭页签、点击返回、刷新浏览器）且有未保存修改时提示。

### T5 单据详情页

```
┌───────────────────────────────────────────────────────────────────────┐
│ ← SO-202609-0001  [已审核]      [打印▾] [更多▾] [反审核] [关闭] [下推出货] │ 页头
├───────────────────────────────────────────────────────────────────────┤
│ ● 草稿 ──── ● 待审批 ──── ◉ 已审核 ──── ○ 执行中 ──── ○ 已完成             │ 状态步骤条
├───────────────────────────────────────────────────────────────────────┤
│ 客户：ABC Ltd       单据日期：2026-09-24     币别：USD   汇率：7.1000    │
│ 业务员：张三         交期：2026-10-30         金额：USD 12,500.00         │ 单头（描述列表）
├───────────────────────────────────────────────────────────────────────┤
│ [明细] [执行情况] [关联单据] [审批记录] [操作日志] [附件(2)]               │ 页签
│  ...                                                                   │
└───────────────────────────────────────────────────────────────────────┘
```

- 页头按钮按**状态 + 权限**显示（各单据的“按钮显示矩阵”在需求文档中定义）。主要动作（如审核、下推）在最右侧并为主按钮，危险动作（作废、反审核、关闭）用普通按钮 + 二次确认 + 原因弹窗。
- 状态步骤条显示标准流程；已关闭/已作废时步骤条替换为对应状态的提示条（`el-alert`）。
- 单头使用 `el-descriptions`，1920 下 4 列、1366 下 3 列。
- 固定页签：
  - **明细**：只读表格，含执行数量列（如已出货、已开票）。
  - **执行情况**：每行的上下游数量对照（按单据定义）。
  - **关联单据**：上游和下游单据列表（单据类型、单号、日期、状态），点击跳转。
  - **审批记录**：`ApprovalTimeline`，时间线显示每个节点的审批人、结论、意见、时间。
  - **操作日志**：`OperationLogTable`，显示状态变更历史（操作、从 → 到、原因、操作人、时间）。
  - **附件**：`AttachmentPanel`，草稿状态可上传/删除，其他状态只读（需求文档另有规定除外）。

### T6 树 + 列表页

- 用于有层级的数据（组织架构、物料类别）。
- 左侧树 260px：顶部搜索框（过滤并展开匹配节点），节点右侧悬停显示 [+下级] [编辑] [删除] 图标。
- 右侧：选中节点的下级列表或关联数据列表（T1 结构）。
- 或使用**树形表格**（`el-table` 的 `tree-props`）：适用于节点字段较多、需要表格形式查看的场景。各页面在需求文档中指明。

### T7 报表页

- 查询区（同 T1）+ 汇总指标卡片（可选）+ 图表（可选，`ECharts`，按需引入）+ 明细表格。
- 所有报表支持导出 Excel，导出内容与当前查询条件一致。
- 报表数据截止时间显示在右上角：“数据更新于 2026-09-24 10:00”。

### T8 配置页

- 用于参数、编码规则等配置：左侧分组导航（或 Tabs），右侧分组表单，底部 [保存]。
- 每个参数下方用 12px 灰字说明作用和影响。

## 5. 公共组件清单

以下组件由前端框架层统一实现（位于 `erp-ui/src/components/`），各模块只能使用，不得自行实现同类组件。

### 5.1 列表类

| 组件 | 说明 | 关键属性 |
|---|---|---|
| `ErpSearchForm` | 查询区（T1），自动处理展开/收起、回车查询、重置 | `fields`（配置式）、`v-model`、`@search`、`@reset` |
| `ErpTable` | 表格封装：列配置、列设置持久化、合计行、操作列、状态标签、数字格式 | `columns`、`data`、`loading`、`selection`、`summary`、`storageKey` |
| `ErpPagination` | 分页 | `v-model:pageNo`、`v-model:pageSize`、`total` |
| `useListPage` | 组合式函数：查询参数、加载、分页、勾选、刷新、keep-alive 恢复 | `api`、`defaultQuery` |

### 5.2 表单与选择器

| 组件 | 说明 |
|---|---|
| `DictSelect` / `DictRadio` / `DictTag` | 数据字典驱动的下拉、单选和标签（颜色取字典项配置） |
| `StatusTag` | 单据状态标签，颜色见 7.3 |
| `MaterialSelect` | 物料远程搜索下拉：按编码/名称/规格搜索，下拉显示“编码 名称 规格 单位”，只能选启用物料；可按物料类型过滤 |
| `MaterialPickerDialog` | 物料批量选择弹窗：左侧物料类别树，右侧物料列表（多选、分页），已选区域显示在底部 |
| `CustomerSelect` | 客户远程搜索（编码/名称/简称），可按状态过滤（下单只能选正式客户） |
| `SupplierSelect` | 供应商远程搜索，可按状态过滤 |

## 6. 交互规范

### 6.1 按钮

| 场景 | 规范 |
|---|---|
| 主按钮 | 每个区域最多一个 `type=primary` |
| 顺序 | 工具栏：主操作在最左；弹窗/页头：[取消] 在左，主操作在最右 |
| 文案 | 动词或动宾短语，2～4 个字：新建、编辑、删除、保存、提交、审核、反审核、关闭、作废、打印、导入、导出、下推出货 |
| 防重复提交 | 点击后按钮进入 loading 状态，接口返回前不可再次点击 |
| 危险操作 | 删除、作废、反审核、关闭、停用、重置密码：二次确认 |
| 不可用 | 因状态或权限不可用的按钮**隐藏**；因条件未满足暂时不可用（如未勾选数据）的按钮**置灰**并用 tooltip 说明原因 |

### 6.2 确认与提示文案模板

| 场景 | 文案 |
|---|---|
| 删除确认 | 确定删除{对象}「{编号} {名称}」吗？删除后不可恢复。 |
| 批量删除确认 | 确定删除选中的 {N} 条{对象}吗？删除后不可恢复。 |
| 作废确认 | 作废后单据不可恢复，也不再参与任何统计。请填写作废原因。 |
| 反审核确认 | 反审核后单据回到草稿状态，可以修改。请填写反审核原因。 |
| 关闭确认 | 关闭后剩余数量不再执行。请填写关闭原因。 |
| 停用确认 | 停用后{对象}不能在新单据中使用，已有单据不受影响。确定停用吗？ |
| 未保存离开 | 有未保存的修改，确定离开吗？ |
| 保存成功 | 保存成功 |
| 提交成功 | 提交成功（需审批时：已提交，等待审批） |
| 审核成功 | 审核成功 |
| 批量操作部分失败 | 成功 {M} 条，失败 {N} 条（弹窗列出失败明细） |

### 6.3 消息反馈

| 类型 | 组件 | 时长 |
|---|---|---|
| 操作成功 | `ElMessage.success` | 2 秒 |
| 业务错误（后端 code ≠ 0） | `ElMessage.error`，显示后端返回的 msg | 4 秒 |
| 系统错误（HTTP 500） | `ElMessageBox.alert`：“系统异常，请联系管理员。追踪号：xxx”，追踪号可一键复制 | 手动关闭 |
| 网络错误 | `ElMessage.error`：“网络异常，请稍后重试” | 4 秒 |
| 登录过期 | 自动用刷新令牌续期；续期失败跳转登录页，登录后回到原页面 | — |
| 无权限（403） | `ElMessage.warning`：“没有该操作权限” | 3 秒 |
| 并发修改 | `ElMessageBox.confirm`：“数据已被他人修改，是否刷新？”，确定后重新加载 | 手动 |

### 6.4 表单校验

- 必填字段 label 前显示红色 `*`。
- 校验时机：失焦时校验单个字段；保存/提交时校验全部，并滚动到第一个错误字段。
- 提示文案：输入类“请输入{字段}”，选择类“请选择{字段}”，格式类“{字段}格式不正确，{规则说明}”，范围类“{字段}必须在 {min}～{max} 之间”。
- 后端返回的字段级校验错误（400）在对应字段下显示；无法定位字段的用消息提示。
- 输入框自动去除首尾空格。
- 编码类字段（编码、单号）输入时自动转为大写（需求文档另有说明除外）。

## 7. 显示格式

### 7.1 空值

- 空值统一显示 `-`（表格、描述列表）；表单中为空的输入框显示 placeholder。

### 7.2 数字与日期

| 类型 | 格式 | 示例 |
|---|---|---|
| 数量 | 千分位；小数位按单位精度，末尾 0 去掉 | `1,000`、`12.5`、`0.125` |
| 金额 | 千分位，固定 2 位小数（币别精度为 0 时 0 位） | `12,500.00` |
| 带币别金额 | 币别代码 + 空格 + 金额 | `USD 12,500.00` |
| 单价 | 最多 6 位小数，末尾 0 去掉，至少 2 位 | `0.50`、`0.1234` |
| 汇率 | 固定 4 位小数（存储 6 位） | `7.1000` |
| 百分比 | 2 位小数 + `%` | `12.50%` |
| 负数 | 前置 `-`，红色 | <span>-1,200.00</span> |
| 日期 | `YYYY-MM-DD` | `2026-09-24` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss`；列表中可只显示到分钟 `YYYY-MM-DD HH:mm` | `2026-09-24 13:53` |
| 时长 | `N 天`、`N 小时 M 分` | `3 天` |

### 7.3 状态颜色（`StatusTag`）

| 状态 | 颜色 | Element type |
|---|---|---|
| 草稿 | 灰 | `info` |
| 待审批 / 待检 / 待处理 | 橙 | `warning` |
| 已审核 / 执行中 / 检验中 | 蓝 | `primary` |
| 已完成 / 合格 / 启用 / 已通过 | 绿 | `success` |
| 已关闭 / 停用 | 灰 | `info`（`effect=plain`） |
| 已作废 / 不合格 / 已驳回 / 黑名单 | 红 | `danger` |

模块特有状态在需求文档中给出颜色；未给出的按语义套用上表。

## 8. 权限在界面上的表现

| 类型 | 表现 |
|---|---|
| 菜单权限 | 无权限的菜单不显示；直接访问地址跳转 403 页 |
| 按钮权限 | 无权限的按钮不显示（`v-perm`） |
| 数据权限 | 列表只返回有权限的数据，界面无额外提示 |
| 字段权限 | 敏感字段（成本价、采购价、毛利）无权限时，列表和详情显示 `***`，表单中不显示该字段，导出中该列为空 |

## 9. 导入导出与打印

### 9.1 导入

- 模板为 `.xlsx`，第一行为中文列名，必填列名后带 `*`，第二行为填写说明（灰色斜体，导入时忽略）。
- 下拉型字段在模板中使用数据验证下拉；日期列设置为日期格式。
- 单次最多 5000 行；超出提示“单次最多导入 5000 行，请拆分文件”。
- 校验错误报告：在原文件最后增加“错误原因”列，错误单元格标红。

### 9.2 导出

- 文件名：`{页面名称}_{yyyyMMddHHmmss}.xlsx`。
- 列与当前列表“列设置”中显示的列一致，顺序一致；金额、数量为数字格式（不是文本）。
- 字段权限不足的列导出为空。

### 9.3 打印

- 纸张默认 A4 纵向，明细列多的单据用 A4 横向（在打印模板中设置）。
- 版式：页眉（公司 Logo、公司名称、单据名称，右上角单号 + 条码）→ 单头信息 → 明细表（跨页时每页重复表头）→ 合计 → 备注 → 签字栏（制单、审核、签收）→ 页脚“第 X 页 / 共 Y 页”、打印时间。
- 对外单据（报价单、PI、Packing List、Invoice）提供英文模板。
- 打印模板管理见《01-系统管理 / 09-打印模板》。

## 10. 前端代码约定

| 项 | 约定 |
|---|---|
| 目录 | `src/modules/<code>/api/*.ts`（接口与类型）、`views/*.vue`（页面）、`components/*.vue`（模块内组件） |
| 页面命名 | 列表 `XxxList.vue`、弹窗表单 `XxxFormDialog.vue`、独立表单页 `XxxEdit.vue`、单据编辑页 `XxxEdit.vue`、单据详情页 `XxxDetail.vue` |
| 路由 | 列表 `/<模块>/<资源>`；新建 `/<模块>/<资源>/new`；详情 `/<模块>/<资源>/:id`；编辑 `/<模块>/<资源>/:id/edit`（详情、新建、编辑在菜单中 `hidden: true`） |
| 类型 | 所有接口入参和返回值定义 TypeScript 类型；ID 类型为 `string` |
| 枚举 | 后端枚举在前端定义同名常量对象（值 + 标签 + 颜色），或使用字典 |
| 样式 | 只用 `scoped` 样式；颜色和间距使用 Element CSS 变量，不写死色值 |
| 文案 | 界面文字写在 `src/modules/<code>/locales/zh-CN.ts` 与 `en.ts`（国际化 P1，一期可先写中文，但集中在文案文件中） |

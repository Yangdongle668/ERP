# UI 设计规范

> 本规范是所有前端页面的强制约定。各模块需求文档中的页面定义只写“用哪个模板 + 具体字段/按钮”，模板的通用行为以本文为准。
> 技术基础：Vue 3 + Element Plus 2.x（中文语言包），图标库 Lucide（`lucide-vue-next`），不引入其他 UI 库。
> 视觉方向：克制、专业的企业级 SaaS / 制造业 ERP。中性灰白为主，颜色只用于状态和关键操作；不使用渐变、玻璃拟态、大圆角、明显阴影和装饰性插画。

## 1. 设计原则

1. **效率优先**：ERP 用户每天长时间录单。支持键盘操作、批量操作，尽量减少页面跳转和弹窗层级（弹窗最多两层）。
2. **一致**：同类页面结构、按钮位置、文案、颜色完全一致。用户学会一个模块，其他模块就会用。
3. **防错**：能选择的不让输入，能带出的不让重复填，危险操作二次确认，未保存离开提醒。
4. **信息密度适中**：列表一屏显示 15～20 行数据（表格可切换紧凑行高）；表单尽量一屏显示完单头。
5. **一套设计系统**：所有页面使用同一套 Design Token 与公共组件，页面不自行设计样式（第 2 节、第 10 节，`npm run lint:style` 强制检查）。
6. **层级清晰**：页面标题 → 面包屑/描述 → 查询与操作 → 主数据 → 次要信息，视觉权重逐级降低（3.4）。

## 2. 基础规范（Design System）

所有 token 定义在 `erp-ui/src/styles/tokens.css`，Element Plus 组件主题在 `styles/element.css`，基础样式与工具类在 `styles/global.css`。
**页面与组件只允许使用 `var(--erp-*)`（或已映射的 `var(--el-*)`）与工具类，不允许写颜色字面量、px 字号、字体、阴影和大圆角**；`npm run build` 前自动执行 `npm run lint:style` 检查。

### 2.1 分辨率与适配

| 项 | 规范 |
|---|---|
| 设计基准 | 1920 × 1080（桌面优先） |
| 最小支持 | 1366 × 768（常见笔记本），此时不得出现页面级横向滚动条（表格、窄面板内部可横向滚动） |
| 浏览器 | Chrome / Edge 最新两个版本 |
| 移动端 | 不适配（工作台审批的 H5 页面另行设计，P2） |

### 2.2 颜色

中性色构成界面主体；语义色**只用于状态与关键操作**（主按钮、链接、选中、状态徽标、校验错误），不用于大面积背景和装饰。

| 用途 | Token | 色值 |
|---|---|---|
| 页面背景 | `--erp-color-bg` | #F5F6F8 |
| 面板 / 表格 / 弹窗 | `--erp-color-surface` | #FFFFFF |
| 表头、工具条、只读底色 | `--erp-color-surface-subtle` | #F7F8FA |
| 主文字 | `--erp-color-text` | #1F2329 |
| 次要文字（标签、说明） | `--erp-color-text-secondary` | #646A73 |
| 三级文字（占位、时间戳、空值） | `--erp-color-text-tertiary` | #8F959E |
| 分割线、面板边框 | `--erp-color-border` | #E5E6EB |
| 表格行分割线 | `--erp-color-border-light` | #EFF0F2 |
| 输入框、按钮边框 | `--erp-color-border-strong` | #D0D3D8 |
| 悬停 | `--erp-color-hover` | #F2F3F5 |
| 按下 | `--erp-color-active` | #EBECEF |
| 主色（主按钮、链接、选中） | `--erp-color-primary` / `--el-color-primary` | #2B6CE6 |
| 成功 | `--erp-color-success` | #1A9E5F |
| 警告 | `--erp-color-warning` | #D97A00 |
| 错误 / 危险 / 负数 | `--erp-color-error` | #D93D3D |
| 信息 / 中性状态 | `--erp-color-info` | #646A73 |

每个语义色有对应浅底色 `--erp-color-*-bg`，用于徽标和选中背景。Element Plus 的 `--el-color-*`（含 light/dark 梯度）、`--el-text-color-*`、`--el-border-color-*`、`--el-fill-color-*` 已映射到上表，组件库自动继承。

### 2.3 字体与字号（Typography）

- 字体：`--erp-font-family` = `"Microsoft YaHei", "微软雅黑", "PingFang SC", "Hiragino Sans GB", -apple-system, "Segoe UI", sans-serif`（Windows 优先微软雅黑）。
- 等宽：`--erp-font-family-mono`（编码规则、参数键、追踪号、JSON）。
- 数字列（数量、金额、单号）使用等宽数字：工具类 `.num`（`font-variant-numeric: tabular-nums`）。
- **只允许以下 5 级**，页面不得自行定义字号：

| 级别 | Token | 字号 / 字重 | 用途 | 工具类 |
|---|---|---|---|---|
| Page Title | `--erp-font-size-page-title` | 20px / 600 | 页面标题（`ErpPage`、单据页头） | `.erp-text-page-title` |
| Section Title | `--erp-font-size-section-title` | 16px / 600 | 面板标题、弹窗/抽屉标题、分组标题 | `.erp-text-section-title`（`.group-title`） |
| Body | `--erp-font-size-body` | 14px / 400 | 正文、表单、表格单元格、按钮 | `.erp-text-body` |
| Secondary | `--erp-font-size-secondary` | 13px / 400 | 表头、页面描述、分页、页签 | `.erp-text-secondary` |
| Caption | `--erp-font-size-caption` | 12px / 400 | 面包屑、表单提示、徽标、时间戳 | `.erp-text-caption`（`.form-tip`） |

字重只用 `--erp-font-weight-regular`（400）/ `-medium`（500，表头、选中项、主按钮）/ `-semibold`（600，标题）。工作台指标数字使用 `--erp-font-size-metric`（28px / 600）。

### 2.4 间距（4 / 8 基准）

| Token | 值 | 用途 |
|---|---|---|
| `--erp-space-1` | 4px | 图标与文字 |
| `--erp-space-2` | 8px | 按钮之间、行内元素 |
| `--erp-space-3` | 12px | 工具栏与表格、紧凑分组 |
| `--erp-space-4` | 16px | 面板内边距（纵向）、页头与内容 |
| `--erp-space-5` | 20px | 面板内边距（横向）、表单项间距、**模块之间**（`--erp-section-gap`） |
| `--erp-space-6` | 24px | **内容区左右留白**（`--erp-page-padding-x`） |

内容区内边距 20px 24px；面板之间 20px；表单项垂直间距 20px；查询条件之间 24px。

### 2.5 圆角、阴影、动效

| 项 | Token | 值 |
|---|---|---|
| 徽标、复选框、下拉选项 | `--erp-radius-xs` | 4px |
| 输入框、按钮、选择器 | `--erp-radius-control` | 6px |
| 面板（Card）、下拉浮层、Toast | `--erp-radius-card` | 8px |
| 弹窗、确认框 | `--erp-radius-dialog` | 10px |
| 浮层阴影（Dropdown、Popover、Toast） | `--erp-shadow-float` | 很轻 |
| 弹窗阴影（Dialog、Drawer） | `--erp-shadow-dialog` | 轻 |
| 动效时长 | `--erp-duration-fast` / `--erp-duration` | 120ms / 160ms，缓动 `--erp-ease` |

- 不使用 16px 以上圆角；面板、表格、按钮**默认无阴影**，以 1px 边框区分层次。
- 交互状态：Hover（`--erp-color-hover` 底色或加深边框）、Active（`--erp-color-active`）、Focus（主色描边 + 3px 浅色聚焦环，键盘聚焦显示 outline）、Disabled（浅底 + 禁用文字色）、Loading（按钮 loading、表格骨架/遮罩）。

### 2.6 图标

- 统一使用 **Lucide** 线性图标（描边 1.75），在 `src/components/icons.ts` 注册；名称沿用 Element Plus 图标名（`icon="Plus"`、`<el-icon><Search /></el-icon>`、模块菜单 `icon: 'Box'`）以兼容已有代码。
- 需要新图标时在 `icons.ts` 中增加映射；**禁止**直接引入 `@element-plus/icons-vue`、其他图标库或使用 Emoji 作为界面图标。
- 尺寸：行内 `--erp-icon-size-sm`（14px）、按钮/菜单/表格 `--erp-icon-size`（16px）、头部工具 `--erp-icon-size-lg`（18px）。

### 2.7 组件尺寸

| 组件 | 尺寸 |
|---|---|
| 控件高度（`--erp-control-height`） | 32px（Element `default`）；登录页 `large` 40px |
| 表格行高 | 默认约 40px；紧凑约 32px（表格工具栏切换，全站记忆） |
| 头部 / 页签栏 / 侧边栏 | 52px / 36px / 220px（折叠 64px） |
| 弹窗宽度 | 小 480px（确认、原因）/ 中 640px（单列表单）/ 大 960px（双列表单、选择器）/ 超大 1200px（选单） |
| 抽屉宽度 | 640～720px（详情预览） |

## 3. 整体布局

```
┌──────────┬────────────────────────────────────────────────────────────────┐
│ ■ ERP系统 │ ⇤  [⌕ 搜索菜单 Ctrl+K]                         [铃] │ (张) 张三 ⌄ │ ← 头部 52px
│          ├────────────────────────────────────────────────────────────────┤
│ ⌂ 工作台  │  工作台   物料 ×   销售订单 ×   SO-202609-0001 ×                   │ ← 页签栏 36px
│ ◎ CRM  ⌄ ├────────────────────────────────────────────────────────────────┤
│ ◇ 研发 ⌃ │  研发工程 / 物料                                  ← 面包屑 12px    │
│   物料 ▌ │  物料                                   [页面级操作] ← 标题 20px   │
│   BOM    │  物料主数据：编码、规格……                          ← 描述 13px    │
│ ...      │  ┌ 面板 ─────────────────────────────────────────────────────┐  │
│          │  │ 查询条件……                              [查询] [重置]       │  │
│          │  ├──────────────────────────────────────────────────────────┤  │
│          │  │ [+ 新建] [批量…]  已选 3 项 · 取消选择        ⇪ ⇩ ▥ ☰ ⟳  │  │
│          │  │ 表格……                                                    │  │
│          │  │ 共 128 条                          20条/页 ‹ 1 2 3 › 前往  │  │
│          │  └──────────────────────────────────────────────────────────┘  │
└──────────┴────────────────────────────────────────────────────────────────┘
  侧边栏 220px（折叠 64px）；内容区背景 #F5F6F8，内边距 20px 24px
```

所有业务页面以 `ErpPage` 为根组件，内容由 `ErpPanel` 组成；**不允许页面自行实现不同的布局逻辑**。

### 3.1 侧边栏

- 白底，右侧 1px 分割线；顶部为系统名称与单色标识（深灰方块 + 首字）。
- 两级菜单：模块（图标 + 名称，主文字 500）→ 页面（次要文字）。只显示有权限的菜单；模块下没有任何有权限的页面时整个模块隐藏。
- 手风琴模式（同时只展开一个模块）。当前页面浅主色底 + 主色文字高亮，且自动展开所属模块。
- 折叠状态记住在本地（localStorage），折叠后鼠标悬停显示二级菜单。

### 3.2 头部

| 元素 | 行为 |
|---|---|
| 折叠按钮 | 展开/折叠侧边栏（图标按钮） |
| 菜单搜索 | 输入拼音首字母或中文，下拉匹配菜单，回车跳转。快捷键 `Ctrl + K` 聚焦 |
| 待办铃铛 | 显示待办数量角标（>99 显示 99+），每 60 秒刷新；点击下拉显示最近 10 条待办，底部“查看全部”跳转工作台待办 |
| 用户菜单 | 头像（姓名首字）+ 姓名；个人中心、修改密码、切换语言（中文/English）、退出登录 |

面包屑不在头部，而在页面标题上方（3.4）。

### 3.3 多页签栏

- 文字页签，当前页签主文字 + 主色下划线；悬停浅灰底；关闭按钮悬停时显示。
- 每打开一个页面新增一个页签；已打开的页面再次点击菜单时切换到该页签而不是新开。
- 单据详情/编辑页按单号或“新建销售订单”作为页签标题，同一单据只开一个页签。
- 页签缓存页面状态（`keep-alive`）：切换回列表时保留查询条件、页码、滚动位置。
- 右键菜单：刷新、关闭、关闭其他、关闭右侧、关闭全部。“工作台”页签固定不可关闭。
- 最多 20 个页签，超出时自动关闭最早打开的未修改页签。
- 页签内有未保存修改时标题前显示橙色圆点，关闭时提示“有未保存的修改，确定关闭吗？”。

### 3.4 页面骨架与信息层级（`ErpPage` / `ErpPanel`）

| 层级 | 元素 | 视觉 |
|---|---|---|
| 1 | 页面标题 | 20px / 600，主文字；右侧为页面级操作（表单页的保存/取消，参数页的保存） |
| 2 | 面包屑（标题上方）/ 页面描述（标题下方） | 12px 三级文字 / 13px 次要文字；描述一句话说明页面用途和关键规则 |
| 3 | 查询条件、工具栏 | 查询条件在面板顶部（`ErpPanel` 的 `filter` 插槽，下方 1px 分割线）；工具栏左侧主操作（唯一的主色按钮）+ 批量操作，右侧图标按钮 |
| 4 | 主数据 | 表格 / 表单，14px 主文字 |
| 5 | 次要信息 | 分页、合计、说明、时间戳，12～13px 次要文字 |

**面板（Card）使用原则**

- 只有具有独立信息边界的内容才使用面板：一个列表页通常**只有一个面板**（查询 + 工具栏 + 表格 + 分页）；主从页面（树 + 列表、类型 + 明细）左右各一个面板；表单页按信息分组（基本信息、组织与权限）分面板。
- 不在面板里再套面板或卡片；不用彩色卡片；面板之间 20px。
- 面板白底、1px `--erp-color-border` 边框、8px 圆角、无阴影；标题 16px / 600，右侧 `extra` 插槽放面板级按钮。

## 4. 页面模板

所有业务页面必须从以下模板中选用。模块需求文档中用模板代号（如 **T1**）说明页面类型。

### T1 列表页

```
┌───────────────────────────────────────────────────────────────────────┐
│ 单号 [__________]  客户 [______▾]  状态 [全部▾]  日期 [____ ~ ____]      │ 查询区
│                                            [查询] [重置] 展开 ⌄         │
├───────────────────────────────────────────────────────────────────────┤
│ [+ 新建] [批量审核] [批量删除]                    [导入] [导出] ⚙ ⟳     │ 工具栏
├───────────────────────────────────────────────────────────────────────┤
│ ☐ │ 单号 ▲       │ 客户      │ 日期       │ 金额       │ 状态   │ 操作        │
│ ☐ │ SO-2609-0001 │ ABC Ltd  │ 2026-09-24 │ 12,500.00 │ 已审核 │ 编辑 更多▾   │ 表格
│ ...                                                                  │
├───────────────────────────────────────────────────────────────────────┤
│                              共 128 条  [20条/页▾] ‹ 1 2 3 … 7 ›        │ 分页
└───────────────────────────────────────────────────────────────────────┘
```

**查询区**
- 默认显示一行（1920 宽度最多 4 个条件，1366 宽度 3 个），其余条件点击“展开”显示。
- 条件控件宽度统一 200px；日期范围 260px。
- 输入框回车即查询；下拉、日期变更不自动查询，需点“查询”。
- “重置”恢复默认条件并查询。
- 文本条件默认模糊匹配；单号、编码条件为前缀匹配（需求文档另有说明的除外）。
- 列表的默认条件（如“近 3 个月”）在各页面定义中说明。

**工具栏**
- 左侧：主操作（“新建XX”，`type=primary`，带 `Plus` 图标；每个工具栏只有一个主色按钮），然后是批量操作（勾选后才可用，未勾选时置灰）。勾选后工具栏显示“已选 N 项 · 取消选择”。
- 右侧（`ErpIconButton`：无边框图标按钮 + tooltip）：导入、导出、列设置、行高（默认/紧凑）、刷新。
- 批量操作结果：全部成功提示“操作成功 N 条”；部分失败弹窗列出失败的单号和原因。

**表格**
- 第一列勾选框（有批量操作时才显示）。
- 单号/编码列：蓝色链接，点击打开详情页（单据）或编辑弹窗（主数据）。
- 状态列：`StatusTag`（颜色见 7.3）。
- 数量、金额、单价列右对齐（等宽数字）；其余（文本、状态徽标、日期）左对齐。
- 表头浅灰底、13px 次要文字 / 500；只有横向分割线，不用斑马纹；悬停整行浅灰；可编辑明细表（`LinesEditor`）保留竖线。
- 超长文本单行省略 + 悬停提示（`show-overflow-tooltip`）。
- 操作列固定在右侧，最多直接显示 3 个文字按钮，其余放入“更多 ▾”下拉。按钮按单据状态和权限显示，不可用时**隐藏**而不是置灰。
- 支持列排序的列在需求文档中标注“可排序”，排序由后端执行。
- 列设置：可调整显示/隐藏、顺序，按用户 + 页面保存在本地；提供“恢复默认”。
- 需要合计的列表（如订单明细查询）在底部显示当前页合计和查询结果总计。
- 首次加载显示骨架行（Skeleton）；刷新时保留数据并显示半透明遮罩。
- 空数据显示 `ErpEmpty`（线性图标 + “暂无数据”，可带“新建”次要按钮），不使用插画。

**分页**：左侧“共 N 条”，右侧每页条数（20 / 50 / 100 / 200，默认 20）、页码、跳转；翻页后表格滚动回顶部。

### T2 弹窗表单（主数据新建/编辑）

- 用于字段不超过 12 个的主数据（如计量单位、币别、字典项）。
- 标题：“新建XXX” / “编辑XXX”。
- 单列布局用中弹窗（640px），label 宽 100px；字段 7～12 个用双列布局 + 大弹窗（960px）。
- 底部按钮：右对齐 [取消] [保存]；新建时可额外提供 [保存并新建]。
- 点击遮罩不关闭；有修改时关闭提示“有未保存的修改，确定关闭吗？”。
- 保存成功：关闭弹窗、提示“保存成功”、刷新列表并保持当前页。

### T3 独立表单页（复杂主数据）

- 用于字段多、有分组或子表的主数据（如用户、物料、客户、供应商）。
- 路由：`/<模块>/<资源>/new`、`/<模块>/<资源>/:id/edit`。
- 结构：页头（返回、标题、[取消] [保存]）+ 若干分组卡片（或 Tabs）。
- 表单栅格：1920 下每行 3 列，1366 下每行 2 列；文本域、地址类占整行。

### T4 单据编辑页（单头 + 明细）

```
┌───────────────────────────────────────────────────────────────────────┐
│ ← 新建销售订单                                  [取消] [保存草稿] [提交]  │ 页头（吸顶）
├───────────────────────────────────────────────────────────────────────┤
```

**页头**：左侧返回箭头 + 标题（新建时“新建XXX”，编辑时“编辑XXX SO-…”）；右侧按钮从左到右：[取消] [保存草稿] [提交]（提交为主按钮）。页头滚动时吸顶。

**单头**：按分组卡片展示（基本信息 / 交易信息 / 其他），次要分组可折叠。选择客户/供应商等主数据后自动带出默认值（币别、付款条件、业务员等），带出的值可修改。

**明细行（可编辑表格，`LinesEditor` 组件）**
- 行号自动生成（10、20、30…，便于插行；显示为 1、2、3 亦可，各单据统一用 1、2、3）。
- 物料单元格：输入编码或名称后回车/失焦 → 精确匹配编码则直接带出；否则弹出物料选择器。带出名称、规格、单位、默认单价等只读字段。
- 键盘：`Enter` / `Tab` 移到下一个可编辑单元格；在最后一行最后一个单元格回车自动新增一行；`↑` `↓` 在同一列上下移动；`Ctrl + Delete` 删除当前行。
- 自动计算：数量 × 单价 = 金额；修改后实时刷新底部合计。
- 行校验：保存时校验所有行，有错误的单元格标红，鼠标悬停显示原因，并滚动到第一处错误。
- 空行（物料为空）保存时自动忽略；至少需要一行有效明细，否则提示“请至少添加一行明细”。
- 行操作：删除、复制行、插入行（在当前行上方）。
- 从上游选单：打开 `SourceDocPicker`，勾选上游单据行后带入，数量默认为上游剩余可执行数量。
- 超过 200 行时启用虚拟滚动。

**保存与提交**
- 保存草稿：只做必填和格式校验，状态为草稿。
- 提交：做全部校验 → 保存 → 提交审批（或直接审核）。成功后跳转到详情页，并关闭当前编辑页签。
- 快捷键：`Ctrl + S` 保存草稿，`Ctrl + Enter` 提交。
- 离开页面（关闭页签、点击返回、刷新浏览器）且有未保存修改时提示。

## 6. 交互规范

### 6.1 按钮

| 场景 | 规范 |
|---|---|
| 主按钮 | 每个区域最多一个 `type=primary` |
| 顺序 | 工具栏：主操作在最左；弹窗/页头：[取消] 在左，主操作在最右 |
| 文案 | 动词或动宾短语，2～4 个字：新建、编辑、删除、保存、提交、审核、反审核、关闭、作废、打印、导入、导出、下推出货 |
| 防重复提交 | 点击后按钮进入 loading 状态，接口返回前不可再次点击 |
| 危险操作 | 删除、作废、反审核、关闭、停用、重置密码：二次确认 |
| 不可用 | 因状态或权限不可用的按钮**隐藏**；因条件未满足暂时不可用（如未勾选数据）的按钮**置灰**并用 tooltip 说明原因 |

| 关闭确认 | 关闭后剩余数量不再执行。请填写关闭原因。 |

### 6.4 表单校验

- 必填字段 label 前显示红色 `*`。
- 校验时机：失焦时校验单个字段；保存/提交时校验全部，并滚动到第一个错误字段。
- 提示文案：输入类“请输入{字段}”，选择类“请选择{字段}”，格式类“{字段}格式不正确，{规则说明}”，范围类“{字段}必须在 {min}～{max} 之间”。
- 后端返回的字段级校验错误（400）在对应字段下显示；无法定位字段的用消息提示。
- 输入框自动去除首尾空格。
- 编码类字段（编码、单号）输入时自动转为大写（需求文档另有说明除外）。

## 7. 显示格式

### 7.1 空值

- 空值统一显示 `-`（表格、描述列表）；表单中为空的输入框显示 placeholder。

### 7.2 数字与日期

| 类型 | 格式 | 示例 |
|---|---|---|
| 数量 | 千分位；小数位按单位精度，末尾 0 去掉 | `1,000`、`12.5`、`0.125` |
| 金额 | 千分位，固定 2 位小数（币别精度为 0 时 0 位） | `12,500.00` |
| 带币别金额 | 币别代码 + 空格 + 金额 | `USD 12,500.00` |
| 单价 | 最多 6 位小数，末尾 0 去掉，至少 2 位 | `0.50`、`0.1234` |
| 汇率 | 固定 4 位小数（存储 6 位） | `7.1000` |
| 百分比 | 2 位小数 + `%` | `12.50%` |
| 负数 | 前置 `-`，红色 | <span>-1,200.00</span> |
| 日期 | `YYYY-MM-DD` | `2026-09-24` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss`；列表中可只显示到分钟 `YYYY-MM-DD HH:mm` | `2026-09-24 13:53` |
| 时长 | `N 天`、`N 小时 M 分` | `3 天` |

### 7.3 状态颜色（`StatusTag` / `ErpBadge`）

状态统一以徽标显示：圆点 + 文字 + 对应浅底色（`ErpBadge`），不使用实心色块。

| 状态 | 颜色 | type |
|---|---|---|
| 草稿 | 灰 | `info` |
| 待审批 / 待检 / 待处理 | 橙 | `warning` |
| 已审核 / 执行中 / 检验中 | 蓝 | `primary` |
| 已完成 / 合格 / 启用 / 已通过 | 绿 | `success` |
| 已关闭 / 停用 | 灰色圆点 + 三级文字，无底色 | `info` + `plain: true` |
| 已作废 / 不合格 / 已驳回 / 黑名单 | 红 | `danger` |

模块特有状态在需求文档中给出颜色；未给出的按语义套用上表。“内置”“本位币”等非状态标记使用不带圆点的徽标（`:dot="false"`）。

## 8. 权限在界面上的表现

| 类型 | 表现 |
|---|---|
| 菜单权限 | 无权限的菜单不显示；直接访问地址跳转 403 页 |
| 按钮权限 | 无权限的按钮不显示（`v-perm`） |
| 数据权限 | 列表只返回有权限的数据，界面无额外提示 |
| 字段权限 | 敏感字段（成本价、采购价、毛利）无权限时，列表和详情显示 `***`，表单中不显示该字段，导出中该列为空 |

## 9. 导入导出与打印

### 9.1 导入

- 模板为 `.xlsx`，第一行为中文列名，必填列名后带 `*`，第二行为填写说明（灰色斜体，导入时忽略）。
- 下拉型字段在模板中使用数据验证下拉；日期列设置为日期格式。
- 单次最多 5000 行；超出提示“单次最多导入 5000 行，请拆分文件”。
- 校验错误报告：在原文件最后增加“错误原因”列，错误单元格标红。

### 9.2 导出

- 文件名：`{页面名称}_{yyyyMMddHHmmss}.xlsx`。
- 列与当前列表“列设置”中显示的列一致，顺序一致；金额、数量为数字格式（不是文本）。
- 字段权限不足的列导出为空。

### 9.3 打印

- 纸张默认 A4 纵向，明细列多的单据用 A4 横向（在打印模板中设置）。
- 版式：页眉（公司 Logo、公司名称、单据名称，右上角单号 + 条码）→ 单头信息 → 明细表（跨页时每页重复表头）→ 合计 → 备注 → 签字栏（制单、审核、签收）→ 页脚“第 X 页 / 共 Y 页”、打印时间。
- 对外单据（报价单、PI、Packing List、Invoice）提供英文模板。
- 打印模板管理见《01-系统管理 / 09-打印模板》。

## 10. 前端代码约定

| 项 | 约定 |
|---|---|
| 目录 | `src/modules/<code>/api/*.ts`（接口与类型）、`views/*.vue`（页面）、`components/*.vue`（模块内组件） |
| 页面命名 | 列表 `XxxList.vue`、弹窗表单 `XxxFormDialog.vue`、独立表单页 `XxxEdit.vue`、单据编辑页 `XxxEdit.vue`、单据详情页 `XxxDetail.vue` |
| 路由 | 列表 `/<模块>/<资源>`；新建 `/<模块>/<资源>/new`；详情 `/<模块>/<资源>/:id`；编辑 `/<模块>/<资源>/:id/edit`（详情、新建、编辑在菜单中 `hidden: true`） |
| 类型 | 所有接口入参和返回值定义 TypeScript 类型；ID 类型为 `string` |
| 枚举 | 后端枚举在前端定义同名常量对象（值 + 标签 + 颜色），或使用字典 |
| 页面结构 | 根组件 `ErpPage`，内容用 `ErpPanel`；列表页参考 `modules/engineering/views/MaterialList.vue`，主从页参考 `system/views/DictList.vue`，表单页参考 `system/views/UserEdit.vue` |
| 样式 | 只用 `scoped` 样式，且只写布局（flex、宽度、间距）；颜色、字号、字重、圆角、阴影、字体一律使用 `--erp-*` token 或 `global.css` 工具类；不覆盖 Element 组件外观；不写行内颜色/字号 |
| 样式检查 | `npm run lint:style`（`npm run build` 自动执行）：检查颜色字面量、px 字号、字体、数字字重、>10px 圆角、Emoji、直接引入 Element 图标、页面是否使用 `ErpPage` |
| 图标 | 只用 `components/icons.ts` 注册的 Lucide 图标名 |
| 文案 | 界面文字写在 `src/modules/<code>/locales/zh-CN.ts` 与 `en.ts`（国际化 P1，一期可先写中文，但集中在文案文件中） |
